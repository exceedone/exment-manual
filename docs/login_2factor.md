# Login (two-step verification)
How to log in to Exment with two-factor authentication.  
The settings that make two-factor authentication usable are made by the administrator ([Two-factor authentication system settings](/login_2factor_setting)).

## Two-factor authentication method
The two-factor authentication methods that can be used now are the following two.  
Ask your administrator which method is used.

##### Email
After you log in with the ID and password, an email with an authentication code arrives at the registered email address.  
Enter that authentication code on the screen, and the login is finished.

##### Google Authenticator
After you log in with the ID and password, two-factor authentication is done with Google Authenticator.

### Two-step verification procedure (email)

- On the login screen, enter the ID and password and press the [Login] button.
![System setting screen](img/login/login_2factor11.png)  

- The screen changes to the two-factor authentication screen, and the input field of the authentication code appears.
![System setting screen](img/login/login_2factor12.png)  

- An authentication code arrives at the email address of the user who logged in. Check it.
![System setting screen](img/login/login_2factor13.png)  

### Two-step authentication procedure (Google authentication system)

- On the login screen, enter the ID and password and press the [Login] button.
![System setting screen](img/login/login_2factor11.png)  

- The screen changes to the two-factor authentication screen, and the input field of the authentication code appears.
![System setting screen](img/login/login_2factor15.png)  

- When you log in for the first time, you need to set up Google Authenticator first.  
Press the [Submit] button, and an email for registering Google Authenticator is sent to the registered email address.
![System setting screen](img/login/login_2factor5.png)  

- The URL for registering Google Authenticator arrives at the email address of the user who logged in. Press it.  
![System setting screen](img/login/login_2factor6.png)  

- When you press the URL, the screen changes to the one for installing the two-factor authentication system. Do steps 1 to 3.  
When you enter the authentication code correctly and send it, the login with two-factor authentication is finished.

![System setting screen](img/login/login_2factor7.png)  

> If you enter a wrong authentication code more than a certain number of times in two-factor authentication, logins from the connection that tried are blocked. Please be careful.
