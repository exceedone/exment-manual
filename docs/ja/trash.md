# ゴミ箱
削除したデータを、すべてのテーブルぶん 1 つの画面で見ます。元に戻すことも、完全に削除することもできます。  
また、削除してから決めた日数がたったデータを、夜に自動で完全に削除することもできます。

※この機能は、Exment v7.3.0 以降で使えます。  
※「ゴミ箱」の画面は、はじめは「使わない」です。システム管理者が「[機能の管理](/ja/feature)」で「ゴミ箱」を「使う」にするまで、メニューに出ず、URL を開いても「見つかりません」と出ます。

## ゴミ箱の画面
「設定：データと画面」→「ゴミ箱」を開きます（URL は `/admin/trash`）。

### 見られるデータ
次の両方を満たすテーブルの、削除したデータが出ます。
- 「削除データの表示」の権限があるか、そのテーブルの管理者であること。
- そのテーブルのデータを見られること。

[権限](/ja/permission)の決め方は、「権限」のページを見てください。

### 一覧
次の項目が出ます。新しく削除したものが上です。1 ページに 30 件です。
- テーブル
- データ
- 削除日時
- 削除したユーザー
- データへのリンク

次の条件で絞り込めます。
- テーブル
- 削除日時（いつから・いつまで）
- 削除したユーザー

### 元に戻す
1 行ずつ、または行を選んでまとめて、「元に戻す」ことができます。
- 一度に選べるのは 100 件までです。まとめて行うときは、全部できるか、全部できないか（1 件でもだめなら、何も変わりません）のどちらかです。
- 元に戻すには、そのテーブルと、そのデータの編集の権限が要ります。
- 親のデータがまだ削除されているときは、子のデータだけを元に戻せません。先に親を元に戻します。
- 親を元に戻すと、その子のデータも一緒に戻ります。

### 完全に削除する
1 行ずつ、または行を選んでまとめて、完全に削除できます。
- 一度に選べるのは 100 件まで。まとめて行うときは、全部できるか、全部できないかです。
- 変更履歴・ファイル・子のデータも一緒に消えます。
- **あとで元に戻すことはできません。** よく確かめてから行ってください。

削除したデータについては、[削除済データ](/ja/deleted_data)のページも見てください。

### プラグインへの知らせ
データを元に戻したとき、完全に削除したときに、プラグインがイベントを受け取れます（`CustomValueRestored`・`CustomValueForceDeleted`）。

## 自動で完全に削除する
削除してから決めた日数がたったデータを、夜に自動で完全に削除します。

### テーブルごとの設定
[テーブルの設定](/ja/table)にある「削除してから完全に削除するまでの日数」に、日数を入れます。
- 空か 0 のときは、自動では削除しません。はじめは空です。
- ユーザー・組織・コメント・ドキュメントのテーブルには、この設定はありません。

### 夜の処理
毎晩 3 時 50 分に、`exment:trash-purge` が動きます。削除してから決めた日数より長くたったデータを、完全に削除します。

**この自動の削除は、「ゴミ箱」の画面を「使わない」にしていても動きます。** 動くかどうかは、テーブルの設定だけで決まります。

### アーカイブ
完全に削除する前に、次のものをコピーして、アーカイブに残します。
- データ
- 子のデータ
- コメント
- 変更履歴
- 添付ファイルのコピー

次のときは、そのデータは削除せずに残します。次の夜に、もう一度ためします。
- ファイルをコピーできなかったとき
- 削除が止められたとき
- 削除されていない子のデータが、まだあるとき

アーカイブは、初期値では 365 日たつと消えます。`.env` で変えられます。

| 設定 | 内容 |
| --- | --- |
| `EXMENT_DELETED_ARCHIVE_KEEP_DAYS` | アーカイブを残す日数。初期値は 365。0 なら消しません。 |
| `EXMENT_DELETED_ARCHIVE_DISK` | アーカイブの保存先。空なら、添付ファイルと同じ保存先です。フォルダーは `archives/deleted` です。 |

※アーカイブから元に戻す機能は、まだありません（予定しています）。

### コマンドで確かめる
```
php artisan exment:trash-purge --dry-run
```
`--dry-run` をつけると、何も変えずに、「削除するもの」と「飛ばすもの」だけを表示します。  
`--table=テーブル名` をつけると、1 つのテーブルだけを対象にします。
