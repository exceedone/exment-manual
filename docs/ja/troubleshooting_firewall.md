# ファイアウォール・プロキシに保存を止められるとき

Exment のサーバーの前に、ファイアウォール（AWS WAF・Cloudflare・社内のプロキシなど）を置いていると、保存の内容によっては、Exment に届く前に止められることがあります。  
この画面では、そのときの見分け方と、直し方の例を書きます。

> この知らせとセキュリティチェックの項目は、v7.3.x からです。

## どんなときに起きるか

ファイアウォールは、送られた本文の中に、攻撃に使われることばがないかを見ています。次のようなことばを書くと、ふつうの保存でも止められることがあります。

- `http://localhost/`・`http://127.0.0.1/`・`http://10.0.0.1/` のような、サーバー自身や社内のアドレス
- `169.254.169.254`（クラウドのメタデータのアドレス）
- `../`・`../../etc/passwd`・`C:\Windows\` のようなパス
- `<script>` のようなタグ、とても長い本文

たとえば、セキュリティの報告や、サーバーの手順を課題やコメントに書いたときです。

## 見分け方

### 画面の知らせ

Exment は、自分の答えに `X-Exment` というヘッダーを付けています。保存のときに、このヘッダーのない 403・406・413 などが返ると、画面の上に次のように出します。

> 保存が通信の途中でことわられました（ファイアウォールなど）

「権限がありません」とは出しません。書いた内容は、フォームに残っています。  
「くわしく」を押すと、ステータス・送り先・答えのヘッダーの名前・答えの最初の行が出ます。管理者に伝えるときは、これを写してください。

ふつうのフォームの保存（ページが切りかわる保存）が止められたときは、ファイアウォールのページが出ます。ブラウザーの「戻る」でフォームに戻ると、「前の保存が Exment に届かなかったかもしれません」と出ます。

### ブラウザーのログ

「ブラウザーのログ」を使っているときは、そのリクエストの行に「not answered by Exment (a firewall or a proxy in front?)」と、答えのヘッダーの名前が残ります。本文の中身は残しません。

### セキュリティチェック

管理者は、「設定：システム」→「セキュリティチェック」の「サイトの前のファイアウォール」で、「ためす」を押します。このブラウザーから、上のことばを入れた小さな本文を自分のサイトに送り、止められるかを見ます。

- 「問題なし」：前で止められていません。
- 「直してください」：前で止められました。下の「直し方」のとおりに、ファイアウォールの設定を見直してください。

### ファイアウォールの記録

どのルールで止めたかは、ファイアウォールの記録でわかります。

- AWS WAF：Web ACL の「サンプルリクエスト」、または `aws wafv2 get-sampled-requests`。ログを CloudWatch Logs などに出していれば、そのログ
- Cloudflare：「セキュリティ」→「イベント」

## 直し方

**ルールを丸ごと外さないでください。** 止められた道（URL のパス）だけ、そのルールを外します。ほかの道（ログイン・API など）は、今までどおり守ります。

### AWS WAF（マネージドルール）の例

AWS のマネージドルール `AWSManagedRulesCommonRuleSet` では、`EC2MetaDataSSRF_BODY`・`GenericRFI_BODY`・`GenericLFI_BODY`・`CrossSiteScripting_BODY`・`SizeRestrictions_BODY` などが、本文のことばで止めます。

1. マネージドルールのグループで、止めているルールだけを「Count」（記録だけ）にします（ルールのアクションのオーバーライド）。
2. そのルールのラベル（例：`awswaf:managed:aws:core-rule-set:GenericLFI_Body`）が付いたリクエストを Block する、自分のルールを、マネージドルールのあとに足します。
3. その自分のルールに、「URI のパスが、保存の道（例：`/admin/data/`・`/admin/files`・`/fileupload` で終わるもの）ならば止めない」という条件を入れます。

こうすると、保存の道では本文のことばで止めず、ほかの道では今までどおり止めます。変える前の Web ACL は、`aws wafv2 get-web-acl` で取っておいてください。

### Cloudflare の例

「セキュリティ」→「WAF」で、止めているマネージドルールに「例外（スキップ）」を作ります。

- 条件：URI のパスが保存の道で始まる（例：`/admin/data/`）
- スキップするもの：止めているルール（イベントに出たルールの ID）だけ

### 社内のプロキシ

プロキシの管理者に、止められたときの時刻・送り先のパス・ステータス（「くわしく」の中身）を伝えて、その道だけ外してもらってください。

## 本文が大きすぎるとき（413）

本文の大きさで止められるときは、ファイアウォールのほかに、Web サーバーの上限もあります。

- nginx：`client_max_body_size`（既定 1 MB）
- PHP：`post_max_size`・`upload_max_filesize`（[php.ini の設定](/ja/additional_php_ini)）
- Exment の文字の上限：`.env` の `EXMENT_CHAR_LENGTH_LIMIT_COUNT`（既定 63,999 文字）
