# ログの管理

「管理者設定」→「設定：システム」→「ログの管理」で、このサイトのログを 1 つの画面で管理します（Exment 7.3.0 以降）。
見られるのはシステム管理者と、役割グループで「監査」を持つ人です。設定を変えられるのと、ファイル・アーカイブをダウンロードできるのは、システム管理者だけです。

## ログの種類

| 種類 | 置き場所 | 残す期間（初めの値） |
|---|---|---|
| 操作の記録 | データベース | 「操作ログ」の画面の自動削除の設定のまま |
| ログインの記録 | データベース | 365 日 |
| アプリのログ | storage/logs | 日ごとのファイルは 90 日（1 つの laravel.log は消しません） |

古いログは、決まった時間の処理「ログ：古いものを消す」（`php artisan exment:log-maintenance`、毎日 3:40）が消します。残す日数を 0 にすると、消すまで残します。

## 設定

- **ログインの記録を残す日数・アプリのログを残す日数**
- **アプリのログの重さ**：書く重さの下限（debug・info・notice・warning・error）。空のときサイトの設定（LOG_LEVEL）のまま
- **アプリのログを日ごとのファイルにする**：laravel-YYYY-MM-DD.log。古いファイルは残す日数を過ぎたら消します
- **操作の記録に残すもの**：すべての操作（今までどおり）か、何かを変えた操作だけ

## ログインの記録

日付・ログイン名・結果（成功・失敗・ロック・ログアウト）で絞りこみ、CSV でダウンロードできます。失敗には理由（パスワードの間違い・知らないユーザー・2 段階認証の失敗）が付きます。

## アーカイブ

「古いログを消す前に、月ごとの gzip ファイルにまとめる」をオンにすると、消す前に、種類ごと・月ごとのファイル（`log_archive/<種類>/<種類>-YYYY-MM.csv.gz`、アプリのログは `.log.gz`）に入れます。

- 置き場所：このサーバー（storage/app/log_archive、持ち主だけが読める 600）か、バックアップと同じ場所（バックアップが S3 なら S3。S3 が暗号にします）
- 「アーカイブを APP_KEY で暗号にする」をオンにすると、これから書く月から暗号にします。**APP_KEY をなくすと読めません。**
- アーカイブを残す年数を決められます

## ログの個人の情報

ログは盗まれることがあります。Exment 7.3.0 から、ログには個人の情報をなるべく残しません。

- **ログに入力の値を残す**（初めはオフ）：オフのとき、操作の記録（画面・API・MCP）には送った内容のキーだけを残し、値は `***` にします。アプリのログでは、メールアドレスと SQL の値を伏せます。オンのとき、今までどおり値を残します（パスワード・トークン・秘密の鍵は伏せます）
- **ログの IP アドレス**：そのまま（初め）・短くする（IPv4 は /24、IPv6 は /48）・ハッシュにする（同じアドレスは同じ文字）。監査では、ふつう IP アドレスがそのまま要ります
- **メールの送信の記録に本文を残さない**（初めはオフ：今までどおり本文も残します）
- ログインに失敗したとき、打った文字は残しません（間違えて入れたパスワードかもしれないため）
- 新しいログのファイルは 0640 で作ります（`.env` の `EXMENT_LOG_FILE_PERMISSION`。cron を同じグループの別のユーザーで動かすときは 0660）。`php artisan exment:setup-dir` は storage/logs を 02770・0640、アーカイブを 02700・0600 にします
- デバッグの設定（`EXMENT_DEBUG_MODE_REQUEST`）でも、Cookie と認証のヘッダーは書きません

[セキュリティチェック](/ja/security_check)の「ログと個人の情報」が、入力の値を残しているとき・デバッグの設定がオンのとき・ログのファイルをだれでも読めるときに知らせます。

## 7.3.0 に更新するとき

<span class="red bold">7.3.0 から、操作の記録には送った内容の値を残しません（キーだけ）。アプリのログでは、メールアドレスと SQL の値を伏せます。新しいログのファイルは 0640 になります。今までどおり値を残すときは、「ログの管理」で「ログに入力の値を残す」をオンにしてください。</span>
`php artisan exment:update` を実行すると、1 回だけこのことを表示します。
