# API の上限の一時的な引き上げ
ユーザーか API のクライアントに、期限つきで、API を 1 分に呼べる回数を増やします。データの取り込みや、ほかのシステムからの乗り換えのときに、サーバーの作業なしで速く進められます。期限が来ると、元の回数に戻ります。

「設定：API設定」の一覧の上にある「API の上限の一時的な引き上げ」（URL は `/api_rate_raises`）で開きます。

※この機能は、Exment v7.2.6 以降で使えます。  
※この画面を使えるのは、システム管理者だけです。

## 使い始める
[機能の管理](/ja/feature)で「API の上限の一時的な引き上げ」を「使う」にします。はじめは「使わない」です。使わないときは、この画面は開けません（404 になります）。登録してある引き上げも効きません。

## ふだんの上限
API は、1 分に 60 回までです（ユーザーごと。API キーのときは、キーごとと IP アドレスごと）。超えると `429 Too Many Requests` を返します。回数は `.env` の `EXMENT_API_MAX_RATE_LIMIT` で変えられます。

## 引き上げを追加する
| 項目 | 入れるもの |
|---|---|
| 相手 | ユーザーか、API のクライアント（[API設定](/ja/api)で作ったもの） |
| 1 分の回数 | ふだんの上限より大きい数（例：600） |
| 期限（時間） | 今から何時間か。最長 24 時間です |
| 理由 | 何のために上げるか（例：Backlog からの取り込み） |

- ユーザーに引き上げると、そのユーザーのログイン・OAuth のトークン・[API キー](/ja/api_key)の、どれで呼んでも上がります。
- API のクライアントに引き上げると、そのクライアントで取ったトークンで呼んだときに上がります。
- ユーザーとクライアントの両方に引き上げがあるときは、多いほうを使います。

## 一覧
期限が来たものは「期限切れ」と出して、使いません。一覧には残ります。期限の前にやめたいときは「削除」を押します。すぐに元の上限に戻ります。

追加と削除は、Exment のログ（`storage/logs`）に残ります。だれが・いつ・どの相手に・何回まで・いつまで・理由を書きます。

## .env の設定
| 設定 | 意味 |
|---|---|
| `EXMENT_API_MAX_RATE_LIMIT_CEILING` | 引き上げで入れられる 1 分の回数の最大です。SaaS の運営が決めます。空のとき（オンプレミス）は、最大はありません。あとで下げたときは、前に入れた引き上げも、この回数までしか効きません |
| `EXMENT_API_RATE_RAISE_MAX_HOURS` | 期限の最長（時間）です。はじめは 24 です |
