# API キー
ユーザーが自分で API キーを作り、プログラムや AI から、自分の権限で Exment の API を呼べます。OAuth のアクセストークンの代わりに、`Authorization: Bearer exk_...` として送ります。

※この機能は、Exment v7.2.1 以降で使えます。  
※はじめは「使わない」です。システム管理者が「設定：システム」→「[機能の管理](/ja/feature)」で「API キー」を使う設定にし、使える役割グループを選んでください。  
※OAuth のアクセストークン（[API設定](/ja/api)）は、今までどおり使えます。

## 自分のキーを作る
右上のユーザーメニューの「設定」の画面にある「API キー」から開きます（URL は `/auth/api_keys`）。システム管理者は、「API設定」の一覧からも開けます。

![API キー](img/api_key/api_key_mine.png)

| 項目 | 内容 |
|---|---|
| 名前 | キーの用途がわかる名前 |
| できること | 「読むだけ」（me・table_read・view_read・value_read・workflow_read・notify_read）か、範囲を選ぶ |
| テーブル | 見られるテーブル全部か、選んだテーブルだけ。選ぶと、そのテーブルの API と、自分の情報（me）だけを呼べます |
| つないでよい IP | 1 行に 1 つ（範囲も可）。空なら、どこからでも（サイト全体の API の IP 制限はそのまま効きます） |
| 期限 | 7・30・90（初め）・180・365 日 |
| クライアント証明書 | 証明書の SHA-256 の指紋を入れると、その証明書を付けたときだけ使えます（証明書は手前の Web サーバーが確かめます） |
| 現在のパスワード | 作るときに、いまのパスワードを入れます |

- **キーは作ったときに 1 回だけ表示します**。控えて、人に渡さないでください。あとから見ることはできません。
- キーでできるのは、**そのユーザーが画面でできることのうち、キーに選んだ範囲だけ**です。
- 使えるキーは、1 人 10 個までです。
- 一覧に、最後に使った日時・IP・回数が出ます。要らなくなったキーは、一覧から止めてください。

## キーを使う
~~~
curl -H "Authorization: Bearer exk_xxxxxxxx" https://(ExmentのURL)/api/data/(テーブル名)
~~~

※「/admin」が付いているサイトでは、`https://(ExmentのURL)/admin/api/...` です（[URLに含む「admin」](/ja/additional_prefix)）。

キーは、期限が過ぎたとき・止めたとき・ユーザーやログインを消したとき・使える役割グループから外れたとき・つないでよい IP や証明書と合わないとき・選んだテーブルの外を呼んだときに使えなくなります（理由は返しません）。

## システム管理者：すべてのキー
「API キー」の管理の画面（URL は `/api_keys`）で、このサイトのユーザーが作った API キーを見て、キーを 1 つ、またはユーザーのキーを全部、すぐに止められます。

![API キーの管理](img/api_key/api_key_admin.png)

- SSO の人は、IdP で止めても、期限か、ここで止めるまでキーが使えます。人がやめたときは「このユーザーのキーを全部止める」を使ってください。
- `.env` の `ADMIN_API_KEY_REQUIRE_CLIENT_CERT=true` で、すべてのキーにクライアント証明書を求められます。ロードバランサーなどの後ろでは、`ADMIN_TRUST_PROXY_IPS` を設定すると、本当の IP で比べます。
