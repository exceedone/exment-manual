# メンテナンスモード
データの移行やプラグインの導入のあいだ、システム管理者だけがサイトに入れるようにします。「設定：システム」→「メンテナンスモード」（URL は `/maintenance`）で切り替えます。

※この画面は、Exment v7.2.1 以降で使えます。  
※この画面を使えるのは、システム管理者だけです。「機能の管理」で「メンテナンスモード」を使う設定にしてください。

![メンテナンスモード](img/maintenance/maintenance1.png)

## メンテナンス中にできること
- 入れるのは、**システム管理者・メンテナンスを始めた人・「入れてよい IP アドレス」** だけです。
- ほかの人には、「お知らせの文」と終わりの予定を出したメンテナンスの画面が出ます（HTTP 503）。ログイン中の人はログアウトします。
- 始まりと終わり・変えたことは、操作ログに残ります。

## 設定
| 項目 | 内容 |
|---|---|
| 始まり | 空にすると予定なし（すぐ始めるときは「今すぐメンテナンスを始める」）。決めると、始まるまでログイン中の人に画面の上でお知らせします |
| 終わり | 過ぎると自動で終わります（置き忘れを防ぎます）。空にすると、終えるボタンを押すまで続きます |
| お知らせの文（ja・en） | メンテナンスの画面に出す文です |
| 入れてよい IP アドレス | 1 行に 1 つ。範囲（`192.168.0.0/24` など）も書けます。画面に、サーバーから見たあなたの IP アドレスが出ます |
| API（OAuth・API キー） | 「システム管理者だけ」「止める」「止めない」から選びます |
| 外からの画面を止める | 公開フォーム・共有リンク・安否確認の回答・LINE での承認と回答を止めます |
| 決まった時間の処理を止める | スケジュール・プラグインのバッチを止めます。終わったあとに 1 回だけ動きます（自動バックアップのように時刻を決めた処理は、次のその時刻まで待ちます） |
| キューを止める | メールなどの裏の処理を止めます。終わったら続きから動きます |

## コマンド
画面が開けないときや、サーバーの作業から切り替えるときは、コマンドも使えます。

~~~
php artisan exment:maintenance status
php artisan exment:maintenance on --until="2026-12-01 09:00" --message="メンテナンス中です" --allow-ip=192.168.0.0/24
php artisan exment:maintenance off
~~~

`php artisan down`（画面からの更新やリストアで使うもの）は、これとは別で、そのまま動きます。
