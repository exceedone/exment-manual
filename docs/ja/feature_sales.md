# 営業（CRM・SFA）
顧客・案件・見積・契約・活動の記録をまとめて管理するための、テーブル・ビュー・ダッシュボード・メニューなどを一度に入れる機能です。[機能の管理](/ja/feature)の 1 行です。

※この機能は、Exment v7.3.0 以降で使えます。  
※はじめは「使わない」です。使うにすると、下の「入るもの」がサイトに作られます。

## 使うにする
次のどちらかで使うにします。

- **機能の管理から**：システム管理者でログインし、「管理者設定」→「[機能の管理](/ja/feature)」を開きます。「Exment の機能」の「営業（CRM・SFA）」を「使う」にして、保存します。
- **初期設定画面から**：新しくインストールしたときの[初期設定画面](/ja/first_setting)の「機能」の欄で、「営業（CRM・SFA） を使いますか？」にチェックを入れます。初期設定を保存したあとに入ります。あとから「機能の管理」で使うにすることもできます。

入ると、「「営業（CRM・SFA）」の表・ビュー・ダッシュボード・メニューなどを入れました。使う人を役割グループに入れてください。」と出ます。  
つぎに、[役割グループ](/ja/role_group)の画面で、役割グループ「営業」に使う人を入れてください。

※「機能の管理」の「使える人」の欄には、「入れる役割グループで決めます（役割グループの画面）」と出ます。だれが使えるかは、この画面ではなく、役割グループ「営業」（テーブルの権限）で決めます。  
※「メニュー」の欄には、「入れるメニューは、メニューの画面で動かしたり、外したりできます。」と出ます。

## 入るもの

### テーブル
| テーブル | テーブル名 | 主な列 |
| --- | --- | --- |
| 顧客 | `sales_customer` | 顧客名・区分（見込み・取引中・取引終了）・住所・電話・メール・Web サイト・担当者 |
| 顧客の担当者 | `sales_customer_contact` | 氏名・部署・役職・電話・メール（顧客の中に入れます） |
| 案件 | `sales_deal` | 案件名・顧客・段階（問い合わせ・提案・見積・受注・失注）・見込み金額・受注予定日・確度・担当者 |
| 見積 | `sales_quote` | 件名・顧客・案件・見積日・有効期限・合計 |
| 見積明細 | `sales_quote_detail` | 品名・数量・単位・単価・金額（見積の中に入れます） |
| 契約 | `sales_contract` | 契約名・顧客・案件・契約日・開始日・終了日・自動更新・金額・契約書 |
| 活動の記録 | `sales_activity` | 種類（訪問・電話・メール・次の予定）・件名・日時・顧客・案件・担当者（はじめはログインしている人）・内容 |

### ビュー
- **段階ごとのかんばん**（案件）：案件を段階ごとに並べる[カンバンビュー](/ja/view_kanban)です。段階ごとに見込み金額の合計が出ます。カードを動かすと段階が変わります。
- ダッシュボードで使う集計・一覧のビュー（下のダッシュボードの 5 つ）

### 営業のダッシュボード
メニュー「営業・顧客」のいちばん上に「営業のダッシュボード」が入ります。次の 5 つが並びます。

- 月ごとの受注見込み（棒グラフ）
- 担当者ごとの案件（進行中）：件数と見込み金額
- 今月の活動
- 有効期限が近い見積（14 日）
- 終了日が近い契約（30 日）

### メニュー
メニュー「営業・顧客」が入ります。中は、営業のダッシュボード・顧客・案件・見積・契約・活動の記録です。[メニュー](/ja/menu)の画面で、動かしたり外したりできます。

### 通知
「契約の終了日が近い（30 日前）」：契約の終了日の 30 日前の 9 時に、その契約を作った人と、契約を見られる人に、Exment の中のお知らせで知らせます。日数などは[通知設定](/ja/notify)の画面で変えられます。

### 役割グループ「営業」
上の 7 つのテーブルの、すべてのデータを見て、作り、直せる役割グループです。使う人をここに入れます。

## 注意
- **途中で失敗したとき**：作れたものは、そのまま残ります。「「営業（CRM・SFA）」を入れられませんでした。もう一度「使う」にして保存してください。くわしくはログにあります。」と出て、「使わない」に戻ります。もう一度「使う」にして保存すると、足りないものだけを作ります。初期設定画面で失敗したときも、初期設定はそのまま終わります。あとで「機能の管理」から使うにしてください。
- **何度「使う」にしても**、同じものを 2 つ作ることはありません。サイトで変えたところ（テーブルやビューの名前、見出し、通知の日数、役割グループ、メニュー）も、そのまま残ります。
- **消したものは、また作られます**：テーブルやビューを消したあと、「使わない」にしてからもう一度「使う」にすると、消したものがまた作られます。要らないものは、消さずにメニューから外すなどしてください。
- **「使わない」にしても、何も消えず、何も隠れません**：テーブル・データ・ビュー・ダッシュボード・メニュー・通知・役割グループは、そのまま残り、メニューにも出たままです。使わないときは、[メニュー](/ja/menu)から外したり、役割グループから人を外したりしてください。
- **同じ名前のテーブルがあるとき**：サイトにすでに `sales_` で始まる同じ名前のテーブル（`sales_customer`・`sales_deal` など）があるときは、新しいテーブルは作らず、そのテーブルに足りない列を足します。今の列とデータは、そのまま残ります。
- **前に営業のテンプレートを入れたサイト**：前の[テンプレート](/ja/template)「営業パック」を入れたサイトでは、上の「同じ名前のテーブル」と同じく、足りないものだけが足されます。案件の列の名前は、前のまま「状態」です（新しく入れたサイトでは「段階」です）。変えたいときは、[カスタム列](/ja/column)の画面で変えてください。

## サーバーの設定で止める
サーバーの `.env` の `EXMENT_FEATURES_LOCKED` に `sales` を書くと、この機能は「使わない」に固定され、初期設定画面にも出ません。くわしくは[サーバーの設定で固定する](/ja/feature?id=サーバーの設定で固定する)をご覧ください。
