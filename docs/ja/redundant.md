# (上級者向け)冗長化
Web サーバーを 2 台以上にして、1 台が止まっても使えるようにすること（冗長化）があります。  
このページは、Exment を冗長化の構成で動かすときの手順です。

することは、次の 2 つです。

1. Web サーバーをそれぞれ用意し、追加のライブラリを入れる
2. `.env` ファイルで、ファイルの置き場所とセッションの管理方法を変える

## はじめに
本ページでは、以下のような構成を構築します。  


### 冗長化する際に考慮すること
Web サーバーが 1 台（シングル構成）のときと違い、次の 2 つを考える必要があります。

- **アップロードファイルを、Webサーバー以外の場所に配置する**  
画面からアップロードしたファイルを Web サーバーに置くと、もう 1 台の Web サーバーからは、そのファイルを開けません。  
そのため、Web サーバーとは別の場所にアップロードします。  
このページでは、AWS の S3 にアップロードします。  

- **セッション管理方法を変更する**  
Laravel の標準では、セッション（ログインの状態など）を、Web サーバーに置くファイルで管理します。  
冗長化すると、もう 1 台の Web サーバーにアクセスしたときにセッションがないので、ログインの状態が消えてしまいます。  
そのため、セッションの管理方法を変えます。  
このページでは、Redis を使います。


## 構築方法
### Webサーバー構築
Web サーバーを、それぞれ用意します。  
[通常のインストール方法](/ja/quickstart)でインストールすればよいのですが、次の 2 つだけ、追加で行ってください。

#### 追加ライブラリのインストール
composer で、次のライブラリを Web サーバーに入れてください。

~~~
# S3
composer require league/flysystem-aws-s3-v3

# Redis
composer require predis/predis
~~~

#### .envファイル修正
- .env ファイルを開き、次の設定値を追加・変更します。  

~~~
###ファイルアップロード管理
EXMENT_DRIVER_EXMENT=s3 #Exmentでファイルアップロードを行う先。s3に設定
AWS_ACCESS_KEY_ID=XXXXXX #AWSのS3のアクセスキー
AWS_SECRET_ACCESS_KEY=XXXXXX #AWSのS3のシークレットキー
AWS_DEFAULT_REGION=ap-northeast-1 #AWSのS3のリージョン
AWS_BUCKET=XXXXXX #AWSのS3のバケット名

###セッション管理
SESSION_DRIVER=redis #redisに書き換え
REDIS_HOST=127.0.0.1 #redisのホスト名
REDIS_PASSWORD=XXXXXX #redisのパスワード
REDIS_PORT=6379 #redisのポート番号
~~~
