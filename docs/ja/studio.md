# スタジオ
スタジオは、画面を作る・直す・まとめて見るための機能です。kintone のアプリのように、部品を並べるだけで、データの入れ物（テーブル）と入力の画面・一覧を作れます。作った画面は、スマホのアプリ（Exment アプリ）でも使えます。

※ここに書いた機能は、Exment v7.2.1 でそろいます。

## はじめに使う
- スタジオは、はじめは「使わない」です。システム管理者が「管理者設定」→「[機能の管理](/ja/feature)」で「スタジオ」を「使う」にすると、「管理者設定」の下に「スタジオ」のメニューが出ます（URL は `/studio`）。
- スタジオを開けるのは、機能の管理で選んだ人のうち、どれかのテーブルでテーブル・フォーム・ビューの設定の権限がある人と、システム管理者です。

| できること | 要る権限 |
| --- | --- |
| 新しいアプリ（テーブル）を作る | システムの「テーブル」の権限 |
| 今あるテーブルに画面を足す・スタジオで直す | そのテーブルのフォームの設定の権限 |
| ボタンを作る・直す画面で新しい項目（列）を足す | そのテーブルの設定の権限 |

## 画面の一覧
スタジオを開くと、サイトの画面を 1 つの画面でまとめて見られます。

| 欄 | 内容 |
| --- | --- |
| テーブルの画面 | テーブルごとに、入力の画面（フォーム）と一覧（ビュー）が並びます。「開く」「編集」「複製」と、「列の設定」「テーブルの設定」へのリンクがあります。上の欄で、テーブル名・画面名で絞り込めます。 |
| ダッシュボード（まとめの画面） | システムのダッシュボードと、ユーザーのダッシュボードです。 |
| プラグインのページ | ページのプラグインです。 |
| テーブルの関係図 | 親子（1対多）・多対多のリレーションと、ほかのテーブルを選ぶ列を、図で見られます。 |

- 入力の画面の名前（と鉛筆のアイコン）を押すと、[スタジオで直す](/ja/studio?id=スタジオで直す)の画面が開きます。今までのフォーム設定の画面は、歯車のアイコン（「フォーム設定で開く」）から開けます。
- 一覧に出るのは、自分が設定できるテーブルと、その中の設定できる画面だけです。

## 新しいアプリ・画面を作る
一覧の「新しいアプリ・画面」を押します。作り方は 3 つです。

| 作り方 | 内容 |
| --- | --- |
| 新しいアプリを作る | 部品を並べると、テーブルと列・入力の画面・一覧ができます。選べば、カンバン・カレンダー・グラフ・ダッシュボードもまとめてできます（[アプリとしてまとめて作る](/ja/studio?id=アプリとしてまとめて作る)）。 |
| 今あるテーブルに画面を足す | テーブルは作りません。今ある列を並べて、入力の画面（フォーム）だけを作ります。 |
| Excel・CSV から作る | Excel（.xlsx）か CSV を読み込むと、1 行目を項目名、2 行目からをデータとして、部品を推測して並べます。違うところは直してから保存します。「データも取り込む」にすると、データも一緒に入ります（1,000 行まで、ファイルは 10MB まで）。 |

保存の前に、何ができるか（「保存すると、アプリ『○○』（テーブル・入力の画面・一覧）ができます。」など）が出ます。保存すると、作った画面でデータを入力できます。

### 部品
| 部品 | 内容 |
| --- | --- |
| 1行テキスト・複数行テキスト・URL・メールアドレス | 文字を入れます。 |
| 整数・小数・通貨 | 数を入れます。 |
| 計算 | ほかの数の項目から計算します（下の「計算」）。 |
| 日付・日付と時刻・時刻 | 日付や時刻を入れます。 |
| 選択肢・YES/NO | 決まった中から選びます。選択肢は 1 行に 1 つずつ書きます。 |
| 選択肢 (他のテーブルの値一覧から選択) | ほかのテーブルのデータを選びます。「選ぶ元のテーブル」を決めます。 |
| ユーザー・組織 | Exment のユーザーや組織を選びます。 |
| 自動採番 | 保存すると、日付と番号（例：20261121-0001）が自動で付きます。 |
| ファイル・画像 | ファイルや画像を添付します。 |

- 部品を押すと最後に足し、ドラッグすると好きな場所に入れられます。項目は 100 個まで置けます。
- 項目ごとに、項目名・列名（英数字）・必須を決めます。

### 行と列の並び
行ごとに「1 列」「2 列」「2 列（左が広い）」「2 列（右が広い）」「3 列」「4 列」を選ぶと、項目を横に並べられます。スマホでは縦に並びます。行は 50 行まで作れます。

### 表示の条件
項目ごとに、ほかの項目の値で表示を切り替えられます（「と同じとき」「と違うとき」「が空のとき」「が空でないとき」）。たとえば、状態が「保留」のときだけ「理由」を出します。必須の項目には条件を付けられません。

### 明細（子テーブル）
注文の中の商品のように、1 件のデータに何行も入力する明細を作れます。明細ごとに子テーブルができ、入力の画面の下に表の形で出ます。明細は 5 個まで作れます。明細の中でも、計算・ほかのテーブルから選ぶ部品を使えます。

### 計算
計算の部品では、ほかの数の項目（整数・小数・通貨・計算）を `[ ]` で囲んで書きます。

- 例：`[数量] * [単価]`
- 明細の合計：`合計[明細の名前.項目]`（例：`合計[注文明細.金額]`）
- 使えるのは、項目・数・`+ - * / ( )` だけです。

### ボタン
データの画面に出るボタンを作れます。押すと、項目の値を変えます（例：「完了にする」を押すと、状態が「完了」に）。

- 1 つの画面で 5 個まで作れます。変えられる項目は、選択肢・YES/NO・1行テキスト・整数です。
- もうその値になっているデータには、ボタンは出ません。
- ボタンは、テーブルの「[データ更新設定](/ja/operation)」として作られます。あとからそこで直したり消したりできます。
- ボタンを作れるのは、そのテーブルの設定の権限がある人だけです。

### くわしい設定
- **テーブル名（英数字）**：データの URL などに使う名前です。空のときは自動で付けます。あとから変えることはできません。
- **メニューに追加する場所**：左のメニューのどこに足すかを選びます（「追加しない」も選べます）。

## アプリとしてまとめて作る
「新しいアプリを作る」では、「アプリとして一緒に作るもの」の欄で、データを見る画面も一緒に作れます。

| 作るもの | 使う項目 |
| --- | --- |
| カンバン | 列に分ける項目（選択肢） |
| カレンダー | 日付の項目（カレンダーで探せるように、その項目の検索インデックスをオンにします） |
| グラフ（件数） | 分ける項目（選択肢・YES/NO）ごとの件数 |
| ダッシュボード | 一覧・グラフ・カレンダーを並べます。システム管理者が作ると全員に、ほかの人が作ると自分だけに見えます。 |

- 使える項目を置くと、自動でオンになります。外すこともできます。
- どれも、ビュー・ダッシュボードの設定の画面で作るのと同じものです。あとから、その画面で直せます。

## スタジオで直す
スタジオで作った入力の画面（と、今あるテーブルのフォーム）を、作ったときと同じ画面で直せます。画面の一覧で、入力の画面の名前を押します。直せるのは、そのテーブルのフォームの設定の権限がある人です。

- 項目を動かす・外す、表示の条件を付ける・外す、画面の名前を変える、ボタンを足すことができます。
- 画面から外した項目も、テーブルの列とデータはそのまま残ります。
- 「新しい項目（テーブルに列もできます）」から部品を足すと、保存したときにテーブルに列ができ、一覧にも出ます。これができるのは、テーブルの設定の権限がある人だけです。計算の部品は、ここでは足せません（列の設定で足します）。
- 見出し・説明文・HTML・画像・罫線・システムの項目など、スタジオにまだない項目は消さずに残ります。動かす・外すことはでき、中身はフォーム設定で直します。
- 明細（子テーブルの入力）はそのまま残ります。明細を直すときは、フォーム設定で開いてください。
- 保存の前に、何が変わるか（「テーブル『○○』に、列『○○』もできます。」など）が出ます。

## スマホのアプリ（Exment アプリ）
スマホのブラウザーで `/app` を開くと、スタジオの画面をスマホのアプリとして使えます。「ホーム画面に追加」すると、アプリのように開けます。

- **画面**：使えるテーブルの入力の画面が並びます。開くと一覧が出て、右下の「+」で新しく登録できます。
- **写真・ファイル**：ファイル・画像の項目では、その場で写真を撮って付けられます。写真は、スマホの中で小さくしてから送ります。
- **コードを読み取る**：上のボタンから、カメラで QR コード・バーコードを読み取れます。Exment の二次元バーコード（[二次元バーコード設定](/ja/2d_barcode)）や、データの URL の QR コードなら、そのデータが開きます。一覧の画面から読むと、そのテーブルの文字・整数・自動採番の列が同じデータを探します。JAN コードも探せます。
- **電波がないとき**：保存のときに電波がなければ、入力（明細・写真も）をスマホの中に下書きとして取っておき、アプリを開いたときや電波が戻ったときに自動で送ります。一度開いた画面は電波がなくても開けるので、新しく入力もできます。「送っていない下書き」の一覧から、開いて直す・今すぐ送る・消すができます。サーバーが受け付けなかった下書きは、理由を出して残します。下書きはユーザーごとです。
- 「PC 版」で、いつもの画面に戻れます。
