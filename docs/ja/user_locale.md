# ユーザーごとの言語とタイムゾーン
v7.2.4 から、ユーザーごとに、画面の言語とタイムゾーンを選べます。メールと通知も、受け取る人の言語とタイムゾーンで届きます。

## 言語を選ぶ
言語は、次のどこからでも選べます。

- 右上のユーザーメニュー
- ログインユーザー設定（右上のユーザーメニュー →「ログインユーザー設定」）の「言語」
- ログインの画面

選べる言語は、日本語・English・Tiếng Việt・简体中文・한국어・Deutsch・Español です。  
※ベトナム語・中国語（簡体字）・韓国語・ドイツ語・スペイン語の画面は、機械翻訳です。直したほうがよいところは、[GitHub](https://github.com/exceedone/exment/issues) で教えてください。  
※管理者は、ユーザーが選べる言語をしぼれます（下の「管理者の設定」）。

### 使う言語の順番
Exment は、次の順番で言語を決めます。

1. ユーザーがログインユーザー設定で選んだ言語
1. ログインの画面で選んだ言語
1. ブラウザーの言語（システム設定の「ユーザーが言語を選んでいないとき、ブラウザーの言語を使う」が YES のとき。ユーザーが選べる言語の中から）
1. サイトの言語

ログインユーザー設定の「言語」で「自動（ブラウザーの言語）」を選ぶと、言語を選んでいない状態に戻ります。

> [!WARNING]
> v7.2.4 に更新すると、言語を選んでいないユーザーのうち、ブラウザーの言語がサイトの言語とちがう人には、ブラウザーの言語で画面が出ます。  
> 全員をサイトの言語のままにするときは、システム設定 →［詳細設定］の「ユーザーが言語を選んでいないとき、ブラウザーの言語を使う」を NO にしてください。

## タイムゾーンを選ぶ
タイムゾーンは、ログインユーザー設定の「タイムゾーン」で選びます。初期値は「サイトのタイムゾーン」です。

選んだタイムゾーンで、日時を表示し、入力します。対象は、一覧・詳細・フォーム・「今日」などのフィルター・カレンダー・ガントチャート・カンバン・コメント・更新履歴・通知・操作ログです。

### サイトのタイムゾーンのままのもの
- データベースには、サイトのタイムゾーンで保存します。
- 日付だけの列（時刻のない日付）は、変えません。
- API は、サイトのタイムゾーンのままです。
- 日時でまとめたグラフ（集計のビューやダッシュボード）は、サイトの時刻でまとめます。グラフには「（サイトの時刻: Asia/Tokyo）」のように出ます。
- エクスポートは、初期値ではサイトのタイムゾーンです。「あなたのタイムゾーン（…）の日時でエクスポート」を選ぶと、自分のタイムゾーンで書き出せます。
- インポートでは、「ファイルの日時のタイムゾーン」で、ファイルの日時がサイトのタイムゾーンか自分のタイムゾーンかを選びます。

## メールと通知
メールと通知は、受け取る人の言語とタイムゾーンで送ります。受け取る人が言語を選んでいないときは、サイトの言語です。

## 管理者の設定
システム設定 →［詳細設定］で設定します（[システム設定](/ja/system_setting)）。

| 項目 | 内容 | 初期値 |
| --- | --- | --- |
| ユーザーが選べる言語 | ユーザーが右上のメニュー・ログインの画面・ログインユーザー設定で選べる言語です。空欄のときは、入っているすべての言語を選べます。サイトの言語は、いつでも選べます。 | 空欄（すべて） |
| ユーザーが言語を選んでいないとき、ブラウザーの言語を使う | YES にすると、言語を選んでいないユーザーには、ブラウザーの言語（ユーザーが選べる言語の中から）で画面を出します。NO にすると、サイトの言語で出します。 | YES |

サイトの言語とタイムゾーンは、これまでどおり `.env` の `APP_LOCALE` と `APP_TIMEZONE` で決めます。
