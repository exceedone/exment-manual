# PHP設定値変更

PHP の設定値を変える手順です。次の 4 つを変えられます。

| 設定 | 変えると、どうなるか |
| ---- | ---- |
| ファイルアップロード上限サイズ変更 | 画面からアップロードできるファイルの大きさが変わります |
| メモリ量変更 | Exment(PHP) が使うメモリの量が変わります |
| タイムアウト時間変更 | 時間のかかる処理が、途中で止まりにくくなります |
| 一度にPOSTできる上限数 | 項目の多い画面でも、保存できるようになります |

変えかたは、下の「[設定方法](/ja/additional_php_ini?id=設定方法)」をご覧ください。


#### ファイルアップロード上限サイズ変更
Exment には、画面からファイルをアップロードする機能があります。  
アップロードできるファイルの大きさには、サーバーごとに上限があります。  
（はじめの上限は、インストールしたサーバーによって違います）  

#### メモリ量変更
Exment(PHP) が使うメモリの量を変えます。  
メモリの量が大きいほど、処理が速くなったり、一度に実行できる内容が変わったりします。ただし、大きすぎると、サーバーの動作に影響することがあります。

#### タイムアウト時間変更
PHP のタイムアウト時間（処理を打ち切るまでの時間）を変えます。  
時間を長くすると、インポート・エクスポート・バックアップなど、時間のかかる機能を、より確実に実行できます。  
※時間のかかる機能には、タイムアウト時間を伸ばす処理を、はじめから Exment のコードにも入れています。ただし、環境によっては、この処理が効かないことがあります。タイムアウトがたびたび起きるときに、この設定を行ってください。

#### 一度にPOSTできる上限数
一度に POST できる（画面から送れる）項目の数の上限を決めます。  
データを入力する画面で、項目の数が上限をこえると、正しく動かないことがあります。  
※おもに、次の画面で、上限が足りずにエラーになることがあります。  

- ワークフロー利用設定で、テーブル数・ワークフロー数が多いとき
- カスタムフォーム設定画面で、登録する列の項目がとても多いとき
- カスタムデータ入力画面で、項目がとても多いとき




## 設定方法
設定方法 1・2 の、どちらかで設定してください。


### 設定方法1 php.ini修正

1. PHP をインストールしたフォルダにある、「php.ini」ファイルを開きます。※php.ini ファイルの場所は、環境によって違います。

2. php.ini ファイルの、次の値を直します。※すでに数値が入っていることが多いので、数値を書きかえてください。

~~~
### ファイルアップロード上限サイズ変更
#POSTデータに許可される最大サイズ
post_max_size=20M
#1つのファイルアップロードに許可される最大サイズ
upload_max_filesize=20M


### メモリ量変更
# 512Mに変更する場合
memory_limit=512M
# 無制限に変更する場合
memory_limit=-1


### タイムアウト時間変更
#240秒に変更する場合
max_execution_time=240
#無制限に変更する場合
max_execution_time=0


### 一度にPOSTできる上限数変更
#3000件に変更する場合
max_input_vars=3000
~~~

3. サーバーを再起動します。


### 設定方法2 .htaccessファイル修正
1. Exment をインストールしたフォルダの、「public/.htaccess」ファイルを開きます。

2. 次の値を追加します。

~~~
### ファイルアップロード上限サイズ変更
#POSTデータに許可される最大サイズ
php_value post_max_size 20M
#1つのファイルアップロードに許可される最大サイズ
php_value upload_max_filesize 20M


### メモリ量変更
# 512Mに変更する場合
php_value memory_limit 512M
# 無制限に変更する場合
php_value memory_limit -1


### タイムアウト時間変更
#240秒に変更する場合
php_value max_execution_time 240
#無制限に変更する場合
php_value max_execution_time 0


### 一度にPOSTできる上限数変更
#3000件に変更する場合
php_value max_input_vars 3000
~~~

3. サーバーを再起動します。
