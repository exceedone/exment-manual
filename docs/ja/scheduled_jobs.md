# 決まった時間の処理
サーバーの cron（`php artisan schedule:run`）が、決まった時間に動かす処理の一覧です。「設定：システム」→「決まった時間の処理」（URL は `/scheduled_jobs`）で開きます。

※この画面は、Exment v7.2.6 以降で使えます。  
※この画面を見られるのは、システム管理者だけです。

## 使い始める
[機能の管理](/ja/feature)で「決まった時間の処理」を「使う」にします。はじめは「使わない」です。使わないときは、この画面は開けません（404 になります）。

処理の記録は、使っているあいだだけ残します。

## cron の状態
最後に `schedule:run` が動いた時刻を出します。10 分以上動いていないときは、注意を出します。そのときは、通知・自動バックアップ・プラグインのバッチなどが止まっています。サーバーの cron に、次の 1 行を入れてください（[チューニング](/ja/tuning)でも確かめられます）。

~~~
* * * * * cd /var/www/exment && php artisan schedule:run >> /dev/null 2>&1
~~~

## 処理の一覧
| 項目 | 出すもの |
|---|---|
| 処理 | Exment の処理の名前と、コマンド（プラグインのバッチは「プラグインのバッチ：名前」） |
| 動く時間 | 「5 分おき」「毎時」「毎日 3:30」のように、ことばで出します |
| 次に動く時刻 | あなたのタイムゾーンで出します |
| 状態 | 動かさない処理は、理由も出します（例：「安否確認」を使っていない） |
| 最後の実行・最近の記録 | 始まり・終わり・かかった時間・結果・終了コード・実行した人・出力の最後の 4KB |

処理ごとに、最近の 20 回の記録を残します。回数は `.env` の `EXMENT_SCHEDULED_JOBS_KEEP_RUNS` で変えられます。

## 続けて失敗したとき
3 回続けて失敗した処理は、赤で出します。システム管理者には、画面の上のお知らせとメールで、1 回だけ知らせます。成功すると元に戻り、また続けて失敗したときに知らせます。回数は `.env` の `EXMENT_SCHEDULED_JOBS_ALERT_FAILURES` で変えられます。

## 今すぐ実行
「今すぐ実行」を押すと、その処理をすぐに裏で動かします。動いている処理は、重ねて動かせません。

ただし、重なりを止める設定のない処理（毎時の `exment:schedule` や、プラグインのバッチ）は、決まった時間の実行のほうが「今すぐ実行」を待ちません。動く時刻（毎時ちょうどなど）のすぐ前に押すと、2 つが同時に動くことがあります。動く時刻の近くでは押さないでください。

次のときは、ボタンを押せません（理由を出します）。サーバーの cron は、そのときも処理を動かします。
- PHP から外のコマンドを動かせないサーバー（`proc_open` が使えないレンタルサーバーなど）
- デモの環境

## コマンド
~~~
php artisan exment:schedule-status          # 一覧を表で出します
php artisan exment:schedule-status --json   # 処理ごとの最後の実行と、続けて失敗した回数を JSON で出します
~~~

SaaS では、テナントごとに、そのテナントの処理と記録だけを出します。
