# Exmentで業務を開始するまでの流れ
Exment を入れてから、業務で使い始めるまでの流れです。  
だれが・何をするかを、役割ごとにまとめています。

### 役割
Exment にかかわる人の役割は、次の 4 つです。それぞれの担当者が、Exment の設定を行います。  
※会社によっては、インフラ担当者が管理者もかねるなど、1 人がいくつかの役割を持つこともあります。

- ##### インフラ担当者  
→Exment をサーバーにインストールする・アップデートするなど、サーバーまわりの作業をする人

- ##### 管理者  
→インストールのあとの初期設定や、テーブル・列の追加など、Exment を使うための設定をする人

- ##### ユーザー(一般ユーザー)  
→管理者が用意したテーブルを使って、データを登録・編集・削除する人

- ##### 開発者  
→プラグインを使うときなど、特別な機能が必要になったときに、Exment を拡張する開発をする人  

### ステップ

#### 【インフラ担当者】
- [インストール](/ja/quickstart)  
サーバーに Exment をインストールします。  

- [アップデート](/ja/update)  
Exment の新しい版が出たときに、サーバーにログインして、アップデートします。  

#### 【管理者】
- [初期設定](/ja/first_setting)  
インストールのすぐあとに、サイト名や、最初の管理者のログイン ID など、必要な項目を登録します。

- [カスタムテーブル設定](/ja/table)  
「顧客管理」「タスク管理」など、管理したいものをテーブルとして登録します。  

- [カスタム列設定](/ja/column)  
「顧客管理」テーブルの「顧客名」「郵便番号」「住所」など、管理したい項目を列として登録します。

- [テンプレート](/ja/template)  
用意されているテンプレートを使うと、カスタムテーブル・カスタム列を 1 から作らずに、まとめて追加できます。

##### ■その他、必要な設定

- [ユーザー・ログインユーザー](/ja/user)  
一般ユーザーが Exment にログインするための、ID・パスワードを設定します。

- [役割・権限](/ja/permission)  
ユーザーごとに、Exment で操作できる範囲を決めます。

- [メニュー](/ja/menu)  
画面の左にいつも出ている、メニューの項目を管理します。  

#### 【ユーザー(一般ユーザー)】
- [データ](/ja/data)  
管理者が設定したカスタムテーブルに、データを追加・更新・閲覧・削除します。  

- [検索](/ja/search)  
登録したデータを、かんたんに検索できます。  


#### 【開発者】
- [プラグイン](/ja/plugin_quickstart)  
Exment の機能を拡張する必要があるときに、プラグインをアップロードして、機能を足せます。
