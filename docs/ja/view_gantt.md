# ガントチャートビュー

データを、開始日から期限日(終了日)までの横棒（バー）にして、時系列に表示するビューです。

## ガントチャートビューとは

ガントチャートとは、作業ごとの期間を横棒で表し、日付の目盛りの上に並べて表示する図です。  
どの作業がいつからいつまでの予定か、今日の時点でどの作業が期限を過ぎているかが一目で分かります。

Exment のガントチャートビューでは、次のことができます。

- 1件のデータを、開始日の列から期限日(終了日)の列までの1本のバーで表示する
- 選択肢の列の値ごとに、バーを色分けする
- 進捗率をバーの中に重ねて表示し、期限を過ぎても完了していないデータを赤枠で強調する
- 選択肢やマイルストーン（他のテーブルの値一覧から選択）ごとに行をグループ化し、マイルストーンの期限を◆マークで表示する
- 親子関係のあるデータを、親の下に字下げして表示する
- 担当者をアイコンで表示する

※ガントチャートは表示専用です。チャート上でバーをドラッグして日付を変更することはできません。日付などを変更する場合は、データの編集画面から変更してください。

## ビューの新規追加

1. カスタムビュー設定画面を開きます（[カスタムビュー](/ja/view.md)を参照）。
2. 右上の［新規］ボタンをクリックします。
3. 表示されたダイアログから「ガントチャートビュー新規作成」を選択します。

データ一覧画面の［ビュー］ボタンのメニューからも、「ガントチャートビュー新規作成」を選択できます。この場合、保存後にそのビューでデータ一覧が表示されます。

※テーブルに「日付」または「日付と時刻」の列が1つもない場合、「ガントチャートビュー新規作成」は表示されません。

#### ビュー表示名・ビュー権限・既定・ビューの情報ボックスを使用する
[ビューの設定項目](/ja/view.md?id=ビューの設定項目)と同様の設定項目になります。

## 基本設定

#### 開始日の列
バーの開始位置になる日付列です。（必須）  
※「日付」「日付と時刻」の列のみ指定できます。「日付と時刻」の列は、日付の部分のみを使用します。

#### 期限日(終了日)の列
バーの終了位置になる日付列です。（必須）  
バーは、開始日から期限日まで（両方の日を含む）表示されます。  
※「日付」「日付と時刻」の列のみ指定できます。  
※期限日が今日より前で、進捗率が100未満のデータは「期限超過」として、バーが赤枠で、行の左側の期限日が赤字で表示されます。「進捗率の列」を設定していない場合や、進捗率が未入力の場合も、期限超過として扱います。

#### バーの色分け(選択肢の列)
この列の値ごとに、バーを色分けします。チャートの上部に、値と色の凡例が表示されます。  
※「選択肢」「選択肢 (値・見出しを登録)」の列のみ指定できます。複数選択の列の場合は、1つ目の値で色分けします。  
※色は、その列の「値ごとの色」（列に設定した[表示プリセット](/ja/cell_style_preset.md)を含む）をそのまま使用します。色を指定していない値には、選択肢の並び順に応じた色が自動で割り当てられます。  
※設定しない場合、すべてのバーが青色で表示されます。

#### 進捗率の列(0〜100)
バーの中に、進捗率(%)の分だけ濃い色を重ねて表示します。  
※「整数」「小数」「通貨」の列のみ指定できます。  
※値は0〜100として扱います。0未満は0、100を超える値は100として表示します。

## 高度な設定

#### グループ化する列
この列の値ごとに、行をグループ化して表示します。指定しない場合、グループ化せずに表示します。  
※「選択肢」「選択肢 (値・見出しを登録)」「選択肢 (他のテーブルの値一覧から選択)」の列（複数選択でないもの）のみ指定できます。

グループの並び順は、次のとおりです。

| 列の種類 | 並び順 |
| --- | --- |
| 選択肢、選択肢 (値・見出しを登録) | 選択肢の並び順 |
| 選択肢 (他のテーブルの値一覧から選択) | 参照先データの期限が近い順。期限のないものは最後 |

- 「選択肢 (他のテーブルの値一覧から選択)」の列（マイルストーンのテーブルを参照する列など）を指定した場合、参照先データの期限を、グループの見出し行と、チャート上の◆マークで表示します。
- 値が未入力のデータは、最後に「未分類」グループとして表示されます。
- データが1件もない値のグループは表示されません。

※参照先データの期限には、参照先テーブルの日付列（「日付」「日付と時刻」）のうち、列名に「due」「end」「limit」「deadline」「期限」のいずれかを含む最初の列を使用します。該当する列がない場合は、最後の日付列を使用します。日付列がない場合、◆マークは表示されません。

#### 親子関係の列(自テーブル参照)
自テーブルを参照する列を選ぶと、子のデータを親のデータのすぐ下に「└」を付けて字下げして表示します。  
※「選択肢 (他のテーブルの値一覧から選択)」の列のうち、参照先がこのテーブル自身である列のみ指定できます。  
※字下げされるのは1階層のみです。孫以降のデータは、グループの最後に字下げなしで表示されます。  
※親のデータが同じグループに表示されていない場合、子のデータは通常の行として表示されます。

#### 担当者の列
ユーザー列を選ぶと、各行に担当者のアイコン（ユーザー名の1文字目）を表示します。アイコンにマウスを乗せると、ユーザー名が表示されます。  
※「ユーザー」の列、または参照先がユーザーテーブルの「選択肢 (他のテーブルの値一覧から選択)」の列のみ指定できます。複数選択の列の場合は、1人目を表示します。

#### 最大表示件数
チャートに表示するデータの最大件数です（10〜2000、初期値500）。  
※未入力の場合や、範囲外の値の場合は、500件として扱います。  
※表示条件に一致するデータがこの件数を超えた場合、「表示件数が上限(○件)を超えています。表示条件で絞り込んでください。」と表示され、超えた分のデータは表示されません。

## データ並べ替え・データ表示条件

[ビューの設定項目](/ja/view.md?id=ビューの設定項目)の「データ並べ替え」「データ表示条件」と同様の設定項目になります。  
「データ表示条件」で、チャートに表示するデータを絞り込みます。

※チャート上の行は、「データ並べ替え」の設定に関わらず、各グループ内で開始日の早い順に表示されます（開始日が未入力のデータは最後）。「データ並べ替え」は、データが「最大表示件数」を超えた場合に、どのデータを表示するかの順序に使用されます。

## チャートの使い方

### 画面の見方

#### ツールバー

| 場所 | 内容 |
| --- | --- |
| 左側 | 凡例です。「バーの色分け」の値と色、今日を表す「│ 今日」、マイルストーンの期限がある場合は「◆ 期限」が表示されます。 |
| 右側 | データ一覧画面と同じ［ビュー］ボタン、テーブルのメニュー、［新規］ボタンが表示されます（権限に応じて表示されます）。 |

#### 行の左側

各行の左側に、バーの色・データの見出し・担当者のアイコン・期限日（月/日）が表示されます。

- データの見出しは、データの詳細画面へのリンクです。
- 担当者のアイコンは、「担当者の列」を設定している場合のみ表示されます。
- 期限日が未入力のデータは「—」と表示されます。期限超過のデータは赤字で表示されます。
- 左上の見出しには、「グループ化する列」の名前が表示されます。

#### 日付の目盛り

- 上段に年月（例：2026/10）、下段に各週の月曜日の日付（例：10/19）が表示されます。幅が狭い場合、週の日付は1週おきに表示されます。
- 土曜日・日曜日は、背景が薄い灰色で表示されます。
- 今日の位置に、赤い縦線と「今日」が表示されます。
- 表示する期間は、表示するデータの開始日・期限日、マイルストーンの期限、今日を含むように自動で決まります。前後に数日の余白を付け、月曜日から日曜日の単位でそろえます。
- 1日あたりの幅は、画面の幅に合わせて自動で調整されます（拡大・縮小の切り替えはありません）。期間が長い場合は、横にスクロールして表示します。
- 画面を開いたときは、今日の日付が見える位置まで自動でスクロールします。

※今日から約3年以上離れた日付は、表示期間を広げる対象になりません。その場合、バーは表示期間の端で切れて表示されます。

#### バー

- 開始日から期限日までのバーが表示されます。
- 「進捗率の列」を設定している場合、進捗率の分だけ、バーの中に濃い色が重ねて表示されます。
- 期限超過のデータは、バーの周りが赤枠になります。
- バーにマウスを乗せると、データの見出し・期間（開始日 ~ 期限日）・進捗率・担当者名が表示されます。

※開始日または期限日が未入力のデータは、バーは表示されず、行の左側のみ表示されます。

#### グループの見出し行

「グループ化する列」を設定している場合、グループごとに見出し行が表示されます。

- 見出し行には、グループ名・件数、（マイルストーンの場合は）期限日が表示されます。
- 見出し行をクリックすると、そのグループの行を折りたたみ／展開できます。

### データを開く

バー、または行の左側のデータの見出しをクリックすると、そのデータの詳細画面へ移動します。

### 表示されるメッセージ

| メッセージ | 内容 |
| --- | --- |
| ガントチャートの表示には「開始日の列」と「期限日(終了日)の列」の設定が必要です。ビュー設定画面で日付列を選択してください。 | 「開始日の列」「期限日(終了日)の列」が設定されていない、または指定した列が日付列でなくなった（削除された）場合に表示されます。 |
| 表示件数が上限(○件)を超えています。表示条件で絞り込んでください。 | 表示条件に一致するデータが「最大表示件数」を超えた場合に表示されます。 |
| 表示するデータがありません。 | 表示するデータが1件もない場合に表示されます。 |

## 注意事項

- ガントチャートは表示専用です。バーのドラッグや、チャート上での編集はできません。
- 表示されるのは、ログインユーザーが閲覧できるデータのみです。
- ビューの設定画面の［プレビュー］ボタンで、保存前に表示内容を確認できます（[カスタムビュー](/ja/view.md?id=プレビュー)を参照）。
- ダッシュボードの「データ一覧」「チャート」では、ガントチャートビューは選択できません（[ダッシュボード](/ja/dashboard.md)を参照）。
