# 削除済データ
削除したデータを一覧で見て、元に戻す（復元）・完全に削除する、の操作をする画面の説明です。

- 削除済データを表示できるのは、削除データの表示権限を持つユーザーだけです。
- 編集権限のあるユーザーは、データの復元や完全削除ができます。  

※権限について、くわしくは[役割グループ](/ja/role_group.md)をご覧ください。

## 一覧表示
![データ画面](img/data/deleted_data1.png)  

1. データ一覧画面の左上［フィルタ］の右横にある▼マークから、「削除済データ」を選びます。
2. 表示が変わり、そのテーブルの削除済データが一覧で出ます。

![データ画面](img/data/deleted_data2.png)  


## 詳細表示

- 削除済データ一覧にあるデータは、詳細を表示できます。  
- 表示したいデータの行、または操作列にある表示アイコンをクリックしてください。

![データ画面](img/data/deleted_data3.png)  

- データ詳細画面では、削除ユーザーと削除日時を確かめられます。

![データ画面](img/data/deleted_data4.png)  

## 復元

- 削除済データは、データ一覧画面へ戻せます（復元）。
- 復元の方法は３つあります。
    - データ詳細画面にある［復元］ボタンを使う。
    ![データ画面](img/data/deleted_data5.png)  
    - 削除済データ一覧画面で、操作列にある［復元］アイコンを使う。
    ![データ画面](img/data/deleted_data6.png)  
    - 削除済データ一覧画面で、復元したいデータにチェックを入れ、削除済データ画面の左上にある▼マークから、「復元」を選ぶ。
    ![データ画面](img/data/deleted_data7.png)  

※データを復元できるのは、そのデータの編集権限が付いているユーザーだけです。


## 完全に削除

- 削除済データは、完全に削除できます。完全に削除したデータは、削除済データ一覧からも消えます。
- 完全に削除する方法は３つあります。
    - データ詳細画面にある［完全に削除する］ボタンを使う。
    ![データ画面](img/data/deleted_data8.png)  
    - 削除済データ一覧画面で、操作列にある［完全に削除する］アイコンを使う。
    ![データ画面](img/data/deleted_data9.png)  
    - 削除済データ一覧画面で、完全に削除したいデータにチェックを入れ、削除済データ画面の左上にある▼マークから、「完全に削除する」を選ぶ。
    ![データ画面](img/data/deleted_data10.png)  

※データを完全に削除できるのは、そのデータの編集権限が付いているユーザーだけです。


## データ一覧画面に移動

- 削除済データ一覧の画面で、［削除済データ▼］をクリックして「取消」を選ぶと、そのテーブルのデータ一覧画面に移ります。

![データ画面](img/data/deleted_data11.png)  


#### 権限設定
- 削除済データを表示するには、そのデータの表示権限がユーザーに必要です。
- 削除済データを復元する・完全に削除するには、そのデータの編集権限がユーザーに必要です。

※権限の設定については、[役割グループ](/ja/role_group.md)をご覧ください。
