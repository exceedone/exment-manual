# ログイン設定
Exment にログインするときのルールを決めるページです。パスワードのルール（パスワードポリシー）と、2段階認証を設定できます。  
コマンドでパスワードをリセットする方法も、このページにあります。

> SSOに関する設定・説明は、[こちら](/ja/login_sso)をご確認ください。


## 2段階認証
Exment は、2段階認証に対応しています。  
ユーザー情報を入力してログインしたあと、Eメールで届いたコードか、Google認証システムに出るコードを入力すると、Exment を使えるようになります。  
※2段階認証は、ログイン方式が「標準」「LDAP」の場合に利用できます。

- [2段階認証 システム設定](/ja/login_2factor_setting)
- [ログイン(2段階認証)](/ja/login_2factor)


## ログイン設定管理方法

- システム管理者が、次の URL を開きます。  
http(s)://(ExmentのURL)/login_setting  
※上記で記載の「システム設定変更」を行うことで、アクセスが出来るようになります。

> ※URL は、「/admin」が付かない標準の設定（v7.2.1 以降に新しくインストールしたサイト）の場合です。`.env` の `ADMIN_ROUTE_PREFIX` に値がある場合（前の版で入れたサイトは「admin」）は、サイトの URL のあとにその値を足してください（例：`http(s)://(ExmentのURL)/admin/oauth/token`）。詳しくは[URLに含む「admin」の変更・削除](/ja/additional_prefix)をご覧ください。

- v7.1.0以降は、左メニューの「管理者設定」→「ログイン設定」からも開けます。
- v7.0以前は、「ログイン設定」は、はじめはメニューに出ません。メニューに足すには、「管理者設定」 > 「メニュー」ページを開き、メニュー種類「システムメニュー」を選びます。対象に「ログイン設定」が出ますので、選んで保存してください。

![ログイン設定一覧](img/login/login_setting4.png)  

- 2段階認証の設定は、次のページの手順で行います。

    - [2段階認証 システム設定](/ja/login_2factor_setting)


### パスワードポリシー設定
ログインのパスワードについてのルールを決めます。   

![パスワードポリシー設定画面](img/system_setting/system_setting_password.png)  

#### 複雑なパスワード
- YES にすると、パスワードは、3種類以上の文字種（半角英大文字、半角英小文字、半角数字、半角記号）を含んだ12文字以上にする必要があります。
- 初期値は「NO」です。

#### 有効日数
- 決めた日数がすぎたあと、はじめてログインしたときに、パスワード変更画面が出ます。パスワードを変えてから、もう一度ログインしてください。
- 有効日数を「0」にすると、パスワードは無期限になります。
- 初期値は「0」です。

#### 初回ログイン時にパスワードを変更させる
- YES にすると、ユーザーがはじめてログインしたときに、パスワードを変える画面を出します。
- この設定を YES にしたあとで、新規登録したユーザーと、パスワードをリセットしたユーザーが対象です。
- YES にする前に新規登録などを行ったユーザーは、対象になりません。
- 初期値は「NO」です。

#### パスワードの履歴件数
- 最近使ったパスワードを、もう一度使えないようにします。新しいパスワードが、直近の履歴件数分のパスワードのどれかと同じときは、エラーにします。
- 履歴件数を「0」にすると、くらべません。
- 初期値は「0」です。

#### パスワードの長さ (v7.3.0 以降)
- パスワードの長さは、8文字以上64文字以下です。最大の長さは、v7.3.0 から 32 文字ではなく 64 文字になりました。長い合言葉（パスフレーズ）も使えます。
- 長さと使える文字は、`.env` で変えられます。詳しくは[設定値一覧](/ja/config)の「パスワード」をご覧ください。

#### 新しいサイトの初期値 (v7.3.0 以降)
- `.env` に `EXMENT_PASSWORD_POLICY_NEW_SITE=true` を書いておくと、新しく作るサイトは、次の設定で始まります。
    - 複雑なパスワード：YES
    - 初回ログイン時にパスワードを変更させる：YES
    - パスワードの履歴件数：5
- 有効日数は「0」のままです。
- すでにあるサイトは変わりません。あとから、この画面で変えられます。

#### 注意

- <span class="small">「複雑なパスワード」と「パスワードの履歴件数」は、ユーザー設定画面やパスワードのリセット画面などで、ユーザー自身がパスワードを決めるときに使われます。システム管理者が決めるときは、対象外です。</span>


### 新しい場所からのログイン (v7.3.0 以降)
ふだんと違うIPアドレスからログインがあったとき、本人に知らせます。

- **新しいIPアドレスからのログインを本人に知らせる**
    - YES にすると、ログインしたIPアドレスが、同じユーザーの過去90日間のログインで使われていないとき、本人に通知します。
    - ユーザーの初めてのログインは通知しません。
    - 初期値は「NO」です。
- **メールでも知らせる**
    - 「新しいIPアドレスからのログインを本人に知らせる」が YES のときに出ます。YES にすると、通知をユーザーのメールアドレスにも送ります。
    - 初期値は「NO」です。

> ロードバランサーやリバースプロキシの後ろで使うときは、`.env` の `ADMIN_TRUST_PROXY_IPS` を設定してください。設定しないと、記録されるIPアドレスが、プロキシのものになります。詳しくは[リバースプロキシ使用時の設定](/ja/additional_reverse_proxy)をご覧ください。


### ログイン履歴 (v7.3.0 以降)
ユーザー自身が、自分のログインを確かめられます。右上のユーザーメニュー →「ログインユーザー設定」の下に、「ログイン履歴」が出ます。

- 自分のアカウントの、最近のログイン20件が出ます。
- 日時・結果・IPアドレス・ブラウザーを見られます。
- 心当たりのないログインがあったら、パスワードを変えて、システム管理者に連絡してください。


### その他
- v3.3.0未満からv3.3.0以上にアップデートした場合で、ユーザーコードに「ドット(.)」を含んだプロバイダでログインすると、エラーになることがあります。  
そのときは、次のように直してください。
    - 「ユーザー」テーブルの「カスタム列設定」で、「ユーザーコード」列の編集画面を開く。
    - 「使用可能文字」オプションで、「ドット」にチェックを入れて保存する。


- はじめの設定では、ログインしたままブラウザを閉じても、一定時間（120分）がすぎるまでは、ログインの状態が続きます。  
v3.6.0以降では、ブラウザを閉じたときに自動でログアウトするようにできます。「.env」ファイルを開き、次のように追記してください。  
※設定ファイルの直し方は、[設定値一覧](/ja/config)をご覧ください。

~~~
EXMENT_SESSION_EXPIRE_ON_CLOSE=true
~~~




## パスワードリセットコマンド
コマンドで、ユーザーのパスワードをリセットできます。

- システム管理者が、コンソールで次のコマンドを実行します。

~~~
php artisan exment:resetpassword --email=foobar@test.com --password=P@ssw0rd!
~~~

- このコマンドは、Eメールアドレスが"foobar@test.com"のユーザーに、パスワード"P@ssw0rd!"をセットします。


### コマンドの引数

```
exment:resetpassword {--id=} {--email=} {--user_code=} {--password=} {--random=0} {--send=0} {--reset_first_login=0}
```

#### 引数：ユーザー指定
※次の引数のうち、どれか 1 つが必須です。いくつか指定したときは、id > email > user_code の順に優先して探します。

- ##### id
対象のユーザーのログインIDです。

- ##### email
対象のユーザーのEメールアドレスです。

- ##### user_code
対象のユーザーのユーザーコードです。


#### 引数：パスワード
※"password"か、"random=1"のどちらかを指定してください。両方を指定したときは、"password"を優先します。

- ##### password  
新しいパスワードの文字列を指定してください。

- ##### random  
パスワードをランダムに作るときは、1を指定してください。未指定の場合、0。

#### 引数：オプション

- ##### send  
新しいパスワードを、対象のユーザーにメールで送るときは、1を指定してください。未指定の場合、0。

- ##### reset_first_login  
パスワードを変えたあと、ユーザーがはじめてログインしたときに、パスワードを変える画面を出します。未指定の場合、0。  
※このオプションを指定しなくても、ログイン設定で「初回ログイン時にパスワードを変更させる」を YES にしていると、ユーザーがはじめてログインしたときに、パスワードを変える画面を出します。

### 特記事項
- "random=1"を指定して、"send=1"を指定しなかったときは、リセットのあと、新しいパスワードをコンソールに出します。


### コマンド実行例

~~~
# 例 : id1のユーザーに、パスワードを指定してリセット
php artisan exment:resetpassword --id=1 --password=P@ssw0rd!

# 例 : ユーザーコード"user1"のユーザーに、ランダムパスワードをセットし、メール送信する
php artisan exment:resetpassword --user_code=user1 --random=1 --send=1

# 例 : Eメールアドレス"foobar@test.com"のユーザーに、ランダムパスワードをセットする
php artisan exment:resetpassword --email=foobar@test.com --random=1
パスワードをリセットしました。新しいパスワード：XXXXXXXXXX #変更後のパスワードがコンソール出力される
~~~
