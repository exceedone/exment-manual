# 一時的に、プログラムの差し替えを行う場合
ふつうのアップデートとは別に、Exment のプログラムを一時的に入れかえるための手順です。  
次のようなときに使います。

| したいこと | 見るところ |
|---|---|
| 先行開発版（開発中の版）を入れる | 「開発版のリリースを行う」 |
| 過去の版を入れる | 「開発版のリリースを行う」（同じ手順で、過去の版を指定します） |
| 不具合のあるソースの一部を、正式リリースの前に一時的に入れかえる | 「ソースコードの差し替えを行う」 |

**先にお読みください**

- 開発版を入れたあとで、ソースが更新されることがあります。そのあと元に戻すと、正常に動かなくなる場合があります。  
特にデータベースの定義は、変更が入ると、不整合が起きる場合があります。ご了承ください。
- 過去の版を入れると、関連するライブラリの版が変わり、正常に動かなくなる場合があります。


### 開発版のリリースを行う
開発版や過去の版は、次の手順で入れます。

1. フォルダー「vendor/exceedone/exment」の中のソースコード一式を、バックアップします。
2. コマンドラインで、次のコマンドを実行します。最初にバックアップを取り、そのあと、入れたい版に合うほうの 2 行（開発版か、過去の版か）を実行してください。

~~~
# バックアップを実施する(範囲は主にデータベースで、ソースコードはバックアップされません)
php artisan exment:backup

# Exmentの開発バージョンを指定する。例：バージョン「release_foobar」を入れる場合、以下の手順を実施する
composer require exceedone/exment=dev-release_foobar
php artisan exment:update

# Exmentの過去バージョンを指定する。例：バージョン「4.3.1」を入れる場合、以下の手順を実施する
composer require exceedone/exment=v4.3.1
php artisan exment:update
~~~

#### 開発版から、最新版に戻す場合
次のどちらかを行うと、最新版に入れかわります。

- [アップデート](/ja/update)を行う。
- 次のコマンドを実行する。

~~~
composer require exceedone/exment
php artisan exment:update
~~~



### ソースコードの差し替えを行う
ソースコードの一部を入れかえるときは、次の手順で行います。

1. フォルダー「vendor/exceedone/exment」の中のソースコード一式を、バックアップします。  
または、これから入れかえるソースコードだけをコピーして、名前を変えておきます。
2. 「vendor/exceedone/exment」の該当するところに、入れかえるソースコードを置きます。

#### 開発版から、最新版に戻す場合
次のどちらかを行うと、最新版に入れかわります。  
<span class="red">※ 実行の途中で、ファイルを上書きするかどうかを確かめるメッセージが出る場合があります。</span>そのときは同意して、入れかえを進めてください。

- [アップデート](/ja/update)を行う。
- 次のコマンドを実行する。

~~~
composer require exceedone/exment
php artisan exment:update
~~~
