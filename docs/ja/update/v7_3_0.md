# 更新手順 v7.3.0
v7.2.x から v7.3.0 に上げる手順です。v7 の中のアップデートですが、**v7.3 だけは、`composer update` だけでは上がりません。**

v7.3 では、管理画面のライブラリ「exceedone/exment-admin-core」が 1.x から **2.x** に変わります。今までの `composer.json` は admin-core を `^1.0` に決めているので、そのまま `composer update` をしても v7.2.x のままです（エラーにはなりません）。

| | v7.2.x | v7.3.0 |
| ---- | ---- | ---- |
| PHP | 8.2 以上 | 8.2 以上（変更なし） |
| exceedone/exment-admin-core | 1.x（`^1.0`） | **2.x（`^2.1.1`）** |
| Laravel | 12 | 12（変更なし） |
| MySQL / MariaDB | 8.0 以上 / 10.11 以上 | 変更なし |

アップデートでエラーが出たときは、[トラブルシューティング](/ja/troubleshooting)をご覧ください。

## 1. バックアップを取る
<span class="red bold">必ず、上げる前にバックアップを取ってください。</span>データとファイルに加えて、元に戻すときのために次のものも控えます。

- 画面の「バックアップ」（[バックアップ](/ja/backup)）
- `composer.json` と `composer.lock`
- `.env`
- プラグインなどで、`config/admin.php` やソースを自分で変えているときは、そのファイル

## 2. PHP の版を確かめる
v7.3 も **PHP 8.2 以上**が要ります（v7.2 と同じです）。`php --version` で確かめてください。レンタルサーバーでは、SSH の `php` と、管理画面で選んだ PHP の版が違うことがあります（[レンタルサーバー](/ja/install_rental)）。

## 3. composer.json を変えて、アップデートする
<!-- A15 の確かめたコマンドに合わせて直す -->
Exment をインストールしたフォルダー（プロジェクトのルート）で、次を実行します。

~~~
composer require "exceedone/exment:^7.3" "exceedone/exment-admin-core:^2.1.1" --no-update
composer update -W
php artisan exment:update
~~~

- `composer require ... --no-update` は、`composer.json` の 2 行（exment と exment-admin-core）を書きかえるだけです。手で書きかえてもかまいません。
- `-W`（`--with-all-dependencies`）を付けて、ほかのライブラリーもまとめて新しくします。付けないと、admin-core 2.x と合わないライブラリーが残って止まります。
- 本番（`APP_ENV=production`）で端末がないとき（スクリプト・cron など）は、`php artisan exment:update --force` にします。
- 終わったら、ブラウザーで **Ctrl+F5**（スーパーリロード）を押してください。

## 4. zip で入れたサイト・レンタルサーバー
<!-- A15 に確かめる -->
zip で入れたサイトや、composer を使わないサイトは、v7.3 の zip で入れかえます。

1. 上の「バックアップを取る」をします。
2. [ダウンロード](https://exment.net/download/)から v7.3 の zip を取ってきて、展開します。
3. 今のフォルダーの **`.env` と `storage` フォルダー** を残して、ほかを zip の中身で入れかえます。
4. `php artisan exment:update` を実行します。

## 5. v7.3 で変わること
### プラグイン・独自のソース：メッセージは文字として出ます
admin-core 2.x では、`admin_info()`・`admin_success()`・`admin_warning()`・`admin_error()`（`*_once()` も）・`admin_toastr()` のメッセージは、**HTML ではなく文字として**出ます。名前やエラーの文に `<` などが入っていても、そのまま文字で出るので安全です。

メッセージに HTML（`<br>` やリンクなど）を使っているときは、`admin_html_message()` で包んでください。中に入れる値は `e()`（または `esc_html()`）で囲みます。

~~~php
// v7.2 まで
admin_info('完了', $name . ' を作りました。<br><a href="' . $url . '">開く</a>');

// v7.3 から
admin_info('完了', admin_html_message(e($name) . ' を作りました。<br><a href="' . e($url) . '">開く</a>'));
~~~

包まないと、`<br>` などがそのまま文字で出ます（動きは止まりません）。

### 機能の管理
v7.3 で増えた機能（かんたん Web フォーム・バックアップの進み具合など）の多くは、「システム設定」→「[機能の管理](/ja/feature)」で使う・使わないを決めます。新しい機能は、初めは使わないになっているものがあります。

### 画面
左のメニューで、下にメニューがある項目は横に開きます（「システム設定」で前の開き方に戻せます）。くわしくは[リリースノート](/ja/release_note)をご覧ください。

## 6. Exment SaaS をお使いの方
Exment SaaS は、提供する側で上げます。この手順は要りません。

## 7. 元に戻すとき
<!-- A15 に確かめる -->
上げたあとで元に戻すときは、上げる前に取ったものに戻します。

1. `composer.json`・`composer.lock` を上げる前のものに戻して、`composer install` を実行します（zip のサイトは、上げる前のフォルダーに戻します）。
2. データベースを、上げる前のバックアップでリストアします（[バックアップ](/ja/backup)）。
3. `.env` を上げる前のものに戻します。
