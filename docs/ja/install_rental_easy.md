# かんたんインストール（レンタルサーバー）
レンタルサーバー（Xserver・さくらインターネット など）に、**ファイルを 1 つ上げてブラウザーで開くだけ**で Exment を入れる方法です。SSH や composer は使いません。

SSH を使って自分で入れるときは、[レンタルサーバーによる環境構築](/ja/install_rental)を見てください。

## 要るもの
- PHP 8.2 以上（サーバーの管理画面で選べます）
- MySQL 8.0 以上、または MariaDB 10.11 以上の、**空の**データベース
- FTP、またはサーバーのファイルマネージャー（ファイルを上げる・開くため）
- 空き容量 400MB ほど

## 手順
1. [exment-installer.zip](https://exment.net/downloads/installer/exment-installer.zip) をダウンロードして展開し、中の `exment-installer.php` を取り出します。
    zip の SHA-256 は [exment-installer.zip.sha256](https://exment.net/downloads/installer/exment-installer.zip.sha256) に書いてあります（いまは `9954da9ff53685451ac2b9376063fd92fc6b5559bc9e010048ddde72b884e5f1`）。
2. Exment を置きたいフォルダーに、`exment-installer.php` を上げます。
    - ドメインのトップで使う：`public_html`（さくらは `www`）
    - 一部のフォルダーで使う：`public_html/exment` など。**空のフォルダー**にしてください。
3. ブラウザーで開きます（例：`https://example.com/exment-installer.php`）。
4. **キーを入れます。** インストーラーは、同じフォルダーに `exment-installer-key.php` を作ります。FTP かファイルマネージャーでこのファイルを開き、`KEY:` のあとの文字を入れます。  
   ※ このファイルはブラウザーで開いても何も表示されません。ファイルを見られる人（サーバーの持ち主）だけが進められるようにするためです。
5. **サーバーの確認**を見ます。✗ があるときは、出ている直し方のとおりに変えて、「もう一度確かめる」を押します（PHP の版・memory_limit など）。⚠ は、そのままでも入れられます。
6. 「ダウンロードする」を押します。exment.net から Exment をダウンロードし、内容（sha256）を確かめて、展開・配置します。数分かかります。途中で止まったときは、ページを開き直して「続ける」を押すと、続きから進みます。
7. **データベース**：画面の案内のとおりにデータベースを作り、「接続を確かめる」を押します。ここで入れた値は保存しません。
8. 「Exment のインストール画面へ進む」を押します。インストーラーは自分（キー・作業用のファイルも）を消して、Exment のインストール画面を開きます。あとは[インストール手順](/ja/quickstart_easy)のとおりに進めます。

## 置かれる場所
- Exment 本体は、**Web に公開されないフォルダー**に置きます（例：`public_html` のとなりの `exment`、`public_html/t721` なら `exment_t721`）。
- 公開するフォルダーには、Exment の `public` の中身だけを置きます。
- 公開フォルダーの外に書き込めないサーバーでは、公開フォルダーの中の `exment-app` に置き、`.htaccess` で Web から見えないようにします。
- `.env` には、そのサイトだけのキー（APP_KEY）を作り、`APP_ENV=production`・`APP_DEBUG=false` にします。

## サーバーごとの注意
### Xserver
- PHP の版：サーバーパネル →「PHP Ver.切替」
- データベース：サーバーパネル →「MySQL設定」で、データベースとユーザーを作り、ユーザーにデータベースのアクセス権を付けます。ホスト名は「MySQL設定」に出ている名前です。
- <span class="red bold">Exment のインストール画面では、データベースの種類に「MariaDB」を選んでください。</span>Xserver のデータベースは MariaDB です。「MySQL」を選ぶと「お使いのデータベースはMariaDBですが…」と出て止まります。

### さくらインターネット
- PHP の版：コントロールパネル →「スクリプト設定」
- データベース：コントロールパネル →「データベース」→「新規追加」（文字コード utf8mb4）。ユーザー名はアカウント名、ホスト名は一覧に出ている `mysqlNNN.db.sakura.ne.jp` です。

## インストーラーがしないこと
- すでにある Exment や、ほかのサイトの上に書き込みません（フォルダーにファイルがあるとき・Exment がすでにあるときは止まります）。アップデートは[アップデート](/ja/update)を見てください。
- テーブルが入っているデータベースは使いません（接続の確認で断ります）。
- exment.net 以外からファイルを取りません。内容（sha256）が違うファイルは使わずに消します。
- データベースのパスワードを保存・表示しません。
- 終わったあとに残りません（消せなかったときは、画面のとおりに FTP で消してください）。

## うまくいかないとき
- **「このリリースには PHP 8.x 以上が要ります」**：サーバーの管理画面で PHP の版を上げて、ページを開き直し「続ける」を押します。
- **キーを何度もまちがえた**：10 分ほど待ってから入れ直します。
- **はじめからやり直したい**：画面の下の「はじめからやり直す」を押します（置いた Exment のファイルも消します）。
- そのほかは[インストール時のエラー](/ja/install_error)を見てください。
