# MCP サーバー（AI から使う）
Claude などの AI から、ユーザーの権限のまま Exment のデータを読めます。Exment に MCP（Model Context Protocol）のサーバーが入っています。

※この機能は、Exment v7.2.1 以降で使えます。  
※はじめは「使わない」です。システム管理者が「設定：システム」→「[機能の管理](/ja/feature)」で「MCP（AI からつなぐ）」を使う設定にし、使える役割グループを選んでください。  
※できるのは**読むことだけ**です。

## つなぎかた
- アドレス：`https://(ExmentのURL)/api/mcp`（「/admin」が付いているサイトでは `/admin/api/mcp`）
- ログイン：[API キー](/ja/api_key)（または OAuth のアクセストークン）を `Authorization: Bearer ...` で送ります

例（Claude Code）：
~~~
claude mcp add --transport http exment https://(ExmentのURL)/api/mcp --header "Authorization: Bearer exk_xxxxxxxx"
~~~

## 使えるツール
| ツール | 内容 |
|---|---|
| `list_tables` | 見られるテーブルの一覧 |
| `get_table` | テーブルの列など |
| `search_data` | データを探す（言葉を省くと新しい順） |
| `get_data` | データ 1 件 |
| `list_attachments` | 添付ファイルの一覧（名前などだけ） |
| `get_workflow_status` | ワークフローの状態 |

## 返すもの
- **キーやトークンのユーザーが見られるものだけ**を返します。テーブルとデータの権限、キーの範囲（`table_read`・`value_read`・`workflow_read`）、キーに選んだテーブルが、API と同じように効きます。
- 1 回に返す件数は `.env` の `EXMENT_MCP_MAX_ROWS`（初め 50、最大 100）、1 人 1 分あたりの回数は `EXMENT_MCP_CALLS_PER_MINUTE`（初め 60）です。
- 使ったツールは、操作ログに残ります（メソッド `MCP`）。v7.3.0 からは、下の「呼び出しの記録」でも見られます。
- API の IP の制限も、そのまま効きます。

## 呼び出しの記録（MCP の記録）
※この機能は、Exment v7.3.0 以降で使えます。

AI（MCP）からの呼び出しだけを、ログの管理の画面で見られます。操作ログ（メソッド `MCP`）も、今までどおり残ります。

### 使えるようにする
はじめは「使わない」です。システム管理者が「[機能の管理](/ja/feature)」で「MCP の記録」を使う設定にします。

### 見る
「設定：システム」→「ログの管理」の一覧で、「MCP の記録」の「開く」を押します。**システム管理者と、「監査」の権限がある役割グループのユーザーだけ**が見られます。

1 回の呼び出しごとに、次のことを残します。

| 項目 | 内容 |
|---|---|
| 日時・ユーザー・IP アドレス | 呼び出した人（IP アドレスは、ログの管理の「IP アドレスの残し方」のとおり） |
| ツール | 使ったツール（`search_data` など）。ツールでない呼び出しは、そのメソッド（`initialize`・`ping` など） |
| 結果 | 成功・ツールのエラー（データがない、権限がないなど）・エラー（JSON-RPC のエラーとコード）・ことわった |
| 理由 | エラーやことわった理由（`rate_limited`：回数が多すぎる、`parse_error`：JSON でない、`unsupported_version`：MCP の版がちがう など） |
| かかった時間・答えの大きさ | ミリ秒・バイト |
| 引数 | 操作ログと同じく残します。パスワード・トークン・秘密のキーなどの値は隠します。ログの管理で「入力をログに残す」を使わないときは、項目の名前だけです |

- 日時・ユーザー・ツール・結果でしぼりこめます。
- ログインしていない呼び出しは残しません。
- 回数の制限（MCP の 1 分あたりの回数と、API の回数の制限）でことわった呼び出しは、1 人につき 1 分に 1 行だけ残します。
- 残す日数は、はじめ 90 日です。画面の下で、システム管理者が変えられます（0：消さない）。

### IT 監査のレポート
MCP の記録を使っているときは、IT 監査のレポートに「MCP の呼び出し」が出ます。期間の中の呼び出しを、ユーザーごとに 1 行でまとめます。

| 項目 | 内容 |
|---|---|
| ユーザーコード・ユーザー名 | 呼び出した人 |
| 呼び出し・エラー・ことわった | 回数 |
| ツール | 使ったツール |
| 最初・最後 | 期間の中の、最初と最後の呼び出しの日時 |

回数とツールだけで、引数は出しません。ほかの部分と同じく、CSV でもダウンロードできます。
