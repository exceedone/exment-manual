# IPフィルター
Exment の Web ページと API に、アクセスできる IP アドレスを決める設定です。

- 許可する IP アドレスだけを登録します（ホワイトリスト方式）。
- Web ページ用と API 用を、分けて登録します。たとえば「API だけ、実行できる IP アドレスを制限する」こともできます。


### 設定手順
1. Exment をエキスパートモードにします。まだエキスパートモードになっていないときは、「.env」ファイルを開き、次の値を追加します。

~~~
EXMENT_EXPART_MODE=true
~~~

2. システム設定の画面を開きます。IPフィルターの項目が追加されています。

![IPフィルター設定](img/quickstart/ip_filter.png)

#### 設定内容詳細

| したいこと | 入力のしかた | 例 |
| ---- | ---- | ---- |
| IP アドレスを 1 つ決めて許可する | IP アドレスをそのまま入力します | 123.4.5.6 |
| IP アドレスを範囲で許可する | サブネットマスクの形で入力します | 例1： 123.4.0.0/16 → 123.4.0.0から123.4.255.255までアクセス許可<br>例2： 123.4.10.0/24 → 123.4.10.0から123.4.10.255までアクセス許可 |
| localhost に作ったサーバーで、localhost からのアクセスを許可する | 「::1」と入力します | ::1 |
| 複数の IP アドレスを許可する | 改行で区切って入力します。どれか 1 つに合えば、アクセスできます | |


#### IP制限を強制的に無効にする
Web ページの IP アドレスの設定をまちがえて、アクセスできなくなったときなどに、IP 制限を止める手順です。

- 「.env」ファイルを開き、次の値を追加します。

~~~
EXMENT_DISABLE_IP_FILTER=true
~~~
