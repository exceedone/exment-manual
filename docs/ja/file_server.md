# ファイル共有
チームごとのワークスペースにフォルダーとファイルを置いて共有します。フォルダーごとの権限・版の管理・プレビュー・ゴミ箱があります。Box や SharePoint のドキュメントライブラリのように使えます。  
ファイルの中身は、Exment のファイルの保存先（ローカル・S3・Azure・FTP など、今の設定のまま）に置きます。

※この機能は、Exment v7.2.0 以降で使えます。<!-- TODO: ファイル共有が master に入る版に合わせて直す -->

## はじめに使う
ファイル共有は、はじめは「使わない」です。システム管理者が「管理者設定」→「[機能の管理](/ja/feature)」で「ファイル共有」を「使う」にすると、左のメニューに「ファイル共有」が出ます。使える人（役割グループ）も、機能の管理で選べます。

## ワークスペース
ワークスペースは、チームのファイルの置き場所です（SharePoint のサイトに当たります）。

- 「ワークスペースを作る」で作ります。作った人が、そのワークスペースの管理者になります。だれが作れるかは、`.env` の `EXMENT_FILE_SERVER_WORKSPACE_CREATE` で決めます（`admin`：システム管理者だけ、`all`：だれでも）。
- 「ワークスペースの設定」で、次のことを決めます。

| 項目 | 内容 |
| --- | --- |
| 名前・説明 | ワークスペースの名前と説明です。 |
| メンバー | ユーザー・組織と、その権限（閲覧・アップロード・編集・管理）。管理者が 1 人以上必要です。 |
| 容量の上限（GB） | 空にすると上限なし。古い版・ゴミ箱のファイルも数えます。 |
| ゴミ箱に残す日数 | 過ぎると完全に削除します。0 にすると、手で削除するまで残します。 |
| 残す版の数 | 1 つのファイルに残す古い版の数です。 |
| 列（メタデータ） | このワークスペースのファイルに付ける列です。下の「列（メタデータ）」をご覧ください。 |

トップには、開けるワークスペースの一覧と、「お気に入り」「最近更新されたファイル」「自分に共有されたもの」が出ます。

## フォルダーとファイル
- 「新しいフォルダー」「ファイルをアップロード」「フォルダーをアップロード」、またはドラッグ＆ドロップでアップロードします。大きなファイルは分けて送るので、途中で切れても続きから送れます。
- ファイル・フォルダーごとに、名前を変える・移動・コピー・ダウンロード（複数は ZIP）・削除・お気に入りができます。
- 削除したものはゴミ箱に入ります。ゴミ箱から「元に戻す」か「完全に削除」できます。

## 権限
権限は 4 つです。上の権限は、下の権限でできることもすべてできます。

| 権限 | できること |
| --- | --- |
| 閲覧 | 見る・ダウンロードする |
| アップロード | ファイルを足す |
| 編集 | 名前を変える・移動・削除・新しい版・共有リンクを作る |
| 管理 | 権限を変える・チェックアウトを解除する・承認する |

- フォルダー・ファイルは、親のフォルダー（またはワークスペース）の権限を引き継ぎます。
- 「権限の継承をやめる」で、そのフォルダー・ファイルだけの権限にできます。「親の権限を引き継ぐ」で元に戻せます。
- システム管理者は、すべてのワークスペースを管理できます。

## 版の管理とチェックアウト
- 同じ名前のファイルを上書きするか、「新しい版をアップロード」すると、新しい版になります。「版の履歴」から前の版をダウンロードしたり、「この版に戻す」で前の版の内容を新しい版として保存したりできます。
- 「チェックアウト（編集中にする）」にすると、ほかの人はそのファイルを変更・削除できません。終わったら「チェックイン（編集を終える）」にします。管理の権限がある人は「チェックアウトを解除」できます。

## プレビュー
画像・動画・音声・PDF・テキストは、画面で見られます。Office のファイル（docx・xlsx・pptx）は、サーバーの準備で見え方が変わります。

| サーバーの準備 | Office のファイルの見え方 |
| --- | --- |
| LibreOffice がある（`EXMENT_FILE_SERVER_SOFFICE_PATH`） | PDF にして表示します。 |
| 公式プラグイン「Groupware」がある | 「Office で開く」で、ブラウザーの Office（ibisOffice）で読み取り専用で開けます。LibreOffice もあれば、タブで切り替えます。 |
| どちらもない | ファイルの中の文字だけを表示します。見た目どおりに見るにはダウンロードしてください。 |

Groupware の ibisOffice なら、LibreOffice も Docker も要らず、レンタルサーバーでも使えます。準備と Web サーバーの設定は [Groupware](/ja/plugin_groupware?id=web-サーバーの設定) をご覧ください。

※html・svg などは、安全のため画面には出さず、ダウンロードだけです。

※受け取り用のリンクで社外から届いたファイルは、開いてもプレビューと文字の取り出しをしません。管理の権限がある人が「プレビューを作る」を押したときだけ作ります。

## 社外への共有リンク
ファイル・フォルダーを、ログインしない社外の人に渡したり、社外の人からファイルを受け取ったりできます。ファイルの画面の「社外への共有リンク」の欄で、リンクを作ります。

| リンクの種類 | 内容 | 作れる人 |
| --- | --- | --- |
| 共有リンク（社外の人が見る・ダウンロード） | フォルダーのときは中のものも見せます。「ダウンロードを許す」を外すと、プレビューだけです。 | 編集の権限がある人 |
| 受け取り用のリンク（社外からアップロード） | 社外の人がフォルダーにファイルを入れます。ほかの人のファイルは見えません。同じ名前のファイルは上書きせず、「名前 (2)」にします。 | 編集の権限がある人（7.2.1 から。前にアップロードの権限だけの人が作ったリンクは開かなくなります） |

- 有効期限・パスワード・開ける回数を付けられます。パスワードは 8 文字以上です（`EXMENT_FILE_SERVER_SHARE_PASSWORD_MIN`）。「取り消す」で、いつでも無効にできます。
- 無効なリンク（期限切れ・取り消し済み・回数の上限など）は、どれも「リンクを開けません」と出ます。
- 社内の人に渡すときは「社内リンクをコピー」を使います。開けるのは、そのファイルを見る権限のある人だけです。
- 社外への共有リンクを使わせないときは、`.env` に `EXMENT_FILE_SERVER_EXTERNAL_SHARE=false` を書きます。有効期限を必ず付けさせるときは、`EXMENT_FILE_SERVER_SHARE_MAX_DAYS` に日数を書きます。
- 共有リンク（`/share/...`）は、社外の人に渡すものなので、ふだんはシステム設定の Web の IP フィルターを当てません。社内からだけ開かせたいときは、`.env` に `EXMENT_FILE_SERVER_SHARE_WEB_IP_FILTER=true` を書きます。ルートを作るときに読む設定なので、`php artisan route:cache` を使っているサイトは、変えたあとにもう一度実行してください。

## 列（メタデータ）
ワークスペースの設定で、ファイルに付ける列（「顧客」「種類」など）を作れます。

- 種類は、テキスト・複数行・数値・日付・選択・複数選択・はい/いいえです。必須・既定値・一覧に出すかを決められます。
- 一覧で、列で絞り込み（「未入力」も選べる）・並べ替え・グループ分けができます。

## データとの結び付け
ファイルの画面の「関係するデータ」で、Exment のテーブルのデータ（顧客など）と結び付けられます。データの詳細画面には「ファイル共有のファイル」の欄が出ます。どちらも、見る権限のあるものだけが出ます。

## 検索
「検索」で、ファイル名・列の値・ファイルの中の文字で探せます。見る権限のあるファイルだけが出ます。

- ファイルの中の文字は、テキスト・HTML・Office（docx・xlsx・pptx）・OpenDocument から取り出します。PDF は pdftotext（`EXMENT_FILE_SERVER_PDFTOTEXT_PATH`）があるとき、画像とスキャンした PDF は tesseract（`EXMENT_FILE_SERVER_OCR_PATH`）があるときに取り出します。
- ふだんはデータベースで探します。`EXMENT_FILE_SERVER_MEILI=true` にすると、[Meilisearch](/ja/additional_meilisearch) で探します（データの全文検索とは別の索引 `exment_files` を使います）。

## 承認・保全・保持期間

| 機能 | 内容 |
| --- | --- |
| 承認 | フォルダーの「ルール」で「承認が要る」にすると、入れたファイルは「承認待ち」になります。承認されるまで、見られるのはアップロードした人と管理者だけです。管理の権限がある人が「承認」か「差し戻し」をします。 |
| 保全 | ワークスペース・フォルダー・ファイルに付けると、削除できなくなります。古い版も消えません。 |

| ダウンロードできる人 | 決めた権限より下の人は、プレビューだけ見られます。 |
| 透かし | プレビューの上に、見ている人の名前と日時を重ねて出します。 |

| フォロー・コメント | フォローしたワークスペース・フォルダー・ファイルが変わると、ベルとメールで知らせます。コメントの `@ユーザーコード` で、その人に知らせます。 |

## サーバーの準備
- **毎日の処理**：ゴミ箱の自動の削除は、`php artisan exment:file-server-purge`（毎日 3:30）で動きます。[タスクスケジュール](/ja/additional_task_schedule)を設定してください。
- **キュー**：サムネイル・プレビュー・文字の取り出しは、キューで動きます。
- **文字の取り出しをやり直す**：`php artisan exment:file-server-index` で、まだのファイルの文字を取り出し、Meilisearch の索引を作り直します。
- **ほかのソフト**（どれも、なくても動きます）：LibreOffice（Office のプレビュー）・pdftotext（PDF の文字）・tesseract（OCR）・Meilisearch（速い検索）。
- **LibreOffice をネットワークなしで動かす**：Office のファイルは外の URL を読みにいくことがあります。`EXMENT_FILE_SERVER_SOFFICE_PREFIX` に、LibreOffice の前に付けるコマンドを書くと、ネットワークなしで変換できます（例：`unshare -rn`、`firejail --net=none --quiet`）。サーバーでそのコマンドが使えるか、先に確かめてください。
- **アップロードの上限**：大きいファイルは分けて送ります。1 つのファイルは 2 GB まで（`EXMENT_FILE_SERVER_MAX_FILE_SIZE`）、1 人が途中にしておけるアップロードは 20 個まで（`EXMENT_FILE_SERVER_MAX_UPLOADS`）、その合計は 10 GB まで（`EXMENT_FILE_SERVER_MAX_UPLOAD_BYTES`）です。途中のアップロードもワークスペースの容量に数えます。60 分なにも届かないものは数えず、その人が次に始めるときに消します。

## 主な設定（.env）
| 設定 | 既定 | 内容 |
| --- | --- | --- |
| `EXMENT_FILE_SERVER_WORKSPACE_CREATE` | `admin` | ワークスペースを作れる人（`admin`・`all`） |
| `EXMENT_FILE_SERVER_MAX_FILE_SIZE` | `2147483648`（2 GB） | 1 ファイルの大きさの上限（バイト。0 は上限なし。7.2.1 から 2 GB） |
| `EXMENT_FILE_SERVER_MAX_UPLOADS` | `20` | 1 人が途中にしておけるアップロードの数 |
| `EXMENT_FILE_SERVER_MAX_UPLOAD_BYTES` | `10737418240`（10 GB） | 1 人の途中のアップロードの合計（バイト。0 は上限なし） |
| `EXMENT_FILE_SERVER_EXTERNAL_SHARE` | `true` | 社外への共有リンクを使うか |
| `EXMENT_FILE_SERVER_SHARE_MAX_DAYS` | `0` | 共有リンクの有効期限の上限（日。0 は期限なしも可） |
| `EXMENT_FILE_SERVER_SHARE_PATH` | `share` | 共有リンクの URL の最初の部分 |
| `EXMENT_FILE_SERVER_SHARE_PASSWORD_MIN` | `8` | 共有リンクのパスワードの最短の文字数 |
| `EXMENT_FILE_SERVER_SHARE_WEB_IP_FILTER` | `false` | 共有リンクにも Web の IP フィルターを当てるか |
| `EXMENT_FILE_SERVER_SOFFICE_PATH` | なし | LibreOffice（soffice）の場所 |
| `EXMENT_FILE_SERVER_SOFFICE_PREFIX` | なし | LibreOffice の前に付けるコマンド（ネットワークなしで動かす） |
| `EXMENT_FILE_SERVER_PDFTOTEXT_PATH` | なし | pdftotext の場所 |
| `EXMENT_FILE_SERVER_OCR_PATH` | なし | tesseract の場所 |
| `EXMENT_FILE_SERVER_MEILI` | `false` | Meilisearch で探すか |
| `EXMENT_FILE_SERVER_AUDIT` | `true` | 操作の記録を残すか |
| `EXMENT_FILE_SERVER_NOTIFY` | `true` | フォローのお知らせを送るか |
