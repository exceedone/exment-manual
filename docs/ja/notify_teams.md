# Teams の個人のチャットに通知する

通知を、その人の **Teams の個人のチャット** に直接送れます（Exment 7.2.6 以降）。
Exment が Teams の **ワークフロー**（Power Automate）に通知の内容を送り、ワークフローが、その人のチャットにボット（フロー ボット）として投稿します。

- 送るのは、件名・本文・データへのリンクです。Teams では、件名が太字の見出しになり、本文は段落・番号つきのリストのまま、「開く」ボタンが付いたカード（Adaptive Card）で届きます
- 通知のテンプレートの件名と本文を、受け取る人の言語（[ユーザーの言語](/ja/user_locale)）で使います
- 送り先の Teams のアカウントは、Exment のユーザーの **メールアドレス** です

> チャネルに送る今の方法（[Webhook](/ja/notify_webhook) の Microsoft Teams）は、Microsoft が Office 365 コネクタを終わらせる方向です。同じワークフローで、チャネルにも送れます（下の「チャネルに送るとき」）。

## 1. Teams でワークフローを作る

Teams の組織の人が作ります（作った人のアカウントで動きます）。

1. Teams の左の「アプリ」から **ワークフロー**（Workflows）を開き、「作成」→「最初から作成」を選びます
2. トリガーに **「Teams Webhook 要求を受信したとき」**（When a Teams webhook request is received）を選びます
   - 「フローをトリガーできるユーザー」は **「すべてのユーザー」**（Anyone）にします。Exment からは、アドレスを知っているかどうかだけで受け付けます。**アドレスは秘密にしてください**
3. 「新しいステップ」で **「チャットまたはチャネルでカードを投稿する」**（Post card in a chat or channel）を足します
   - 投稿者：**フロー ボット**
   - 投稿先：**フロー ボットとチャットする**
   - 受信者：「式」に `triggerBody()?['to_email']` と入れます
   - アダプティブ カード：「式」に `triggerBody()?['card']` と入れます
4. 保存すると、トリガーに **HTTP POST の URL** ができます。これをコピーします

### Exment が送る JSON

ワークフローは、次の形の JSON を受け取ります。カード（`card`）は Exment が作るので、ワークフローはそのまま投稿するだけです。

```json
{
  "to_email": "user1@example.com",
  "title": "課題が更新されました（ISS00423）",
  "body": "**ログインできない**\n\n1. 状態を「対応中」に変えました",
  "url": "https://exment.example.com/admin/data/pm_issue/423",
  "sender": "野呂 誠二",
  "locale": "ja",
  "card": { "type": "AdaptiveCard", "version": "1.4", "body": [ ... ], "actions": [ ... ] }
}
```

トリガーの「要求本文の JSON スキーマ」を使うときは、次を入れてください。

```json
{
  "type": "object",
  "properties": {
    "to_email": { "type": "string" },
    "title": { "type": "string" },
    "body": { "type": "string" },
    "url": { "type": ["string", "null"] },
    "sender": { "type": ["string", "null"] },
    "locale": { "type": "string" },
    "card": { "type": "object" }
  }
}
```

## 2. Exment に設定する

1. 「管理者設定」→「機能の管理」で **「Teams の通知（個人のチャット）」** を「使う」にします（初めは「使わない」です）
2. 「システム設定」（詳細設定）の **「Teams（ワークフロー）」** の「新しいアドレス」に、コピーした URL を入れて保存します
   - アドレスは秘密の値なので、保存したあとは画面に出ません（「設定済み」とだけ出ます）。空のまま保存すると、今のアドレスを使い続けます。消すときは「アドレスを消す」をオンにして保存します
   - アドレスは操作ログにも出ません
3. 通知の設定（[通知](/ja/notify)）で、「通知アクション」に **「Teams（個人あて）」** を選び、通知先（ユーザー・組織の列、作った人など）を選びます

## チャネルに送るとき

ワークフローの「投稿先」を **チャネル** にして、チームとチャネルを選びます（受信者の式は要りません）。Exment からは、その通知の通知先を 1 人にしてください（1 人に 1 回送るので、通知先が多いと同じカードが何回も投稿されます）。

## うまく届かないとき

- Exment のログ（storage/logs）に「the Teams workflow answered …」と出ているときは、ワークフローの実行の履歴（Teams のワークフロー → そのフロー → 実行の履歴）で理由を見ます
- 受信者が見つからないときは、Exment のユーザーのメールアドレスが、Teams のアカウント（組織のメールアドレス）と同じかを確かめます
- 何も起きないときは、機能の管理で「Teams の通知（個人のチャット）」が「使う」になっているか、システム設定にアドレスが入っているかを確かめます
