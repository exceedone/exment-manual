# Exment concept

![Move your work out of spreadsheets and scattered files](ja/img/concept/concept_hero.png)

## What is Exment
Exment is a **web database for building apps that fit your own business, without writing programs**.  
Customer lists, deals, requests, asset ledgers: bring the data you now manage here and there, in Excel, on paper or in email attachments, into one place. Whoever opens it, and from wherever, works with the same newest data.

> At first it is an "empty box". Add tables to it for the things you want to manage, and it becomes a business system for your company. Add customers and it is customer management; add requests and it is a workflow. **There are as many ways to use it as there are companies.**

## Three strong points
### 1. Build it: without programs
- You can make tables, items, entry forms and lists (views) just by working on the screen.
- A list can be seen as a table, a calendar, a kanban board, a Gantt chart or a chart.
- Choose a template (customer management, the request pack and so on) and you can start using it right away.

### 2. Run it: as a team, safely
- **Workflows** for request → approval or sending back, and **notifications** of deadlines and data changes (email, Slack, Microsoft Teams, LINE).
- With role groups you decide who can see and change what. Operation logs are kept too.
- The dashboard shows the current numbers at a glance. It also works in the browser of a smartphone.

### 3. Connect it: with other systems and AI
- With the API you can exchange data with other systems. You can also make an API key for each user.
- **AI (MCP)**: an AI such as Claude can read the data with the permissions of the user.
- The official plugins (project management, Support Desk, Groupware) are included for free. You can add features with plugins.

## How it differs from Excel
| | Excel and files | Exment |
|---|---|---|
| The newest data | Files get copied, and nobody knows which one is the newest | Always one. Everyone sees the same data |
| Using it at the same time | You cannot change it while someone has it open | Any number of people can enter data at the same time |
| Permissions | For each file. For each row or column it is difficult | By role groups, for each table and each data |
| History | Lost when the file is overwritten | The change history and the operation logs are kept |
| Approval and notifications | Passed around by email or on paper | Automatic, with workflows and notifications |
| Finding | Open the files and look | Keyword search, filtering and sorting |

## For example, uses like these
**Customer management**: put the business partners and the contact persons together, so that everyone sees the same information.

![Customer management](ja/img/concept/concept_customer.png)

**File sharing**: proposals, quotations and contracts in a workspace for each department. With version management and permissions.

![File sharing](ja/img/concept/concept_files.png)

There are also requests and approvals (approval requests, expense claims, leave), deal management, management of assets and equipment, inquiry management, daily reports and more. Any work can start from adding a table. See the [feature map](https://exment.net/en/feature-map/) for details.

## Open source, for the long run
- **Free open source** (GPL-3.0). Install it on your own server, and **the price does not grow when the users increase**.
- The data stays on your own server. If you do not want to prepare a server, you can also choose Exment SaaS.
- With the paid support, you can ask for advice from the start to the daily operation.
