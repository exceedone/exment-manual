# Das Konzept von Exment

![Schluss mit Excel und verstreuten Dateien](../ja/img/concept/concept_hero.png)

## Was ist Exment
Exment ist eine **Webdatenbank, mit der Sie ohne Programmieren Anwendungen bauen, die zur Arbeit Ihres Unternehmens passen**.  
Kundenlisten, Projekte, Anträge, Inventarlisten: Daten, die heute verstreut in Excel, auf Papier oder in E-Mail-Anhängen liegen, kommen an einen Ort. Egal wer sie öffnet und von wo: Alle arbeiten mit denselben, aktuellen Daten.

> Am Anfang ist Exment eine „leere Kiste“. Sie fügen Tabellen für das hinzu, was Sie verwalten möchten. So entsteht ein Geschäftssystem für genau Ihr Unternehmen. Mit Kunden wird es eine Kundenverwaltung, mit Anträgen ein Workflow. **Es gibt so viele Arten der Nutzung, wie es Unternehmen gibt.**

## 3 Merkmale
### 1. Bauen —— ohne Programmieren
- Tabellen, Felder, Eingabeformulare und Listen (Ansichten) entstehen allein durch die Bedienung am Bildschirm.
- Listen sehen Sie als Tabelle, Kalender, Kanban, Gantt-Diagramm oder Grafik.
- Wenn Sie eine Vorlage wählen (Kundenverwaltung, Antragspaket usw.), können Sie sofort anfangen.

### 2. Betreiben —— im Team und sicher
- **Workflows** für Antrag → Genehmigung oder Zurückweisung, **Benachrichtigungen** über Fristen und Datenänderungen (E-Mail, Slack, Microsoft Teams, LINE).
- Mit Rollengruppen legen Sie fest, wer was sehen und ändern darf. Auch ein Vorgangsprotokoll wird geführt.
- Im Dashboard sehen Sie die aktuellen Zahlen auf einen Blick. Exment läuft auch im Browser des Smartphones.

### 3. Verbinden —— mit anderen Systemen und mit KI
- Über die API tauschen Sie Daten mit anderen Systemen aus. Sie können auch API-Schlüssel für einzelne Benutzer anlegen.
- **KI (MCP)**: Eine KI wie Claude kann Daten lesen, und zwar mit den Berechtigungen des Benutzers.
- Die offiziellen Plugins (Projektverwaltung, Support Desk, Groupware) sind kostenlos dabei. Mit Plugins fügen Sie Funktionen hinzu.

## Der Unterschied zu Excel
| | Excel und Dateien | Exment |
|---|---|---|
| Aktuelle Daten | Dateien werden kopiert, und niemand weiß, welche die neueste ist | Immer nur eine. Alle sehen dieselben Daten |
| Gleichzeitig nutzen | Wenn jemand die Datei offen hat, kann man sie nicht ändern | Beliebig viele Personen können gleichzeitig eingeben |
| Berechtigungen | Pro Datei. Pro Zeile oder Spalte ist es schwierig | Mit Rollengruppen, pro Tabelle und pro Datensatz |
| Verlauf | Geht beim Überschreiben verloren | Der Änderungsverlauf und das Vorgangsprotokoll bleiben |
| Genehmigung und Benachrichtigung | Per E-Mail oder auf Papier | Automatisch mit Workflow und Benachrichtigung |
| Suchen | Dateien öffnen und suchen | Stichwortsuche, Filter und Sortierung |

## Zum Beispiel so
**Kundenverwaltung**: Geschäftspartner und Ansprechpartner an einem Ort, damit alle dieselben Informationen sehen.

![Kundenverwaltung](../ja/img/concept/concept_customer.png)

**Dateifreigabe**: Angebote, Kostenvoranschläge und Verträge im Arbeitsbereich jeder Abteilung. Mit Versionsverwaltung und Berechtigungen.

![Dateifreigabe](../ja/img/concept/concept_files.png)

Dazu kommen Anträge und Genehmigungen (Entscheidungsvorlagen, Spesenabrechnung, Urlaub), Projektverwaltung, die Verwaltung von Anlagen und Inventar, die Verwaltung von Anfragen, Tagesberichte und mehr. Jede Arbeit beginnt damit, eine Tabelle hinzuzufügen. Einzelheiten zeigt die [Funktionsübersicht](https://exment.net/en/feature-map/).

## Open Source, auf Dauer nutzbar
- **Kostenlose Open-Source-Software** (GPL-3.0). Auf dem eigenen Server **steigt der Preis nicht, auch wenn die Zahl der Benutzer wächst**.
- Die Daten liegen auf Ihrem eigenen Server. Wenn Sie keinen Server bereitstellen möchten, können Sie auch Exment SaaS wählen.
- Mit dem kostenpflichtigen Support bekommen Sie Beratung von der Einführung bis zum Betrieb.
