## Was ist Exment
### Schluss mit Excel und verstreuten Dateien.
Exment ist eine **kostenlose Open-Source-Webdatenbank, mit der Sie ohne Programmieren eigene Geschäftsanwendungen bauen**. Kunden, Projekte, Anträge und Aufgaben liegen an einem Ort, und das Team arbeitet gemeinsam damit.

- **Ohne Code, schnell fertig**: Tabellen, Formulare, Listen, Kanban, Gantt-Diagramme und Auswertungen entstehen allein durch Einstellungen auf dem Bildschirm.
- **Vom Antrag bis zur Genehmigung, im Team**: Workflows, Benachrichtigungen, öffentliche Formulare und eine API sind schon dabei.
- **Kostenlos. Auch mit mehr Benutzern bleibt der Preis gleich**: Exment ist Open Source (GPL). Der Preis steigt nicht mit der Zahl der Benutzer.
- **Auf dem eigenen Server oder in der Cloud**: Exment läuft auf dem eigenen Server, auf einem Mietserver, auf AWS, Azure und anderen. Die Daten bleiben bei Ihnen.

## Zuerst ausprobieren
- **Die Demo ausprobieren**: Projektverwaltung, Verkaufschancen, Workflows und öffentliche Formulare können Sie gleich nach der Anmeldung testen. Die Anmeldedaten stehen in der <a href="https://exment.net/de/demo-env/" target="_blank">Liste der Demoseiten</a>.
- **Kostenlos anfangen**: Die Schritte der Installation beginnen bei [Erste Schritte](/de/quickstart).
- **Sehen, was möglich ist**: <a href="https://exment.net/de/functions/" target="_blank">Funktionen und Screenshots</a> / <a href="https://exment.net/de/whats-new/" target="_blank">What's new</a> (die neuen Funktionen jeder Version) / [Versionshinweise](/release_note) (Englisch)
- **Fragen stellen**: <a href="https://exment.net/assets/exment-flyer-en.pdf" target="_blank">Broschüre (PDF)</a> / <a href="https://exment.net/de/inquiry/" target="_blank">Kontakt</a> (Beratung zur Einführung und zum Umstieg)

## Über dieses Handbuch
Dieses Handbuch beschreibt immer die neueste Version von Exment.
Bei Funktionen und Befehlen, die in einer späteren Version dazugekommen sind, steht manchmal nicht, ab welcher Version sie nutzbar sind. Wir bitten um Ihr Verständnis.
