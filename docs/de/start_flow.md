# Der Weg bis zum Arbeitsbeginn mit Exment
Dies ist der Weg von der Installation von Exment bis zum Einsatz in der täglichen Arbeit.  
Wer was tut, ist nach Rollen geordnet.

### Rollen
Es gibt die folgenden 4 Rollen rund um Exment. Die jeweils zuständige Person nimmt die Einstellungen von Exment vor.  
※Je nach Unternehmen hat eine Person mehrere Rollen, zum Beispiel ist der Infrastrukturverantwortliche auch Administrator.

- ##### Infrastrukturverantwortlicher  
→Wer die Arbeiten am Server erledigt, zum Beispiel Exment auf dem Server installieren und aktualisieren

- ##### Administrator  
→Wer die Einstellungen für die Nutzung von Exment vornimmt, zum Beispiel die Ersteinrichtung nach der Installation und das Hinzufügen von Tabellen und Spalten

- ##### Benutzer (allgemeiner Benutzer)  
→Wer mit den Tabellen, die der Administrator vorbereitet hat, Daten anlegt, bearbeitet und löscht

- ##### Entwickler  
→Wer Exment durch Entwicklung erweitert, wenn besondere Funktionen nötig sind, zum Beispiel beim Einsatz von Plugins  

### Schritte

#### 【Infrastrukturverantwortlicher】
- [Installation](/de/quickstart)  
Exment wird auf dem Server installiert.  

- [Aktualisierung](/de/update)  
Wenn eine neue Version von Exment erscheint, melden Sie sich am Server an und aktualisieren.  

#### 【Administrator】
- [Ersteinrichtung](/de/first_setting)  
Gleich nach der Installation tragen Sie die nötigen Angaben ein, zum Beispiel den Namen der Website und die Anmelde-ID des ersten Administrators.

- [Einstellungen der benutzerdefinierten Tabelle](/de/table)  
Sie legen das, was Sie verwalten möchten, als Tabelle an, zum Beispiel „Kundenverwaltung“ oder „Aufgabenverwaltung“.  

- [Einstellungen der benutzerdefinierten Spalten](/de/column)  
Sie legen die Angaben, die Sie verwalten möchten, als Spalten an, zum Beispiel „Kundenname“, „Postleitzahl“ und „Adresse“ in der Tabelle „Kundenverwaltung“.

- [Vorlage](/de/template)  
Mit den vorbereiteten Vorlagen fügen Sie benutzerdefinierte Tabellen und Spalten auf einmal hinzu, ohne sie von Grund auf anzulegen.

##### ■Weitere nötige Einstellungen

- [Benutzer und Login-Benutzer](/de/user)  
Sie legen die ID und das Passwort fest, mit denen sich allgemeine Benutzer bei Exment anmelden.

- [Rollen und Berechtigungen](/de/permission)  
Sie legen für jeden Benutzer fest, was er in Exment tun darf.

- [Menü](/de/menu)  
Sie verwalten die Einträge des Menüs, das immer links auf dem Bildschirm steht.  

#### 【Benutzer (allgemeiner Benutzer)】
- [Daten](/de/data)  
In den benutzerdefinierten Tabellen, die der Administrator eingerichtet hat, fügen Sie Daten hinzu, aktualisieren, lesen und löschen sie.  

- [Suche](/de/search)  
Gespeicherte Daten lassen sich leicht suchen.  


#### 【Entwickler】
- [Plugin](/de/plugin_quickstart)  
Wenn die Funktionen von Exment erweitert werden müssen, laden Sie ein Plugin hoch und fügen so Funktionen hinzu.
