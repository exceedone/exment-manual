# Aktualisierung auf v7.3.0
So aktualisieren Sie von v7.2.x auf v7.3.0. Es ist eine Aktualisierung innerhalb von v7, aber <span class="red bold">v7.3 ist die eine Version, die `composer update` allein nicht erreicht.</span>

v7.3 stellt die Bibliothek der Verwaltungsbildschirme „exceedone/exment-admin-core“ von 1.x auf **2.x** um. Die bisherige `composer.json` legt admin-core auf `^1.0` fest, daher meldet ein einfaches `composer update` „Nothing to install, update or remove“ und die Website bleibt auf v7.2.x.

| | v7.2.x | v7.3.0 |
| ---- | ---- | ---- |
| PHP | 8.2 oder neuer | 8.2 oder neuer (unverändert) |
| exceedone/exment-admin-core | 1.x (`^1.0`) | **2.x (`^2.1.1`)** |
| QR-Code-Bibliothek | simplesoftwareio/simple-qrcode | bacon/bacon-qr-code 3.x |
| Laravel | 12 | 12 (unverändert) |
| MySQL / MariaDB | 8.0 oder neuer / 10.11 oder neuer | unverändert |

Bei einem Fehler siehe [Fehlerbehebung](/de/troubleshooting).

## 1. Sicherung erstellen
<span class="red bold">Erstellen Sie vor der Aktualisierung unbedingt eine Sicherung.</span>

- Sichern Sie die Datenbank und den ganzen Ordner von Exment (mit `composer.json`, `composer.lock`, `vendor`, `public/vendor`, `.env` und `storage`).
- <span class="red bold">Prüfen Sie selbst, dass die Sicherungsdatei vorhanden ist.</span> `php artisan exment:backup` kann ohne Fehler enden, auch wenn mysqldump fehlgeschlagen ist (z. B. bei einem selbstsignierten TLS-Zertifikat der Datenbank).

## 2. Mit composer installierte Website
Führen Sie im Ordner, in dem Exment installiert ist (Wurzel des Projekts), nacheinander aus:

~~~
# 1. nur wenn composer.json eine Zeile für simplesoftwareio/simple-qrcode hat
composer remove simplesoftwareio/simple-qrcode --no-update

# 2. exment und exment-admin-core von 7.3 (-W ist nötig)
composer require "exceedone/exment:^7.3" "exceedone/exment-admin-core:^2.1.1" -W

# 3. Datenbank und Übriges aktualisieren
php artisan exment:update --force
~~~

- **1.** Eine aus dem v7.2-Zip oder der Boilerplate installierte Website hat `simplesoftwareio/simple-qrcode` in ihrer `composer.json` (v7.3 nutzt es nicht). Die Aktualisierung klappt auch mit der Zeile, empfohlen wird aber, die ungenutzte Zeile zu entfernen.
- **2.** Fügen Sie `-W` (`--with-all-dependencies`) hinzu. Ohne bricht es mit einer Meldung wie „bacon … fixed to 1.0.2 by a partial update“ ab. Es bringt exment 7.3, exment-admin-core 2.1.1 oder neuer und bacon/bacon-qr-code 3.x (und fügt dasprid/enum hinzu).
    - Wenn die Website selbst `bacon/bacon-qr-code` 1.x verlangt, fügen Sie `"bacon/bacon-qr-code:^3"` in dieselbe Zeile ein.
- **3.** `--force` überspringt die Bestätigung auf einer Produktivwebsite (`APP_ENV=production`).
- Eine Website, deren `composer.json` weder exment-admin-core noch simple-qrcode nennt (nur `exceedone/exment`), aktualisiert mit einem einfachen `composer update` und `php artisan exment:update`.
- Drücken Sie am Ende im Browser **Strg+F5** (Neu laden).

## 3. Aus dem Zip installierte Website, Mietserver
Ersetzen Sie sie durch das Zip von v7.3.

1. `php artisan down` (Wartungsmodus).
2. Erstellen Sie die Sicherung wie oben.
3. Benennen Sie den Ordner um (z. B. `exment` → `exment_old`).
4. [Laden Sie](https://exment.net/download/) das Zip von v7.3 herunter und entpacken Sie es als Ordner mit dem alten Namen.
5. Löschen Sie `storage` im neuen Ordner und kopieren Sie **den ganzen `storage`** und **`.env`** aus dem alten Ordner.
6. Löschen Sie `bootstrap/cache/*.php` im neuen Ordner.
7. Führen Sie `php artisan exment:update --force` aus.
8. `php artisan up` (Ende des Wartungsmodus).

| | Vorgehen |
|---|---|
| `.env`, ganz `storage` (`app/admin`, `app/plugins`, `app/backup`, `app/templates`, `oauth-*.key` usw.) | Die alten unverändert verwenden |
| Dateien, die Sie in `public` abgelegt oder geändert haben, Änderungen von Hand in `config/*.php`, selbst mit composer verlangte Pakete (ldaprecord usw.) | Anhand des alten Ordners von Hand zurückholen |
| Eigener Code in `app/Exment/bootstrap.php` | Von Hand zurückholen (`exment:update` legt die Datei neu an) |
| `vendor`, `composer.json`, `composer.lock`, `public/vendor`, `bootstrap/cache` | Die neuen (die alten nicht verwenden; `exment:update` legt `public/vendor` neu an) |

## 4. Was sich in v7.3 ändert
### Plugins und eigener Code: Meldungen werden als Text angezeigt
Mit admin-core 2.x werden die Meldungen von `admin_info()`, `admin_success()`, `admin_warning()`, `admin_error()` (und `*_once()`) und `admin_toastr()` **als Text, nicht als HTML** angezeigt. Ein `<` in einem Namen oder Fehlertext wird so angezeigt, wie er ist – das ist sicher.

Verwendet eine Meldung HTML (`<br>`, einen Link usw.), umschließen Sie sie mit `admin_html_message()` und die Werte darin mit `e()` (oder `esc_html()`).

~~~php
// bis v7.2
admin_info('Fertig', $name . ' wurde erstellt.<br><a href="' . $url . '">Öffnen</a>');

// ab v7.3
admin_info('Fertig', admin_html_message(e($name) . ' wurde erstellt.<br><a href="' . e($url) . '">Öffnen</a>'));
~~~

Ohne das werden `<br>` usw. als Text angezeigt (es hört nichts auf zu funktionieren).

### Funktionsverwaltung
Viele der in v7.3 hinzugekommenen Funktionen werden unter „Systemeinstellung“ → „[Funktionsverwaltung](/de/feature)“ ein- oder ausgeschaltet. Einige neue Funktionen sind anfangs aus.

### Bildschirme
Im linken Menü öffnet sich ein Eintrag mit Untereinträgen zur Seite (die alte Art lässt sich in den Systemeinstellungen wählen). Siehe die [Versionshinweise](/release_note).

## 5. Exment SaaS
Exment SaaS wird vom Anbieter aktualisiert. Diese Schritte sind nicht nötig.

## 6. Zurück zur alten Version
Gehen Sie auf die vor der Aktualisierung erstellte Sicherung zurück.

1. Stellen Sie die Datenbank aus der vorher erstellten Sicherung wieder her.
2. Holen Sie `composer.json`, `composer.lock`, `vendor` und `public/vendor` von vorher zurück (Zip-Website: zurück zum umbenannten alten Ordner).
3. Löschen Sie den Inhalt von `bootstrap/cache` und führen Sie `php artisan optimize:clear` aus.

<span class="red bold">Verwenden Sie nicht `php artisan migrate:rollback`.</span> Einige Datenbankänderungen von v7.3 haben keinen Rückweg, Menüs und Spalten würden bleiben.
