# Zusätzliche Einstellungen
Nach den [Installationsschritten](/de/quickstart) läuft Exment.  
Für einige Funktionen sind aber zusätzliche Einstellungen nötig.  
Öffnen Sie in der Liste unten die Seite der Funktion, die Sie nutzen möchten, und stellen Sie sie nach der Anleitung ein.  

### Liste der Einstellungen

- [„admin“ in der URL ändern oder entfernen](/de/additional_prefix)  
Sie ändern oder entfernen den Wert, der vor den URLs steht, zum Beispiel „/admin“ (bei neuen Installationen ab v7.2.1 steht er standardmäßig nicht dabei).

- [Aufgabenplan](/de/additional_task_schedule)  
Die Einstellung, damit Verarbeitungen automatisch zu festen Zeiten laufen, zum Beispiel die automatische Sicherung oder Benachrichtigungen über Fristen.

- [Externe Serverkommunikation ausschalten](/de/additional_disable_outside_api)  
Die Einstellung, um die Kommunikation des Servers mit externen Servern zu stoppen, zum Beispiel das Abrufen der Update-Informationen von Exment.

- [Cache aktivieren](/de/additional_cache)  
Stammdaten wie benutzerdefinierte Tabellen, Spalten, Ansichten und Workflows werden im Cache gehalten. Je nach Umgebung wird Exment dadurch schneller.

- [Speicherort der Dateien ändern](/de/additional_file_saveplace)  
Die Schritte, um den Speicherort der Dateien vom lokalen Server auf FTP, AWS S3 usw. zu ändern.

- [PHP-Einstellungen ändern](/de/additional_php_ini)  
Die Schritte, um die Upload-Größe für Anhänge, den Speicherverbrauch von PHP und das Zeitlimit zu ändern.

- [IP-Filter](/de/additional_ip_filter)  
Anfragen an die Webseiten und Aufrufe der API lassen sich nach IP-Adresse einschränken.

- [Wenn bei der API der Fehler 429 auftritt](/de/additional_429_too_many)  
Was Sie tun, wenn beim Aufruf der API 429 Too Many Requests erscheint.

- [In der API zum Abrufen von Daten die Spalte label hinzufügen](/de/additional_api_label)  
Beim Abrufen der Datenliste und beim Anlegen oder Aktualisieren von Daten können Sie dem Ergebnis die Spalte "label" hinzufügen.

- [Eigene Optionen für die Einstellung „Zulässige Zeichen“ des Spaltentyps „Einzeiliger Text“ hinzufügen](/de/additional_available_characters)  
Für die Einstellung „Zulässige Zeichen“ des Spaltentyps „Einzeiliger Text“ der benutzerdefinierten Spalten können Sie nutzbare Optionen hinzufügen.

- [Verzögerte Ausführung der Benachrichtigungen](/de/additional_queue)  
Einige Verarbeitungen wie Benachrichtigungen können später ausgeführt werden (Ausführung über die Warteschlange).

- [Einstellungen für den Reverse-Proxy](/de/additional_reverse_proxy)  
Die zusätzlichen Einstellungen, die in einer Umgebung mit Reverse-Proxy nötig sind.

- [Die Volltextsuchmaschine (Meilisearch) nutzen](/de/additional_meilisearch)  
Die Einstellung, um in Umgebungen mit vielen Daten mit der Volltextsuchmaschine „Meilisearch“ schnell zu suchen.

- [Expertenmodus](/de/additional_expert)  
Die Schritte, um feinere Einstellungsfelder auf dem Bildschirm anzuzeigen.
