# Flow until starting business with Exment
This is the flow from installing Exment until you start using it in your work.  
It shows who does what, for each role.

### Role
The people involved in Exment have the following four roles. The person in charge of each role makes the settings of Exment.  
Note: depending on the company, one person can have several roles; for example, the infrastructure staff can also be the administrator.

- ##### Infrastructure staff  
→ The person who does the work around the server, such as installing Exment on the server and updating it

- ##### Administrator  
→ The person who makes the settings for using Exment, such as the initial settings after the installation and adding tables and columns

- ##### User (general user)  
→ The person who adds, edits and deletes data, using the tables prepared by the administrator

- ##### Developer  
→ The person who develops extensions of Exment when a special feature is needed, for example when plugins are used  

### Steps

#### [Infrastructure personnel]
- [Install](/quickstart)  
Install Exment on the server.  

- [Update](/update)  
When a new version of Exment is released, log in to the server and update.  

#### [Administrator]
- [Initial setting](/first_setting)  
Right after the installation, register the necessary items, such as the site name and the login ID of the first administrator.

- [Custom table settings](/table)  
Register the things you want to manage, such as "Customer management" and "Task management", as tables.  

- [Custom column setting](/column)  
Register the items you want to manage, such as "customer name", "zip code" and "address" of the "Customer management" table, as columns.

- [Template](/template)  
With the templates that are provided, you can add custom tables and custom columns together, without making them from scratch.

##### 【Other necessary settings】

- [User / Login User](/user)  
Set the ID and the password with which general users log in to Exment.

- [Roles / Privileges](/permission)  
Decide, for each user, the range that the user can operate in Exment.

- [Menu](/menu)  
Manage the menu items that are always shown on the left of the screen.  

#### 【User (general user)】
- [Data](/data)  
Add, update, view and delete data in the custom tables set up by the administrator.  

- [Search](/search)  
You can easily search the saved data.  


#### 【Developer】
- [Plugin](/plugin_quickstart)  
When you need to extend the features of Exment, you can upload a plugin and add features.
