# Plugins oficiales
Los plugins oficiales son plugins gratuitos de Exment creados, probados y mantenidos por Exceed One. El código fuente de todos ellos es público ([exceedone/exment-plugins](https://github.com/exceedone/exment-plugins), GPL-3.0).

| Plugin | Qué permite hacer |
| --- | --- |
| [Gestión de proyectos](/es/plugin_pm) | Proyectos e incidencias (tickets), tablero, diagrama de Gantt, Wiki y archivos |
| [Soporte de TI](/es/plugin_it_support) | Mesa de ayuda. Gestiona con tickets las solicitudes por correo, formulario de recepción y teléfono, y comparte el avance con el cliente sin iniciar sesión |
| [Groupware](/es/plugin_groupware) | Correo web, y abrir y editar en el navegador los archivos de Office de Archivos compartidos |

## Cómo instalarlos
### Exment v7.2.1 o posterior
Los plugins oficiales llegan junto con Exment. Se instalan cuando el administrador del sistema pulsa "Usar (instalar)" en el apartado "[Plugins oficiales gratuitos (incluidos con Exment)](/es/feature)" de "Configuración de administración" → "Gestión de funciones". Hasta que se pulsa, no se instalan ni se cargan.

- Exment 7.2.1 incluye Gestión de proyectos (ExmentPM) 1.7.15, Soporte de TI (ExmentITSupport) 1.0.9 y Groupware (ExmentGroupware) 0.4.7 (paquete exceedone/exment-plugins-release 7.2.14).
- Los plugins incluidos se instalan después de comprobar la firma de Exceed One.
- Cuando hay una versión nueva, solo se avisa. Se actualiza con "Actualizar a esta versión" y se puede volver atrás con "Volver a la versión anterior (○○)".
- Cuando hay una versión nueva con una corrección de seguridad, se avisa al administrador del sistema. Para más detalles, vea [Gestión de funciones](/es/feature).
- Groupware crea "Correo" en el menú de la izquierda al instalarlo.
- Actualizar Exment trae las versiones incluidas nuevas, pero los plugins en uso no se cambian solos ([Las actualizaciones y los plugins oficiales incluidos](/es/update?id=las-actualizaciones-y-los-plugins-oficiales-incluidos)).

### Versiones anteriores de Exment
Descargue el zip desde [Releases](https://github.com/exceedone/exment-plugins/releases) de GitHub y cárguelo en "Configuración de administración" → "[Plugin](/es/plugin)". No lo descomprima (no use el botón verde "Code → Download ZIP").

### Exment SaaS
También en Exment SaaS (`*.exments.com`), cuando el administrador del sistema del inquilino pulsa "Usar" en "Gestión de funciones", la instalación y la configuración inicial se hacen automáticamente. El paso a una versión nueva lo hace el operador del servicio, que en ese momento también actualiza la estructura de datos y lo demás.
