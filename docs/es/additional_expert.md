# Modo experto
Es un modo para las personas que conocen bien el sistema, que permite usar ajustes más detallados.  
Con el modo experto se pueden hacer los siguientes ajustes.

- Cuando la columna personalizada es "Texto de una línea", validación del contenido introducido mediante una expresión regular
- La [configuración de operaciones que no se pueden ejecutar desde la pantalla](/es/table) de la configuración de tablas personalizadas
- En la [Configuración del formato de encabezado](/es/table) de la configuración de tablas personalizadas, la configuración mediante columnas de parámetros

### Pasos de configuración 
- Añada el siguiente contenido al archivo .env y guarde.

~~~
EXMENT_EXPART_MODE=true
~~~

- Con esto, los ajustes de arriba se muestran en pantallas como la configuración de tablas personalizadas y la configuración de columnas personalizadas.
