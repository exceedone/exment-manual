# Desactivar la comunicación externa del servidor
Es el ajuste que detiene la comunicación del servidor de Exment con otros servidores.  
Se usa en entornos que no se comunican con otros servidores, como un entorno totalmente local (on-premise).

Exment puede comunicarse con otros servidores para los siguientes fines.

- Para saber si hay una versión más reciente de Exment, se comunica con el sistema de paquetes y obtiene la información de la última versión.
- Para mostrarla en la "Lista de novedades de Exment" del panel, se comunica con el sitio oficial de Exment (exment.net) y obtiene las novedades.

### Pasos de configuración 
> Este procedimiento cambió a partir de v1.3.0.

1. Desde el menú de la izquierda, abra la pantalla "Configuración del sistema".
2. En la lista, ponga en NO el elemento "Permitir comunicación externa del servidor".  
![Desactivar la comunicación externa del servidor](../img/quickstart/outside_api.png)
3. Guarde. Con esto, la configuración ha terminado.
