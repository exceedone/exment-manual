# 大量数据批量导入
这是用服务器的命令，把准备好的 csv 文件中的大量数据一次性放入自定义表的功能（批量插入。1000条以上也可以）。  
因为重视速度，所以不进行细致的错误检查。

流程如下。

1. 制作 csv 文件（“准备数据”）
2. 放到服务器的文件夹中，执行命令（“操作方法”）

## 注意事项
批量插入重视速度。因此，请注意以下几点。

- **即使制作的 csv 或数据内容有问题，也不进行细致的错误检查。** 制作文件时请仔细确认。出现问题时，请试着把一部分数据用页面上的导入功能导入，以便确认。

- [普通的导入](/zh/data_import_export)中可以做到的“[更改其他表数据的指定方法](/zh/data_import_export)”，在此功能中不能使用。请把 id 写在列中再导入。


## 准备数据
首先，制作导入用的 csv 文件。

| 规则 | 内容 |
| ---- | ---- |
| 第1行 | 自定义表的列名 |
| 第2行及以后 | 要导入的数据 |
| 文件名 | **“(自定义表的名称).csv”** (例：client.csv)。要放入1个表的数据分成多个文件时，像 **“(自定义表的名称).序号.csv”** (例：client.01.csv)这样加上序号 |
| 字符编码 | <strong>UTF-8</strong>（无 BOM） |

**用 EXCEL 制作文件时，字符编码一开始是 Shift JIS。请务必先用文本编辑器等转换字符编码。**  

### 可以用作自定义表列名的值
| 项目 | 说明 |
| ---- | ---- |
| id | 主键(数值) ※只在想指定时输入 |
| parent_type | 父表的名称 ※只在是子表的数据时输入 |
| parent_id | 所关联的父数据的ID ※只在是子表的数据时输入 |
| deleted_at | 数据的删除时间 ※只在想指定时输入 |
| deleted_user_id | 删除数据的用户ID ※只在想指定时输入 |
| value.(自定义列的列名) | 在自定义列设置中登记的列名。请务必在开头加上 value. |

- 没有特别的理由时，csv 文件中请只写自定义列（其他项目会自动填入）。  
- **与普通的导入不同，即使指定与现有数据相同的 id，也不会更新。**  

#### 示例文件（client.csv）
- 这是向客户表（client）放入数据的示例。放入客户代码(client_code)和客户名称(client_name)，只在第3条数据中放入了删除时间(deleted_at)和删除用户ID(deleted_user_id)。

CUST002,测试客户名００２,,

CUST008,测试客户名００８,,
CUST009,测试客户名００９,,
~~~

## 操作方法

1. 在服务器的以下位置创建工作用的文件夹。文件夹名建议使用能看出这次工作内容的名称或日期等。  

~~~
(项目的根目录)/storage/app/bulkinsert/(文件夹名)
~~~

2. 把制作的 csv 文件（可以多个）放到该文件夹中。

#### 文件夹的放置示例
![批量导入用的工作文件夹](../img/bulkinsert/folder1.png)  

3. 在命令行中执行以下命令。
~~~
php artisan exment:bulkinsert {文件夹名}
~~~
