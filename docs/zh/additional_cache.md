# 启用缓存
把设置等主数据放入缓存（先临时保存，下次起直接使用的机制）。  
这样对数据库的访问次数会减少，在有些环境下速度会变快。

主要把下面的数据放入缓存。

- 系统设置
- 自定义表
- 自定义列
- 表单设置
- 视图设置
- 工作流设置
- 能否连接数据库
- 其他主数据信息

### 设置步骤 
- 在 .env 文件中添加下面的内容，然后保存。

~~~
EXMENT_USE_CACHE=true
~~~

### 想删除缓存时 
- 缓存会定期更新。想马上删除时，请执行下面的命令。

~~~
php artisan cache:clear
~~~
