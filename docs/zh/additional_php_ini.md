# 更改 PHP 设置值

这是更改 PHP 设置值的步骤。可以更改下面 4 项。

| 设置 | 更改后会怎样 |
| ---- | ---- |
| 更改文件上传大小上限 | 可以从页面上传的文件大小会改变 |
| 更改内存量 | Exment(PHP) 使用的内存量会改变 |
| 更改超时时间 | 耗时较长的处理不容易在中途停止 |
| 一次可以 POST 的上限数 | 项目很多的页面也可以保存 |

更改方法请看下面的“[设置方法](/zh/additional_php_ini?id=设置方法)”。


#### 更改文件上传大小上限
Exment 有从页面上传文件的功能。  
可以上传的文件大小，每台服务器都有上限。  
（最初的上限因安装的服务器而不同）  

#### 更改内存量
更改 Exment(PHP) 使用的内存量。  
内存量越大，处理越快，一次可以执行的内容也会改变。但是，太大时可能影响服务器的运行。

#### 更改超时时间
更改 PHP 的超时时间（到中止处理为止的时间）。  
把时间加长后，导入、导出、备份等耗时较长的功能可以更可靠地执行。  
※对耗时较长的功能，Exment 的代码里本来就加入了延长超时时间的处理。但是，在有些环境下这个处理不起作用。经常发生超时时，请进行这项设置。

#### 一次可以 POST 的上限数
决定一次可以 POST（可以从页面发送）的项目数的上限。  
在输入数据的页面中，项目数超过上限时，可能无法正常运行。  
※主要在下面的页面中，可能因上限不够而出错。  

- 在工作流使用设置中，表的数量、工作流的数量很多时
- 在自定义表单设置页面中，要登记的列的项目非常多时
- 在自定义数据输入页面中，项目非常多时




## 设置方法
请用设置方法 1、2 中的任意一种进行设置。


### 设置方法1 修改 php.ini

1. 打开安装 PHP 的文件夹中的“php.ini”文件。※php.ini 文件的位置因环境而不同。

2. 修改 php.ini 文件中下面的值。※大多已经写有数值，请改写数值。

~~~
### 更改文件上传大小上限
#POST 数据允许的最大大小
post_max_size=20M
#1 个上传文件允许的最大大小
upload_max_filesize=20M


### 更改内存量
# 改为 512M 时
memory_limit=512M
# 改为无限制时
memory_limit=-1


### 更改超时时间
#改为 240 秒时
max_execution_time=240
#改为无限制时
max_execution_time=0


### 更改一次可以 POST 的上限数
#改为 3000 件时
max_input_vars=3000
~~~

3. 重新启动服务器。


### 设置方法2 修改 .htaccess 文件
1. 打开安装 Exment 的文件夹中的“public/.htaccess”文件。

2. 添加下面的值。

~~~
### 更改文件上传大小上限
#POST 数据允许的最大大小
php_value post_max_size 20M
#1 个上传文件允许的最大大小
php_value upload_max_filesize 20M


### 更改内存量
# 改为 512M 时
php_value memory_limit 512M
# 改为无限制时
php_value memory_limit -1


### 更改超时时间
#改为 240 秒时
php_value max_execution_time 240
#改为无限制时
php_value max_execution_time 0


### 更改一次可以 POST 的上限数
#改为 3000 件时
php_value max_input_vars 3000
~~~

3. 重新启动服务器。
