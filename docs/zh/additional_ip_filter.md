# IP 筛选
这是决定哪些 IP 地址可以访问 Exment 的网页和 API 的设置。

- 只登记允许访问的 IP 地址（白名单方式）。
- 网页用和 API 用分开登记。例如，也可以“只限制能执行 API 的 IP 地址”。


### 设置步骤
1. 把 Exment 设为专家模式。还没有设为专家模式时，请打开“.env”文件，添加下面的值。

~~~
EXMENT_EXPART_MODE=true
~~~

2. 打开系统设置页面。页面中已添加 IP 筛选的项目。

![IP 筛选设置](../img/quickstart/ip_filter.png)

#### 设置内容详情

| 想做的事 | 输入方法 | 例 |
| ---- | ---- | ---- |
| 指定 1 个 IP 地址并允许 | 直接输入 IP 地址 | 123.4.5.6 |
| 按范围允许 IP 地址 | 用子网掩码的形式输入 | 例1： 123.4.0.0/16 → 允许从 123.4.0.0 到 123.4.255.255 访问<br>例2： 123.4.10.0/24 → 允许从 123.4.10.0 到 123.4.10.255 访问 |
| 在 localhost 上搭建的服务器中，允许从 localhost 访问 | 输入“::1” | ::1 |
| 允许多个 IP 地址 | 用换行分隔输入。只要符合其中 1 个，就可以访问 | |


#### 强制关闭 IP 限制
网页的 IP 地址设置错了、无法访问时，可以用下面的步骤停止 IP 限制。

- 打开“.env”文件，添加下面的值。

~~~
EXMENT_DISABLE_IP_FILTER=true
~~~
