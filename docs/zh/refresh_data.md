# 刷新自定义数据
这是用命令一次删除（刷新）已登记的自定义数据的步骤。  
设置（表的定义、系统设置等）保留，只删除数据。在下面这些时候使用。

- 验证环境之后，想把登记的数据全部删除，再验证一次。
- 从测试环境移到正式环境之后，想把正式环境的数据全部删除，再开始使用。

命令有 2 个。

| 想做的事 | 命令 | 看哪里 |
|---|---|---|
| 一次删除所有自定义表的数据 | `php artisan exment:refreshdata` | “所有表的数据” |
| 只删除指定的表的数据 | `php artisan exment:refreshtable` | “指定的自定义表的数据” |

无论哪个命令，都建议在执行之前备份数据。

## 所有表的数据
对象是所有的表。  
执行命令后，会删除下面“被删除的数据”中的全部内容。id 的连续编号也从 1 开始。


### 被删除的数据（也包括内部表）
- 访问日志
- 电子邮件地址的验证表
- 通知栏的数据
- 更新历史
- 工作流的作业用户对象
- 工作流的执行状态
- 自定义数据的共享
- n:n 的关联数据（组织-用户除外）
- 自定义数据（用户、组织、通知模板除外）
- 自定义数据的附件（用户、组织、通知模板除外）

### 不被删除的数据
- 系统设置
- 自定义表的设置值
- 工作流设置
- 其他与系统相关的设置值
- 登录信息
- 用户信息、组织信息、通知模板的数据
- 组织-用户的所属信息

### 执行方法
- <span class="red bold">※建议在执行这个命令之前备份数据。</span>
- 请执行下面的命令。

~~~
php artisan exment:refreshdata
~~~


## 指定的自定义表的数据
对象是指定的自定义表。  
不是全部一次删除，而是根据数据的种类，删除的方式不同（下面 3 种）。  
※用户、组织、通知模板的数据不能刷新。

### 全部删除、id 连续编号变为 1 的数据
- 指定的自定义表中的数据
- 指定的自定义表是 1:n 关联的父方时，子方自定义表中的数据
- 指定的自定义表是 n:n 关联的父方、子方时，n:n 的关联数据信息。※关联对方的自定义表中的数据本身不删除。

### 只删除与删除对象的表相关的数据（也包括内部表）
- 通知栏的数据
- 更新历史
- 工作流的作业用户对象
- 工作流的执行状态
- 自定义数据的共享
- 自定义数据的附件、评论

### 更新为空值
- 删除对象的表在其他自定义表的自定义列“选项（从其他表中选择）”中被使用时，那个自定义表中的数据会被一次更新，让引用的值变为空。


### 执行方法

- <span class="red bold">※建议在执行这个命令之前备份数据。</span>
- 请执行下面的命令。

~~~
php artisan exment:refreshtable {表名。多个时用""括起来，以逗号分隔}

# 例：对 1 个表执行
php artisan exment:refreshtable information

# 例：对多个表执行
php artisan exment:refreshtable "table1,table2,table3"
~~~
