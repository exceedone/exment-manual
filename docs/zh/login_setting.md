# 登录设置
这是决定登录 Exment 时的规则的页面。可以设置密码的规则（密码策略）和双重验证。  
用命令重置密码的方法也在本页。

> 关于 SSO 的设置和说明，请看[这里](/zh/login_sso)。


## 双重验证
Exment 支持双重验证。  
输入用户信息登录后，再输入电子邮件中收到的验证码或 Google 身份验证器上显示的验证码，就可以使用 Exment 了。  
※双重验证可以在登录方式为“标准”“LDAP”时使用。

- [双重验证 系统设置](/zh/login_2factor_setting)
- [登录（双重验证）](/zh/login_2factor)


## 登录设置的管理方法

- 系统管理员打开下面的 URL。  
http(s)://(Exment的URL)/login_setting  
※进行上面写的“更改系统设置”后，就可以访问了。

> ※这里的 URL 是不带“/admin”的标准设置（v7.2.1 以后新安装的站点）的情况。`.env` 的 `ADMIN_ROUTE_PREFIX` 有值时（用以前的版本安装的站点是“admin”），请在站点的 URL 后面加上这个值（例：`http(s)://(Exment的URL)/admin/oauth/token`）。详情请看[更改或删除 URL 中包含的“admin”](/zh/additional_prefix)。

- v7.1.0 以后，也可以从左侧菜单的“管理员设置”→“登录设置”打开。
- v7.0 以前，“登录设置”一开始不显示在菜单中。要加到菜单中，请打开“管理员设置” > “菜单”页面，选择菜单类型“系统菜单”。对象中会出现“登录设置”，请选择并保存。

![登录设置列表](../img/login/login_setting4.png)  

- 双重验证的设置按下面页面的步骤进行。

    - [双重验证 系统设置](/zh/login_2factor_setting)


### 密码策略设置
决定关于登录密码的规则。   

![密码策略设置页面](../img/system_setting/system_setting_password.png)  

#### 复杂密码
- 设为 YES 后，密码必须是包含 3 种以上字符（半角英文大写字母、半角英文小写字母、半角数字、半角符号）的 12 个字符以上。
- 初始值是“NO”。

#### 密码有效天数
- 过了设定的天数之后，第一次登录时会显示更改密码的页面。请更改密码后再登录一次。
- 把有效天数设为“0”时，密码没有期限。
- 初始值是“0”。

#### 首次登录时要求更改密码
- 设为 YES 后，用户第一次登录时会显示更改密码的页面。
- 对象是把这个设置设为 YES 之后新登记的用户和重置了密码的用户。
- 在设为 YES 之前进行了新登记等的用户不是对象。
- 初始值是“NO”。

#### 密码历史记录数
- 不让最近用过的密码再次使用。新密码与最近的历史记录数之内的任何一个密码相同时，会报错。
- 把历史记录数设为“0”时，不进行比较。
- 初始值是“0”。

#### 注意

- <span class="small">“复杂密码”和“密码历史记录数”在用户设置页面、重置密码的页面等由用户自己决定密码时使用。系统管理员决定密码时不在此范围内。</span>


### 其他
- 从低于 v3.3.0 的版本更新到 v3.3.0 以上时，用用户代码中包含“点（.）”的提供商登录，可能会出错。  
这时请按下面这样修改。
    - 在“用户”表的“自定义列设置”中，打开“用户代码”列的编辑页面。
    - 在“可用字符”选项中勾选“点”并保存。


- 初始设置中，即使在登录状态下关闭浏览器，在经过一定时间（120 分钟）之前，登录状态仍然保持。  
v3.6.0 以后，可以设置为关闭浏览器时自动退出登录。请打开“.env”文件，按下面这样追加。  
※设置文件的修改方法请看[设置值一览](/zh/config)。

~~~
EXMENT_SESSION_EXPIRE_ON_CLOSE=true
~~~




## 密码重置命令
可以用命令重置用户的密码。

- 系统管理员在控制台中执行下面的命令。

~~~
php artisan exment:resetpassword --email=foobar@test.com --password=P@ssw0rd!
~~~

- 这个命令给电子邮件地址为"foobar@test.com"的用户设置密码"P@ssw0rd!"。


### 命令的参数

```
exment:resetpassword {--id=} {--email=} {--user_code=} {--password=} {--random=0} {--send=0} {--reset_first_login=0}
```

#### 参数：指定用户
※下面的参数中，必须指定其中 1 个。指定了多个时，按 id > email > user_code 的顺序优先查找。

- ##### id
目标用户的登录 ID。

- ##### email
目标用户的电子邮件地址。

- ##### user_code
目标用户的用户代码。


#### 参数：密码
※请指定 "password" 或 "random=1" 中的一个。两个都指定时，"password" 优先。

- ##### password  
请指定新密码的字符串。

- ##### random  
要随机生成密码时，请指定 1。未指定时为 0。

#### 参数：选项

- ##### send  
要把新密码用邮件发送给目标用户时，请指定 1。未指定时为 0。

- ##### reset_first_login  
更改密码后，用户第一次登录时显示更改密码的页面。未指定时为 0。  
※即使不指定这个选项，只要在登录设置中把“首次登录时要求更改密码”设为 YES，用户第一次登录时也会显示更改密码的页面。

### 特别说明
- 指定了 "random=1" 而没有指定 "send=1" 时，重置之后会把新密码输出到控制台。


### 命令执行示例

~~~
# 例 : 给 id1 的用户指定密码并重置
php artisan exment:resetpassword --id=1 --password=P@ssw0rd!

# 例 : 给用户代码为"user1"的用户设置随机密码，并发送邮件
php artisan exment:resetpassword --user_code=user1 --random=1 --send=1

# 例 : 给电子邮件地址为"foobar@test.com"的用户设置随机密码
php artisan exment:resetpassword --email=foobar@test.com --random=1
密码已重置。新密码：XXXXXXXXXX #更改后的密码会输出到控制台
~~~
