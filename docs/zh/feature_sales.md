# 销售（CRM・SFA）
一次性加入用于管理客户、商机、报价、合同和活动记录的表、视图、仪表板、菜单等的功能。它是[功能管理](/zh/feature)中的一行。

※此功能可在 Exment v7.3.0 及以后使用。  
※一开始是“不使用”。设为“使用”后，下面“加入的内容”会在站点中创建。

## 设为“使用”
用下面任一方法。

- **在功能管理中**：以系统管理员登录，打开“管理员设置”→“[功能管理](/zh/feature)”。把“Exment 的功能”中的“销售（CRM・SFA）”设为“使用”并保存。
- **在初始设置页面中**：新安装时，在[初始设置页面](/zh/first_setting)的“功能”栏勾选“使用销售（CRM・SFA）吗？”。保存初始设置后加入。之后也可以在功能管理中设为“使用”。

加入后，会显示已加入表、视图、仪表板、菜单等的消息。  
然后，请在[角色组](/zh/role_group)页面把使用的人加入角色组“销售”。

※谁可以使用不是在功能管理中决定，而是由角色组“销售”（表的权限）决定。  
※加入的菜单可以在菜单页面移动或移除。

## 加入的内容

### 表
| 表 | 表名 | 主要列 |
| --- | --- | --- |
| 客户 | `sales_customer` | 客户名、类别（潜在客户、交易中、已终止交易）、地址、电话、邮件、网站、负责人 |
| 客户联系人 | `sales_customer_contact` | 姓名、部门、职务、电话、邮件（客户中的行） |
| 商机 | `sales_deal` | 商机名、客户、阶段、预计金额、预计成交日、确定度、负责人 |
| 报价 | `sales_quote` | 标题、客户、商机、报价日、有效期、合计 |
| 报价明细 | `sales_quote_detail` | 品名、数量、单位、单价、金额（报价中的行） |
| 合同 | `sales_contract` | 合同名、客户、商机、签约日、开始日、结束日、自动续约、金额、合同文件 |
| 活动记录 | `sales_activity` | 种类（拜访、电话、邮件、下一步）、标题、日期时间、客户、商机、负责人（一开始是登录的人）、内容 |

### 视图
- **按阶段的看板**（商机）：按阶段排列商机的[看板视图](/zh/view_kanban)。每个阶段显示预计金额的合计。移动卡片会改变阶段。
- 仪表板使用的视图（下面仪表板的 5 个框）

### 销售仪表板
在菜单“销售与客户”的最上面加入“销售仪表板”。显示以下 5 个：

- 每月预计订单（柱状图）
- 按负责人的进行中商机：件数和预计金额
- 本月活动
- 即将到期的报价（14 天）
- 即将结束的合同（30 天）

### 菜单
加入菜单“销售与客户”，其中有销售仪表板、客户、商机、报价、合同、活动记录。可以在[菜单](/zh/menu)页面移动或移除。

### 通知
“合同即将到期（30 天前）”：在合同结束日 30 天前的 9 点，用 Exment 内的通知告诉创建该合同的人和可以查看合同的人。天数等可以在[通知](/zh/notify)页面修改。

### 角色组“销售”
可以查看、创建、修改上面 7 个表的所有数据的角色组。把使用的人加入这里。

## 注意
- **中途失败时**：已经创建的内容会保留。会显示消息，该行回到“不使用”。再次设为“使用”并保存，只创建缺少的内容。在初始设置页面失败时，初始设置也会照常完成；请之后在功能管理中设为“使用”。
- **无论设为“使用”多少次**，都不会重复创建。站点修改过的内容（表和视图的名称、标签、通知的天数、角色组、菜单）也会保留。
- **删除的内容会再次创建**：删除表或视图后，先设为“不使用”再设为“使用”，删除的内容会再次创建。不需要的内容，请从菜单中移除，而不是删除。
- **设为“不使用”不会删除任何内容，也不会隐藏任何内容**：表、数据、视图、仪表板、菜单、通知和角色组都会保留，菜单也照常显示。不再使用时，请从[菜单](/zh/menu)中移除，或把人从角色组中移除。
- **已有同名的表时**：如果站点已经有与销售表同名的自己的表（`sales_customer`、`sales_deal` 等以 `sales_` 开头的表），不会创建新表，而是给这些表加入缺少的列。现有的列和数据保持不变。
- **装过旧的销售模板的站点**：在装过旧[模板](/zh/template)“Sales pack”（営業パック）的站点，和上面一样只加入缺少的内容。商机的阶段列保留旧名称（日语为「状態」；新安装的站点为「段階」）。想修改时，请在[自定义列](/zh/column)页面修改。

## 用服务器的设置禁止
在服务器 `.env` 的 `EXMENT_FEATURES_LOCKED` 中写上 `sales`，此功能会固定为“不使用”，也不会显示在初始设置页面。详见[用服务器的设置固定](/zh/feature?id=用服务器的设置固定)。
