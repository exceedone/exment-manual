# 用 Exment 开始业务之前的流程
这是从安装 Exment 到在业务中开始使用的流程。  
按角色整理了由谁、做什么。

### 角色
与 Exment 有关的人有下面 4 种角色。各负责人分别进行 Exment 的设置。  
※在有些公司，一个人会担任多个角色，例如基础设施负责人同时兼任管理员。

- ##### 基础设施负责人  
→在服务器上安装、更新 Exment 等，做服务器方面工作的人

- ##### 管理员  
→做安装之后的初始设置、添加表和列等，为使用 Exment 进行设置的人

- ##### 用户（一般用户）  
→使用管理员准备好的表，登记、编辑、删除数据的人

- ##### 开发者  
→在使用插件等需要特别功能的时候，做扩展 Exment 的开发的人  

### 步骤

#### 【基础设施负责人】
- [安装](/zh/quickstart)  
在服务器上安装 Exment。  

- [更新](/zh/update)  
Exment 出了新版本时，登录服务器进行更新。  

#### 【管理员】
- [初始设置](/zh/first_setting)  
安装之后，马上登记网站名称、第一个管理员的登录 ID 等必要的项目。

- [自定义表设置](/zh/table)  
把“客户管理”“任务管理”等想管理的东西登记为表。  

- [自定义列设置](/zh/column)  
把“客户管理”表的“客户名”“邮政编码”“地址”等想管理的项目登记为列。

- [模板](/zh/template)  
使用准备好的模板，不用从头创建自定义表和自定义列，就可以一起添加。

##### ■其他必要的设置

- [用户和登录用户](/zh/user)  
设置一般用户登录 Exment 用的 ID 和密码。

- [角色和权限](/zh/permission)  
为每个用户决定在 Exment 中可以操作的范围。

- [菜单](/zh/menu)  
管理一直显示在页面左侧的菜单项目。  

#### 【用户（一般用户）】
- [数据](/zh/data)  
在管理员设置的自定义表中添加、更新、查看、删除数据。  

- [搜索](/zh/search)  
可以很简单地搜索已登记的数据。  


#### 【开发者】
- [插件](/zh/plugin_quickstart)  
需要扩展 Exment 的功能时，可以上传插件来增加功能。
