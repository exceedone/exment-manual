# 甘特图视图

把数据做成从开始日期到截止日期（结束日期）的横条，并按时间顺序显示的视图。

## 什么是甘特图视图

甘特图是用横条表示每项工作的期间，并排列在日期刻度上显示的图。  
哪项工作计划从何时到何时，到今天为止哪项工作已经过了期限，一眼就能看出。

Exment 的甘特图视图可以做到以下事情。

- 把1条数据显示为从开始日期列到截止日期（结束日期）列的1根横条
- 按选项列的值，给横条分颜色
- 把进度叠加显示在横条中，并用红框强调过了期限仍未完成的数据
- 按选项或里程碑（从其他表中选择）把行分组，并用◆标记显示里程碑的期限
- 把有父子关系的数据缩进显示在父数据的下面
- 用图标显示负责人

※甘特图仅用于显示。不能在图上拖动横条来更改日期。要更改日期等内容时，请在数据的编辑页面更改。

## 新建视图

1. 打开自定义视图设置页面（请参阅[自定义视图](/zh/view)）。
2. 点击右上角的［新建］按钮。
3. 在显示的对话框中选择“新建甘特图视图”。

也可以从数据列表页面［视图］按钮的菜单中选择“新建甘特图视图”。这时，保存后会用该视图显示数据列表。

※表中1个“日期”或“日期和时间”的列都没有时，不显示“新建甘特图视图”。

#### 视图显示名称、视图权限、默认、使用视图信息框
与[视图的设置项目](/zh/view)相同。

## 基本设置

#### 开始日期列
作为横条开始位置的日期列。（必填）  
※只能指定“日期”“日期和时间”的列。“日期和时间”的列只使用日期部分。

#### 截止日期（结束日期）列
作为横条结束位置的日期列。（必填）  
横条从开始日期显示到截止日期（包含这两天）。  
※只能指定“日期”“日期和时间”的列。  
※截止日期在今天之前，并且进度不到100的数据，作为“已逾期”，横条显示红框，行左侧的截止日期显示为红字。没有设置“进度列”时，或进度未输入时，也作为已逾期处理。

#### 条形颜色（选项列）
按此列的值，给横条分颜色。图的上方会显示值和颜色的图例。  
※只能指定“选项（固定值）”“选项（登记值和标签）”的列。多选的列按第1个值分颜色。  
※颜色直接使用该列的“按值设置颜色”（包括列上设置的[显示预设](/zh/cell_style_preset)）。没有指定颜色的值，会按选项的顺序自动分配颜色。  
※不设置时，所有横条都显示为蓝色。

#### 进度列（0-100）
在横条中，按进度（%）的比例叠加显示较深的颜色。  
※只能指定“整数”“小数”“货币”的列。  
※值按0～100处理。小于0的显示为0，超过100的显示为100。

## 高级设置

#### 分组依据列
按此列的值，把行分组显示。不指定时，不分组显示。  
※只能指定“选项（固定值）”“选项（登记值和标签）”“选项（从其他表中选择）”的列（非多选的列）。

分组的排列顺序如下。

| 列的类型 | 排列顺序 |
| --- | --- |
| 选项（固定值）、选项（登记值和标签） | 选项的排列顺序 |
| 选项（从其他表中选择） | 按引用数据的期限由近到远。没有期限的排在最后 |

- 指定“选项（从其他表中选择）”的列（引用里程碑表的列等）时，引用数据的期限会显示在分组的标题行，并在图上用◆标记显示。
- 值未输入的数据，在最后作为“未分组”分组显示。
- 1条数据都没有的值的分组不显示。

※引用数据的期限，使用引用表的日期列（“日期”“日期和时间”）中，列名包含“due”“end”“limit”“deadline”“期限”之一的第一个列。没有符合的列时，使用最后一个日期列。没有日期列时，不显示◆标记。

#### 父级列（引用本表）
选择引用本表的列后，子数据会紧接在父数据的下面，加上“└”缩进显示。  
※只能指定“选项（从其他表中选择）”的列中，引用对象是此表自身的列。  
※只缩进1层。孙级及以后的数据，在分组的最后不缩进显示。  
※父数据没有显示在同一分组中时，子数据作为普通的行显示。

#### 负责人列
选择用户列后，各行会显示负责人的图标（用户名的第1个字）。把鼠标放到图标上，会显示用户名。  
※只能指定“用户”的列，或引用对象是用户表的“选项（从其他表中选择）”的列。多选的列显示第1个人。

#### 最大显示条数
图中显示的数据的最大件数（10～2000，初始值500）。  
※未输入时，或值在范围之外时，按500件处理。  
※符合显示条件的数据超过这个件数时，会显示“显示件数超过上限（○ 件）。请通过显示条件缩小范围。”，超出部分的数据不显示。

## 数据排序、视图筛选条件

与[视图的设置项目](/zh/view)中的“数据排序”“视图筛选条件”相同。  
用“视图筛选条件”筛选图中显示的数据。

※图上的行，无论“数据排序”如何设置，都在各分组内按开始日期由早到晚显示（开始日期未输入的数据排在最后）。“数据排序”用于在数据超过“最大显示条数”时，决定显示哪些数据的顺序。

## 图的使用方法

### 页面说明

#### 工具栏

| 位置 | 内容 |
| --- | --- |
| 左侧 | 图例。显示“条形颜色”的值和颜色、表示今天的“│ 今天”；有里程碑的期限时，还显示“◆ 截止”。 |
| 右侧 | 显示与数据列表页面相同的［视图］按钮、表的菜单、［新建］按钮（根据权限显示）。 |

#### 行的左侧

各行的左侧显示横条的颜色、数据的标题、负责人的图标、截止日期（月/日）。

- 数据的标题是到数据详细页面的链接。
- 负责人的图标只在设置了“负责人列”时显示。
- 截止日期未输入的数据显示为“—”。已逾期的数据显示为红字。
- 左上角的标题显示“分组依据列”的名称。

#### 日期刻度

- 上一行显示年月（例：2026/10），下一行显示各周星期一的日期（例：10/19）。宽度较窄时，周的日期每隔1周显示。
- 星期六、星期日的背景显示为浅灰色。
- 在今天的位置显示红色竖线和“今天”。
- 显示的期间会自动决定，使其包含所显示数据的开始日期和截止日期、里程碑的期限以及今天。前后各留几天空白，并按星期一到星期日的单位对齐。
- 每1天的宽度会按页面的宽度自动调整（没有放大、缩小的切换）。期间较长时，横向滚动显示。
- 打开页面时，会自动滚动到能看到今天日期的位置。

※距离今天约3年以上的日期，不会用来扩大显示期间。这时，横条会在显示期间的边缘被截断。

#### 横条

- 显示从开始日期到截止日期的横条。
- 设置了“进度列”时，横条中会按进度的比例叠加显示较深的颜色。
- 已逾期的数据，横条的周围变为红框。
- 把鼠标放到横条上，会显示数据的标题、期间（开始日期 ~ 截止日期）、进度、负责人姓名。

※开始日期或截止日期未输入的数据不显示横条，只显示行的左侧。

#### 分组的标题行

设置了“分组依据列”时，每个分组都会显示标题行。

- 标题行显示分组名、件数，以及截止日期（里程碑时）。
- 点击标题行，可以折叠／展开该分组的行。

### 打开记录

点击横条或行左侧的数据标题，会跳转到该数据的详细页面。

### 显示的信息

| 信息 | 内容 |
| --- | --- |
| 显示甘特图需要设置“开始日期列”和“截止日期（结束日期）列”。请在视图设置画面中选择日期列。 | 没有设置“开始日期列”“截止日期（结束日期）列”时，或指定的列不再是日期列（已删除）时显示。 |
| 显示件数超过上限（○ 件）。请通过显示条件缩小范围。 | 符合显示条件的数据超过“最大显示条数”时显示。 |
| 没有可显示的数据。 | 1条要显示的数据都没有时显示。 |

## 注意事项

- 甘特图仅用于显示。不能拖动横条，也不能在图上编辑。
- 只显示登录用户可以查看的数据。
- 用视图设置页面的［预览］按钮，可以在保存之前确认显示内容（请参阅[自定义视图](/zh/view)）。
- 在仪表板的“数据列表”“图表”中，不能选择甘特图视图（请参阅[仪表板](/zh/dashboard)）。
