# 每个用户的语言和时区
从 v7.2.4 起，每个用户可以选择自己的画面语言和时区。邮件和通知也会按接收人的语言和时区发送。

## 选择语言
可以在下面任何一处选择语言。

- 右上角的用户菜单
- 登录用户设置（右上角的用户菜单 →“登录用户设置”）的“语言”
- 登录画面

可以选择的语言有：日本語、English、Tiếng Việt、简体中文、한국어、Deutsch、Español。  
※越南语、中文（简体）、韩语、德语、西班牙语的画面是机器翻译的。如果发现需要修改的地方，请在 [GitHub](https://github.com/exceedone/exment/issues) 告诉我们。  
※管理员可以限制用户可选择的语言（见下面的“管理员的设置”）。

### 使用语言的顺序
Exment 按下面的顺序决定语言。

1. 用户在登录用户设置中选择的语言
1. 在登录画面选择的语言
1. 浏览器的语言（系统设置的“用户未选择语言时使用浏览器的语言”为 YES 时。从用户可选择的语言中选取）
1. 站点的语言

在登录用户设置的“语言”中选择“自动（浏览器的语言）”，就会回到没有选择语言的状态。

> [!WARNING]
> 更新到 v7.2.4 后，在没有选择语言的用户中，浏览器语言与站点语言不同的人，画面会以浏览器的语言显示。  
> 如果想让所有人都保持站点的语言，请把系统设置 →［详细设置］的“用户未选择语言时使用浏览器的语言”设为 NO。

## 选择时区
时区在登录用户设置的“时区”中选择。初始值是“站点的时区”。

日期时间按所选的时区显示和输入。适用范围是：列表、详情、表单、“今天”等筛选条件、日历、甘特图、看板、评论、更新历史、通知、操作日志。

### 仍然使用站点时区的地方
- 数据库中按站点的时区保存。
- 只有日期的列（没有时间的日期）不会改变。
- API 仍然使用站点的时区。
- 按日期时间汇总的图表（汇总视图和仪表板）按站点的时间汇总。图表上会显示“（站点时间：Asia/Tokyo）”这样的文字。
- 导出在初始值下使用站点的时区。选择“以您的时区导出日期时间（…）”，就可以按自己的时区导出。
- 导入时，在“文件中日期时间的时区”中选择文件里的日期时间是站点的时区还是自己的时区。

## 邮件和通知
邮件和通知按接收人的语言和时区发送。接收人没有选择语言时，使用站点的语言。

## 管理员的设置
在系统设置 →［详细设置］中设置（[系统设置](/zh/system_setting)）。

| 项目 | 内容 | 初始值 |
| --- | --- | --- |
| 用户可选择的语言 | 用户在右上角的菜单、登录画面、登录用户设置中可以选择的语言。留空时，可以选择已安装的所有语言。站点的语言随时都可以选择。 | 留空（全部） |
| 用户未选择语言时使用浏览器的语言 | 设为 YES 时，对没有选择语言的用户，以浏览器的语言（从用户可选择的语言中选取）显示画面。设为 NO 时，以站点的语言显示。 | YES |

站点的语言和时区，和以前一样由 `.env` 的 `APP_LOCALE` 和 `APP_TIMEZONE` 决定。
