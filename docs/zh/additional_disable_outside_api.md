# 关闭服务器外部通信
这是停止从 Exment 的服务器向其他服务器通信的设置。  
用于完全的本地部署环境等不向其他服务器通信的环境。

Exment 会因下面的用途向其他服务器通信。

- 为了判断 Exment 是否有最新版本，与包管理系统通信，获取最新版本的信息
- 为了在仪表板的“Exment 最新信息列表”中显示，与 Exment 的官方网站（exment.net）通信，获取最新信息

### 设置步骤 
> 本步骤从 v1.3.0 起有变更。

1. 从左侧菜单打开“系统设置”页面。
2. 把列表中的“允许服务器外部通信”项目设为“否”。  
![关闭服务器外部通信](../img/quickstart/outside_api.png)
3. 保存。至此设置完成。
