# 维护模式
在迁移数据或安装插件期间，只让系统管理员进入站点。在“设置：系统”→“维护模式”（URL 是 `/maintenance`）中切换。

※这个页面可以在 Exment v7.2.1 以后使用。  
※只有系统管理员可以使用这个页面。请在“功能管理”中把“维护模式”设为使用。

![维护模式](../ja/img/maintenance/maintenance1.png)

## 维护期间可以做的事
- 能进入的只有**系统管理员、开始维护的人、“允许进入的 IP 地址”**。
- 其他人会看到显示“消息”和预计结束时间的维护页面（HTTP 503）。已登录的人会被退出登录。
- 开始和结束、更改的内容会留在操作日志中。

## 设置
| 项目 | 内容 |
|---|---|
| 开始 | 留空就是没有计划（要马上开始时用“立即开始维护”）。设置后，在开始之前会在页面上方通知已登录的人 |
| 结束 | 超过后自动结束（防止忘记关闭）。留空时，会持续到点击结束按钮为止 |
| 消息（ja、en） | 显示在维护页面上的文字 |
| 允许进入的 IP 地址 | 每行 1 个。也可以写范围（`192.168.0.0/24` 等）。页面上会显示服务器看到的您的 IP 地址 |
| API（OAuth、API 密钥） | 从“仅限系统管理员”“停止”“不停止”中选择 |
| 停止外部访问的页面 | 停止公开表单、共享链接、安全确认的回复、通过 LINE 的审批和回复 |
| 停止定时任务 | 停止计划任务和插件的批处理。结束后只运行 1 次（像自动备份这样设定了时刻的任务，要等到下一次的那个时刻） |
| 停止队列 | 停止邮件等后台处理。结束后从中断的地方继续运行 |

## 命令
页面打不开时，或者从服务器的操作中切换时，也可以使用命令。

~~~
php artisan exment:maintenance status
php artisan exment:maintenance on --until="2026-12-01 09:00" --message="正在维护中" --allow-ip=192.168.0.0/24
php artisan exment:maintenance off
~~~

`php artisan down`（从页面更新和还原时使用的命令）与这个不同，仍然照常运行。
