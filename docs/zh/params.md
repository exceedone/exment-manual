# 参数变量列表
这是执行时会替换为实际值的“参数变量”的列表。按“${变量名}”的形式书写（[示例](/zh/params?id=示例)）。
可以在以下项目中使用。

- 通知模板
    - 数据新建、更新等
    - 时间经过
    - 按钮
    - 工作流
    - 用户的新建
    - 用户的密码重置
    - 公开表单的登记完成（用户、管理员）通知、错误通知
- 文档输出
- 自定义列的自动编号
- 邮件发送的发件人显示名称

## 变量列表
### 日期
以下的例子，是执行日期时间为“2018/02/17 11:20:32”的情况。

| 项目 | 说明 |
| ---- | ---- |
| ${y} or ${year} | 设置执行时的年，4 位。(例：2018) |
| ${m} or ${month} | 设置执行时的月。(例：2) |
| ${m:(整数)} or ${month:(整数)} | 设置执行时的月，位数为指定的整数。(例：填写 ${m:2} 时，02) |
| ${d} or ${day} | 设置执行时的日。(例：17) |
| ${d:(整数)} or ${day:(整数)} | 设置执行时的日，位数为指定的整数。(例：填写 ${d:2} 时，17) |
| ${h} or ${hour} | 设置执行时的小时。(例：11) |
| ${h:(整数)} or ${hour:(整数)} | 设置执行时的小时，位数为指定的整数。(例：填写 ${hour:2} 时，11) |
| ${i} or ${minute} | 设置执行时的分。(例：20) |
| ${i:(整数)} or ${minute:(整数)} | 设置执行时的分，位数为指定的整数。(例：填写 ${minute:2} 时，20) |
| ${s} or ${second} | 设置执行时的秒。(例：32) |
| ${s:(整数)} or ${second:(整数)} | 设置执行时的秒，位数为指定的整数。(例：填写 ${second:2} 时，32) |
| ${ymdhms} or ${ymdhis} | yyyymmddhhiiss 字符串(例：20180217112032) |
| ${ymdhm} or ${ymdhi} | yyyymmddhhii 字符串(例：201802171120) |
| ${ymdh} | yyyymmddHH 字符串(例：2018021711) |
| ${ymd} | yyyymmdd 字符串(例：20180217) |
| ${ym} | yyyyMM 字符串(例：201802) |
| ${hms} or ${his} | hhiiss 字符串(例：112032) |
| ${hm} or ${hi} | hhii 字符串(例：1120) |
| ${now} | 以 yyyymmddhhiiss 格式输出执行日期时间。(例：20180217112032) |
| ${now:(format)} | 以指定的格式输出执行日期时间。格式请参阅<a href="https://www.php.net/manual/function.date.php" target="_blank">这里</a>。<br />(例：填写 ${now:y} 时，18) |

### 表
| 项目 | 说明 |
| ---- | ---- |
| ${table_name} | 设置该数据的表名(英文数字)。(v4.2.7 起添加) |
| ${table_view_name} | 设置该数据的表显示名。(v4.2.7 起添加) |

### 数据
| 项目 | 说明 |
| ---- | ---- |
| ${id} | 设置已登记的数据的 ID。(例：123) |
| ${id:(整数)} | 设置已登记的数据的 ID，位数为指定的整数。(例：填写 ${id:5} 时，00123) |
| ${suuid} | 设置已登记的数据的 suuid(Short UUID. 20 位的随机字符串)。 |
| ${created_user} | 设置登记数据的用户名。(例：管理员) |
| ${updated_user} | 设置更新数据的用户名。(例：用户A) |
| ${created_at} | 设置登记数据的日期时间。(例：2020/08/06 10:00:00) |
| ${updated_at} | 设置更新数据的日期时间。(例：2020/08/06 14:00:00) |
| ${value_url} | 设置显示已登记的数据的链接。 |
| ${value:(列名)} | 设置已登记的数据的列的值。<br />(例：对用户数据填写 ${value:user_code} 时，设置用户代码) |

#### 数据(选项)
像“${value:(列名)/(选项键1)=(选项值1)}”这样填写，可以给参数添加选项。有多个选项时，请用逗号分隔。
例：
- ${value:mitsumori_date/format="Y"}
- ${value:mitsumori_price/disable_number_format=1,disable_currency_symbol=1}

| 选项键 | 说明 |
| ---- | ---- |
| ${value:(列名)/format="(日期格式)"} | 列类型为“日期”“日期和时间”时，把已登记的数据的列的值转换格式后显示。<br />(例1：“合同信息(contract)”表中有“合同日(contract_date)”列，想显示合同年份时，${value:contract_date/format="Y"}）<br />(例2：“合同信息(contract)”表中有“合同日(contract_date)”列，想以“yyyy/mm/dd”格式显示时，${value:contract_date/format="Y/m/d"}）|
| ${value:(列名)/disable_number_format=1} | 列类型为“整数”“小数”“货币”时，使“数值使用千位分隔符”的设置无效。|
| ${value:(列名)/disable_currency_symbol=1} | 列类型为“货币”时，使“货币显示格式”的设置(日元符号、$ 等)无效。|


### 关联、相关数据
| 项目 | 说明 |
| ---- | ---- |
| ${select_table:(列名).(引用目标表的列名)} | 和“列名”对应的列是“选项（从其他表中选择）”“用户”“组织”时，设置引用目标的列的值。<br />   (例：“合同信息(contract)”表中有“客户(client)”列，引用了“客户信息(client)”表时，设置 ${select_table:client.client_code}，就可以显示“客户信息(client)”表的客户代码(client_code)) |
| ${parent:(引用目标表的列名)} | 设置父表的列的值。<br />(例：从“合同明细信息(contract_detail)”表引用作为父表的“合同信息(contract)”表的合同代码(contract_code)时，填写 ${parent:contract_code}，就会设置合同代码) |


### 个别
有些功能有只能在该功能中使用的变量参数。
以下是各功能、页面，以及在该功能中可以使用的参数的列表。

#### 通知
用邮件或系统内提醒向用户发送通知时可以使用。

| 项目 | 说明 |
| ---- | ---- |
| ${user:user_name} | 邮件收件用户的用户名 |
| ${user:user_code} | 邮件收件用户的用户代码 |
| ${user:email} | 邮件收件用户的电子邮件地址 |

#### 通知(附件)
在通知模板的列“自定义附件”中，按以下规则设置参数后，邮件通知时，会把该自定义列中登记的附件发送给用户。
详情请确认[附件与自定义附件](/zh/mail)。
※目前只在邮件通知时有效。

| 项目 | 说明 |
| ---- | ---- |
| ${file:(自定义列名)} | 自定义列类型“文件”“图片”中登记的附件 |
| ${file:select_table:(选项的自定义列名).(引用目标表的文件列名)} | 在自定义列“选项（从其他表中选择）”中所选数据的“文件”“图片”列中登记的附件。<br/>例：${file:select_table:customer.contract_file} |
| ${documents} | 对数据详情页面登记的（相当于上面链接目标的图像中的位置）附件 |

#### 登录用户
只能在登录时使用。用批处理等发送通知时不能使用。

| 项目 | 说明 |
| ---- | ---- |
| ${login_user:user_name} | 登录用户的用户名 |
| ${login_user:user_code} | 登录用户的用户代码 |
| ${login_user:email} | 登录用户的电子邮件地址 |
| ${login_user:(列名)} | 设置登录用户的指定列的值 |

#### 密码重置
只能在发送密码重置的邮件时使用。

| 项目 | 说明 |
| ---- | ---- |
| ${system:password_reset_url} | 系统的密码重置 URL |
| ${user:password} | 邮件收件用户的登录密码 |

#### 公开表单
只能在公开表单的通知中使用。

| 项目 | 说明 |
| ---- | ---- |
| ${publicform:public_form_view_name} | 公开表单显示名 |
| ${publicform:inputs} | 公开表单 用户输入值 |

#### 公开表单(发生错误时)
只能在公开表单发生错误时的通知中使用。

| 项目 | 说明 |
| ---- | ---- |
| ${error:message} | 公开表单 错误概要 |
| ${error:stacktrace} | 公开表单 错误详情 |


#### 插件(文档输出)

| 项目 | 说明 |
| ---- | ---- |
| ${value_image:(列名)} | 和“列名”对应的列的类型为“图片”时，把图像输出到 Excel。 |
| ${value_image:(列名)/width=(尺寸整数),height=(尺寸整数)} | 要指定输出图像的宽度(width)和高度(height)时，请输入选项。也可以只指定 width 或 height 其中之一。 |


## 示例
※执行日为 2018/8/9、对象数据的 ID 为 100、对象数据的 user_code(用户代码)为 "U12345" 时
- U-${id:4} → U-0100
- ${y}-${m:2}-${d:2}-${id} → 2018-08-09-100
- ${y}${m:2}${d:2}-${id:5} → 20180809-00100
- ${now:y}${m:2}${d:2}-${id:4} → 180809-0100
- ${y}${m:2}${d:2}-${value:user_code} → 20180809-U12345
