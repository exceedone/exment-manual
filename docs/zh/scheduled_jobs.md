# 计划任务
这是服务器的 cron（`php artisan schedule:run`）在固定时间运行的任务列表。从“设置：系统”→“计划任务”（URL 是 `/scheduled_jobs`）打开。

※这个页面可以在 Exment v7.2.6 以后使用。  
※只有系统管理员可以看到这个页面。

## 开始使用
在[功能管理](/zh/feature)中把“计划任务”设为“使用”。一开始是“不使用”。不使用时，这个页面打不开（变为 404）。

任务的记录只在使用期间保留。

## cron 状态
显示 `schedule:run` 最后运行的时刻。超过 10 分钟没有运行时，会显示提醒。这时，通知、自动备份、插件的批处理等已经停止。请在服务器的 cron 中加入下面的 1 行（也可以在[性能调优](/zh/tuning)中确认）。

~~~
* * * * * cd /var/www/exment && php artisan schedule:run >> /dev/null 2>&1
~~~

## 任务列表
| 项目 | 显示的内容 |
|---|---|
| 任务 | Exment 的任务的名称和命令（插件的批处理是“插件批处理：名称”） |
| 运行时间 | 用文字显示，例如“每 5 分钟”“每小时”“每天 3:30” |
| 下次运行 | 按您的时区显示 |
| 状态 | 不运行的任务也会显示原因（例：没有使用“安全确认”） |
| 最后运行、最近的记录 | 开始、结束、耗时、结果、退出代码、运行者、输出的最后 4KB |

每个任务保留最近 20 次的记录。次数可以用 `.env` 的 `EXMENT_SCHEDULED_JOBS_KEEP_RUNS` 更改。

## 连续失败时
连续失败 3 次的任务用红色显示。会用页面上方的通知和邮件，只通知系统管理员 1 次。成功后恢复原状，再次连续失败时再通知。次数可以用 `.env` 的 `EXMENT_SCHEDULED_JOBS_ALERT_FAILURES` 更改。

## 立即运行
点击“立即运行”，这个任务会马上在后台运行。正在运行的任务不能重复运行。

不过，没有防止重叠的设置的任务（每小时的 `exment:schedule` 和插件的批处理），固定时间的运行不会等待“立即运行”。在运行时刻（每小时整点等）之前不久点击，两者可能会同时运行。请不要在运行时刻附近点击。

下面的情况不能点击按钮（会显示原因）。这时服务器的 cron 仍然会运行任务。
- PHP 不能运行外部命令的服务器（不能使用 `proc_open` 的租用服务器等）
- 演示环境

## 命令
~~~
php artisan exment:schedule-status          # 用表格显示列表
php artisan exment:schedule-status --json   # 用 JSON 显示每个任务的最后运行和连续失败的次数
~~~

在 SaaS 中，每个租户只显示该租户的任务和记录。
