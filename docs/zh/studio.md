# Studio
Studio 是用来创建、修改、集中查看页面的功能。像 kintone 的应用一样，只要摆放部件，就能做出数据的容器（表）和输入的页面、列表。做好的页面在手机应用（Exment 应用）中也能使用。

※这里写的功能在 Exment v7.2.1 中齐备。

## 开始使用
- Studio 一开始是“不使用”。系统管理员在“管理员设置”→“[功能管理](/zh/feature)”中把“Studio”设为“使用”后，“管理员设置”下面会出现“Studio”的菜单（URL 是 `/studio`）。
- 可以打开 Studio 的，是在功能管理中选择的人当中，在某个表上有表、表单、视图的设置权限的人，以及系统管理员。

| 可以做的事 | 需要的权限 |
| --- | --- |
| 创建新的应用（表） | 系统的“表”权限 |
| 为现有表添加页面、在 Studio 中修改 | 该表的表单设置权限 |
| 创建按钮、在修改页面中添加新项目（列） | 该表的设置权限 |

## 页面的列表
打开 Studio 后，可以在 1 个页面中集中查看站点的页面。

| 栏 | 内容 |
| --- | --- |
| 表的页面 | 按表排列输入的页面（表单）和列表（视图）。有“打开”“编辑”“复制”，以及通往“列设置”“表设置”的链接。可以在上面的栏中按表名、页面名筛选。 |
| 仪表板 | 系统的仪表板和用户的仪表板。 |
| 插件页面 | 页面类型的插件。 |
| 表关系图 | 可以用图查看父子（一对多）、多对多的关联和选择其他表的列。 |

- 点击输入页面的名称（和铅笔图标），会打开[在 Studio 中修改](/zh/studio?id=在-studio-中修改)的页面。以前的表单设置页面可以从齿轮图标（“在表单设置中打开”）打开。
- 列表中只显示自己可以设置的表和其中可以设置的页面。

## 创建新的应用和页面
点击列表的“新建应用或页面”。创建方式有 3 种。

| 创建方式 | 内容 |
| --- | --- |
| 新建应用 | 摆放部件后，就会做出表和列、输入的页面、列表。选择后，还可以一起做出看板、日历、图表、仪表板（[作为应用一起创建](/zh/studio?id=作为应用一起创建)）。 |
| 为现有表添加页面 | 不创建表。摆放现有的列，只创建输入的页面（表单）。 |
| 从 Excel 或 CSV 创建 | 读取 Excel（.xlsx）或 CSV 后，把第 1 行作为项目名、第 2 行起作为数据，推测部件并摆放。不对的地方修改后再保存。设为“同时导入数据”后，数据也会一起导入（最多 1,000 行，文件最大 10MB）。 |

保存之前，会显示将做出什么（“保存后将创建应用“○○”（表、输入页面和列表）。”等）。保存后，就可以在做好的页面中输入数据。

### 部件
| 部件 | 内容 |
| --- | --- |
| 单行文本、多行文本、URL、电子邮件 | 输入文字。 |
| 整数、小数、货币 | 输入数字。 |
| 计算 | 由其他数值项目计算（下面的“计算”）。 |
| 日期、日期和时间、时间 | 输入日期和时间。 |
| 选项、YES/NO | 从固定的内容中选择。选项每行写 1 个。 |
| 选项（从其他表中选择） | 选择其他表的数据。要决定“选择来源表”。 |
| 用户、组织 | 选择 Exment 的用户和组织。 |
| 自动编号 | 保存后，会自动加上日期和编号（例：20261121-0001）。 |
| 文件、图片 | 附加文件和图片。 |

- 点击部件会加到最后，拖动可以放到喜欢的位置。项目最多可以放 100 个。
- 每个项目要决定项目名称、列名（英文字母和数字）、必填。

### 行和列的排列
为每一行选择“1 列”“2 列”“2 列（左侧较宽）”“2 列（右侧较宽）”“3 列”“4 列”，就可以把项目横向并排。在手机上纵向排列。行最多可以创建 50 行。

### 显示条件
每个项目可以按其他项目的值切换显示（“等于”“不等于”“为空”“不为空”）。例如，只在状态为“保留”时显示“原因”。必填项目不能设置条件。

### 明细（子表）
可以创建像订单中的商品那样，在 1 条数据中输入多行的明细。每个明细会创建一个子表，以表格的形式显示在输入页面的下面。明细最多可以创建 5 个。明细中也可以使用计算和从其他表选择的部件。

### 计算
在计算的部件中，把其他数值项目（整数、小数、货币、计算）用 `[ ]` 括起来写。

- 例：`[数量] * [单价]`
- 明细的合计：`SUM[明细名称.项目]`（例：`SUM[订单明细.金额]`）
- 可以使用的只有项目、数字和 `+ - * / ( )`。

### 按钮
可以创建显示在数据页面上的按钮。点击后会更改项目的值（例：点击“完成”，状态变为“完成”）。

- 1 个页面最多可以创建 5 个。可以更改的项目是选项、YES/NO、单行文本、整数。
- 对已经是那个值的数据，不显示按钮。
- 按钮作为表的“[批量更新设置](/zh/operation)”创建。之后可以在那里修改和删除。
- 只有拥有该表设置权限的人可以创建按钮。

### 更多设置
- **表名（英文字母和数字）**：用于数据的 URL 等的名称。留空时自动生成。之后无法更改。
- **添加到菜单的位置**：选择加到左侧菜单的哪里（也可以选择“不添加”）。

## 作为应用一起创建
在“新建应用”中，可以在“随应用一起创建”一栏里把查看数据的页面也一起创建。

| 创建的东西 | 使用的项目 |
| --- | --- |
| 看板 | 分栏依据的项目（选项） |
| 日历 | 日期项目（为了能在日历中查找，会把该项目的搜索索引设为开） |
| 图表（数量） | 按统计依据的项目（选项、YES/NO）统计的数量 |
| 仪表板 | 并排显示列表、图表、日历。由系统管理员创建时所有人可见，由其他人创建时只有自己可见。 |

- 放置可用的项目后，会自动设为开。也可以取消。
- 这些都与在视图、仪表板的设置页面中创建的相同。之后可以在那些页面中修改。

## 在 Studio 中修改
在 Studio 中创建的输入页面（以及现有表的表单），可以在与创建时相同的页面中修改。在页面的列表中点击输入页面的名称。可以修改的是拥有该表的表单设置权限的人。

- 可以移动、移除项目，设置、取消显示条件，更改页面的名称，添加按钮。
- 从页面中移除的项目，表的列和数据也会原样保留。
- 从“新项目（同时在表中创建列）”添加部件后，保存时会在表中创建列，也会显示在列表中。只有拥有表的设置权限的人可以这样做。计算的部件不能在这里添加（在列的设置中添加）。
- 标题、说明文字、HTML、图片、分隔线、系统项目等 Studio 中还没有的项目不会删除，会保留。可以移动、移除，内容在表单设置中修改。
- 明细（子表的输入）保持不变。要修改明细时，请在表单设置中打开。
- 保存之前，会显示将改变什么（“表“○○”还将创建列“○○”。”等）。

## 手机应用（Exment 应用）
用手机的浏览器打开 `/app`，就可以把 Studio 的页面作为手机应用使用。“添加到主屏幕”后，可以像应用一样打开。

- **页面**：排列着可以使用的表的输入页面。打开后显示列表，用右下角的“+”可以新登记。
- **照片、文件**：在文件、图片的项目中，可以当场拍照并附加。照片会在手机中缩小后再发送。
- **扫码**：从上面的按钮可以用相机读取 QR 码和条形码。如果是 Exment 的二维条码（[二维条码设置](/zh/2d_barcode)）或数据 URL 的 QR 码，会打开那条数据。从列表的页面读取时，会在该表的文字、整数、自动编号的列中查找相同的数据。也可以查找 JAN 码。
- **没有信号时**：保存时没有信号的话，会把输入的内容（包括明细和照片）作为草稿保存在手机中，在打开应用时或信号恢复时自动发送。打开过一次的页面没有信号也能打开，所以也可以新输入。从“未发送的草稿”列表中，可以打开并修改、马上发送、删除。服务器没有受理的草稿，会显示原因并保留。草稿按用户分别保存。
- 用“电脑版”可以回到平时的页面。
