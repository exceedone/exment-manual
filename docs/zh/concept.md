# Exment 的理念

![告别 Excel 和零散的文件](../ja/img/concept/concept_hero.png)

## 什么是 Exment
Exment 是**不写程序就能做出适合自己公司业务的应用的 Web 数据库**。  
客户名单、项目、申请、资产台账——现在用 Excel、纸张、邮件附件零散管理的数据，都可以集中到一个地方。无论谁、从哪里打开，都能用同一份最新的数据工作。

> 一开始它是一个“空箱子”。按照想管理的东西往里面添加表，它就会成为这家公司专用的业务系统。添加客户就是客户管理，添加申请就是工作流。**有多少家公司，就有多少种用法。**

## 3 个特点
### 1. 能做 —— 不用写程序
- 只用页面上的操作，就能做出表、项目、输入表单、列表（视图）。
- 列表可以用表格、日历、看板、甘特图、图表来查看。
- 选择模板（客户管理、申请包等），马上就能开始使用。

### 2. 能运转 —— 团队一起，而且安全
- 申请 → 审批、退回的**工作流**，期限和数据变更的**通知**（邮件、Slack、Microsoft Teams、LINE）。
- 用角色组可以决定谁能看什么、能改什么。操作日志也会留下。
- 用仪表板一眼看到现在的数字。在智能手机的浏览器中也能使用。

### 3. 能连接 —— 与其他系统和 AI
- 用 API 可以和其他系统交换数据。也可以为每个用户创建 API 密钥。
- **AI（MCP）**：Claude 等 AI 可以按用户自己的权限读取数据。
- 官方插件（项目管理、IT 支持、Groupware）免费随附。可以用插件增加功能。

## 与 Excel 的区别
| | Excel、文件 | Exment |
|---|---|---|
| 最新的数据 | 文件被复制，不知道哪个是最新的 | 始终只有一份。大家看同一份数据 |
| 同时使用 | 有人打开时就不能修改 | 多少人都可以同时输入 |
| 权限 | 以文件为单位。很难按行或列设置 | 用角色组，按表、按数据设置 |
| 历史 | 覆盖后就消失 | 留下变更历史和操作日志 |
| 审批、通知 | 用邮件或纸张传递 | 用工作流和通知自动进行 |
| 查找 | 打开文件来找 | 关键字搜索、筛选、排序 |

## 例如，可以这样使用
**客户管理**：把客户和负责人整理在一起，让谁都能看到同样的信息。

![客户管理](../ja/img/concept/concept_customer.png)

**文件共享**：在各部门的工作区中存放提案书、报价单、合同。带有版本管理和权限。

![文件共享](../ja/img/concept/concept_files.png)

此外还有申请和审批（禀议、费用报销、休假）、项目管理、资产和物品的管理、咨询管理、日报等。任何业务都可以从添加表开始。详情请看[功能地图](https://exment.net/en/feature-map/)。

## 可以一直使用的开源软件
- **免费的开源软件**（GPL-3.0）。安装到自己公司的服务器上，**用户增加，费用也不会增加**。
- 数据放在自己公司的服务器上。不想准备服务器时，也可以选择 Exment SaaS。
- 通过付费支持，从导入到运用都可以咨询。
