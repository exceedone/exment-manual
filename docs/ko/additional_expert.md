# 전문가 모드
시스템을 잘 아는 분을 위한, 더 세밀한 설정을 쓸 수 있게 하는 모드입니다.  
전문가 모드로 하면 다음 설정을 할 수 있게 됩니다.

- 사용자 정의 열이 "한 줄 텍스트"인 경우, 입력 내용의 정규 표현식 유효성 검사
- 사용자 정의 테이블 설정의 [화면에서 변경 불가](/ko/table)
- 사용자 정의 테이블 설정의 [제목 형식 설정](/ko/table)에서 매개변수 열에 의한 설정

### 설정 절차 
- .env 파일에 다음 내용을 추가하고 저장합니다.

~~~
EXMENT_EXPART_MODE=true
~~~

- 이렇게 하면 사용자 정의 테이블 설정, 사용자 정의 열 설정 등의 화면에 위의 설정 항목이 표시됩니다.
