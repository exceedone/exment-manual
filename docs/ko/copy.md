# 데이터 복사 설정
어떤 테이블의 데이터를 다른 테이블(또는 같은 테이블)에 복사하기 위한 설정입니다.  
예를 들어 다음과 같이 쓸 수 있습니다.

- "견적" 데이터의 상세 화면에 "수주로 전환" 버튼을 표시하고, 누르면 견적의 내용으로 "수주" 데이터를 만든다.
- 연도마다 같은 항목의 테이블("2025년도 ○○ 데이터", "2026년도 ○○ 데이터")을 만들고 있고, 2026년도에 입력할 때 2025년도의 데이터를 찾아 내용을 옮겨 적은 다음 입력한다.

복사하는 방법은 2가지입니다. 둘 다 이 설정에서 정한 "어느 열을 어느 열에 옮길지"를 사용합니다.

| 방법 | 버튼이 나오는 곳 | 동작 |
|---|---|---|
| [상세 화면의 복사 버튼](/ko/copy?id=상세-화면의-복사-버튼) | 복사 원본 데이터의 상세 화면 | 누르면 복사 대상에 데이터가 **만들어집니다**. |
| [신규 작성 화면의 복사 버튼](/ko/copy?id=신규-작성-화면의-복사-버튼) | 복사 대상의 신규 작성 화면 | 복사 원본 데이터를 찾아 고르면 그 내용이 입력란에 들어갑니다. **저장하기 전까지는 데이터가 만들어지지 않습니다.** |

※ 신규 작성 화면의 "복사" 버튼은 Exment v7.2.2 이후에서 쓸 수 있습니다.  
※ 이 설정을 만들 수 있는 것은 복사 원본 테이블의 "테이블 설정" 권한이 있는 사용자입니다(시스템 관리자 포함).

## 설정 화면을 여는 방법
데이터 복사 설정은 **복사 원본 테이블** 의 설정으로 만듭니다.

- 복사 원본 테이블의 데이터 목록을 열고, 오른쪽 위의 "테이블 상세 설정"에서 "데이터 복사 설정"을 누릅니다.  
※ 그 테이블을 미리 메뉴에 표시해 두어야 합니다.
- 또는 메뉴의 "설정: 데이터와 화면" → "사용자 정의 테이블"에서 복사 원본 테이블의 행 하나에 체크하고, 오른쪽 위의 "테이블 상세 설정"에서 "데이터 복사 설정"을 누릅니다.

## 새로 추가
1. "데이터 복사 설정" 화면에서 오른쪽 위의 ［새로 만들기］를 누릅니다.
1. 대화 상자에서 "복사 대상 테이블"을 고릅니다.
1. "같은 이름의 열 연결"은 처음에는 켜져 있습니다. 켠 채로 진행하면 복사 원본과 복사 대상에서 열 이름이 같은 열이 처음부터 "복사 열 설정"에 들어갑니다([복사 열 설정](/ko/copy?id=복사-열-설정)).
1. 설정 화면에서 필요한 내용을 입력하고 ［전송］을 누릅니다.

## 편집·삭제
목록의 해당 행의 ［편집］, ［삭제］에서 합니다.

## 입력 항목의 상세

### 기본 설정
- ##### 복사 원본 테이블·복사 대상 테이블
복사의 원본과 대상 테이블입니다. 여기에서는 바꿀 수 없습니다.

- ##### 버튼 레이블
상세 화면의 "복사" 버튼에 표시할 문구입니다. 처음에는 "복사"입니다. 예: "수주로 전환", "2026년도로 복사"

- ##### 버튼 아이콘·버튼 HTML class
상세 화면의 "복사" 버튼의 아이콘과 HTML의 class입니다.

- ##### 신규 작성 화면에 버튼 표시
켜면 복사 대상 테이블의 신규 작성 화면에 "복사" 버튼이 나옵니다([신규 작성 화면의 복사 버튼](/ko/copy?id=신규-작성-화면의-복사-버튼)). 처음에는 꺼져 있습니다.  
※ v7.2.2 이후입니다.

- ##### 신규 작성 화면 버튼의 괄호 안 내용
신규 작성 화면의 "복사" 버튼의 괄호 안에 무엇을 표시할지 고릅니다. "신규 작성 화면에 버튼 표시"가 켜져 있을 때만 나옵니다.

| 고르는 것 | 버튼의 이름 |
|---|---|
| 자동(처음) | "복사". 같은 테이블에 이 버튼을 표시하는 설정이 2개 이상 있을 때는 "복사(복사 원본 테이블명)" |
| 복사 원본 테이블명 | 언제나 "복사(복사 원본 테이블명)" |
| 라벨 | "복사(신규 작성 화면 버튼의 라벨)" |

- ##### 신규 작성 화면 버튼의 라벨
괄호 안에 표시할 문구입니다. 예: "전년도"라고 넣으면 "복사(전년도)"가 됩니다. 괄호 안에 "라벨"을 골랐을 때만 나옵니다.

※ 이 2개는 v7.2.2 이후입니다.

- ##### 자식 테이블 설정
상세 화면의 "복사" 버튼으로 그 데이터의 자식 테이블 데이터도 함께 복사합니다. 자식 테이블끼리의 데이터 복사 설정(입력 대화 상자 설정이 없는 것)을 먼저 만들어 둡니다.  
※ 신규 작성 화면의 "복사" 버튼에서는 자식 테이블을 옮기지 않습니다.

### 복사 열 설정
복사 원본의 열과 복사 대상의 열의 조합입니다. 한 행에 한 쌍씩 "복사 원본 테이블 열 ▶ 복사 대상 테이블 열"을 고릅니다.

| 복사 원본 테이블 열 | | 복사 대상 테이블 열 |
|---|---|---|
| 고객 이름 | ▶ | 거래처 이름 |
| 금액 | ▶ | 견적 금액 |
| 담당자 | ▶ | 담당자 |

- 열 이름이 달라도 조합하면 옮길 수 있습니다.
- 여기에 없는 열은 옮기지 않습니다. 복사 대상에서는 빈 값(또는 초기값)이 됩니다.
- 복사 대상 테이블의 **필수 열은 모두 조합에 넣으십시오**. 들어 있지 않으면 저장할 수 없습니다.
- 파일·이미지 열은 고를 수 없습니다.

#### 같은 이름의 열 연결
같은 항목의 테이블끼리라면 한 열씩 조합하기는 번거롭습니다. 새로 추가할 때 "같은 이름의 열 연결"을 켜면 **열 이름(사용자 정의 열의 "열 이름")이 같은 열** 이 처음부터 조합에 들어갑니다. 새로 추가 화면의 오른쪽 위에 있는 "같은 이름의 열 연결" 버튼으로도 다시 넣을 수 있습니다(입력 중인 내용은 사라집니다).

- 자동 번호 열은 조합하지 않습니다.
- 열 이름이 다른 열은 들어가지 않으므로, 필요하면 직접 추가하십시오. 들어간 것은 고치거나 지울 수 있습니다.
- 이미 있는 설정의 편집 화면에는 이 버튼이 없습니다.

※ v7.2.2 이후입니다.

#### 열의 종류가 다를 때
열의 종류가 다른 조합(예: 텍스트 → 정수)도 고를 수 있지만, 값은 그대로 옮깁니다. 맞지 않는 값은 저장할 때의 입력 검사에서 오류가 됩니다. 선택지 열에서 복사 대상에 같은 선택지가 없는 값은 선택되지 않은 상태가 됩니다.

### 입력 대화 상자 설정
상세 화면의 "복사" 버튼을 눌렀을 때 대화 상자에서 다시 입력하게 할 열입니다. 여기에 넣은 열은 대화 상자에서 입력한 값으로 데이터가 만들어집니다.  
※ 신규 작성 화면의 "복사" 버튼에서는 쓰지 않습니다(입력란에서 그대로 고칠 수 있기 때문입니다).

## 상세 화면의 복사 버튼
복사 원본 데이터의 상세 화면에 "버튼 레이블"의 버튼이 나옵니다.

1. 버튼을 누릅니다.
    - 입력 대화 상자 설정이 없을 때는 확인 메시지가 나옵니다.
    - 입력 대화 상자 설정이 있을 때는 그 열의 입력 대화 상자가 나옵니다.
1. 복사 대상에 데이터가 만들어지고, 만들어진 데이터의 화면으로 이동합니다.

※ 버튼을 누를 수 있는 것은 복사 원본 데이터를 볼 수 있고, 복사 대상에 데이터를 만들 수 있는 사용자입니다.

## 신규 작성 화면의 복사 버튼
"신규 작성 화면에 버튼 표시"를 켜면 **복사 대상 테이블** 의 신규 작성 화면 오른쪽 위에 "복사" 버튼이 나옵니다.

1. 복사 대상 테이블(예: 2026년도 ○○ 데이터)의 신규 작성 화면에서 "복사"를 누릅니다.
1. 복사 원본 테이블(예: 2025년도 ○○ 데이터)의 데이터 목록이 대화 상자로 열립니다. 데이터 선택 열의 "검색"과 같은 대화 상자이며, 검색·좁히기·정렬을 할 수 있습니다.
1. 옮기고 싶은 데이터의 "선택"을 누르고 ［설정］을 누릅니다.
1. 고른 데이터의 내용이 들어간 신규 작성 화면이 열립니다. 위에 "○○의 "○○" 내용을 복사했습니다."라고 나옵니다.
1. 필요한 부분을 고치고 저장합니다. **저장하기 전까지는 데이터가 만들어지지 않습니다.**

- 파일·이미지·자동 번호 열은 옮기지 않습니다("복제하여 새로 만들기"와 같습니다).
- 버튼의 이름은 "신규 작성 화면 버튼의 괄호 안 내용"에서 고를 수 있습니다(자동·복사 원본 테이블명·라벨).
- 버튼이 나오는 것은 복사 원본 테이블의 데이터를 볼 수 있는 사용자뿐입니다. 대화 상자에도 볼 수 있는 데이터만 나옵니다.

※ v7.2.2 이후입니다.

## 같은 테이블 안에서 복사할 때
복사 대상으로 같은 테이블을 고를 수도 있습니다. 설정 없이 같은 테이블의 데이터를 옮기기만 한다면, 데이터 목록의 행을 오른쪽 클릭하여 "복제하여 새로 만들기"로도 할 수 있습니다([데이터 목록](/ko/data_grid)).
