# 캐시 활성화
설정 등의 마스터 데이터를 캐시(임시로 저장해 두고 다음부터는 그것을 쓰는 방식)에 넣습니다.  
데이터베이스 접속 횟수가 줄어들므로, 환경에 따라서는 빨라질 수 있습니다.

주로 다음 데이터를 캐시에 넣습니다.

- 시스템 설정
- 사용자 정의 테이블
- 사용자 정의 열
- 폼 설정
- 뷰 설정
- 워크플로 설정
- 데이터베이스 접속 가능 여부
- 그 밖의 마스터 정보

### 설정 절차 
- .env 파일에 다음 내용을 추가하고 저장합니다.

~~~
EXMENT_USE_CACHE=true
~~~

### 캐시를 삭제하려는 경우 
- 캐시는 주기적으로 갱신됩니다. 바로 삭제하려면 다음 명령을 실행하십시오.

~~~
php artisan cache:clear
~~~
