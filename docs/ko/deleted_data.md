# 삭제된 데이터
삭제한 데이터를 목록으로 보고, 되돌리거나(복원) 완전히 삭제하는 조작을 하는 화면의 설명입니다.

- 삭제된 데이터를 표시할 수 있는 것은 삭제 데이터의 표시 권한을 가진 사용자뿐입니다.
- 편집 권한이 있는 사용자는 데이터를 복원하거나 완전히 삭제할 수 있습니다.  

※ 권한에 대한 자세한 내용은 [역할 그룹](/ko/role_group)을 참고하십시오.

## 목록 표시
![데이터 화면](../img/data/deleted_data1.png)  

1. 데이터 목록 화면의 왼쪽 위 ［필터］ 오른쪽 옆에 있는 ▼ 표시에서 "삭제된 데이터"를 고릅니다.
2. 표시가 바뀌어 그 테이블의 삭제된 데이터가 목록으로 나옵니다.

![데이터 화면](../img/data/deleted_data2.png)  


## 상세 표시

- 삭제된 데이터 목록에 있는 데이터는 상세를 표시할 수 있습니다.  
- 표시하고 싶은 데이터의 행, 또는 작업 열에 있는 보기 아이콘을 클릭하십시오.

![데이터 화면](../img/data/deleted_data3.png)  

- 데이터 상세 화면에서는 삭제 사용자와 삭제 일시를 확인할 수 있습니다.

![데이터 화면](../img/data/deleted_data4.png)  

## 복원

- 삭제된 데이터는 데이터 목록 화면으로 되돌릴 수 있습니다(복원).
- 복원하는 방법은 3가지입니다.
    - 데이터 상세 화면에 있는 ［복원］ 버튼을 씁니다.
    ![데이터 화면](../img/data/deleted_data5.png)  
    - 삭제된 데이터 목록 화면에서 작업 열에 있는 ［복원］ 아이콘을 씁니다.
    ![데이터 화면](../img/data/deleted_data6.png)  
    - 삭제된 데이터 목록 화면에서 복원하고 싶은 데이터에 체크하고, 삭제된 데이터 화면의 왼쪽 위에 있는 ▼ 표시에서 "복원"을 고릅니다.
    ![데이터 화면](../img/data/deleted_data7.png)  

※ 데이터를 복원할 수 있는 것은 그 데이터의 편집 권한이 있는 사용자뿐입니다.


## 완전히 삭제

- 삭제된 데이터는 완전히 삭제할 수 있습니다. 완전히 삭제한 데이터는 삭제된 데이터 목록에서도 사라집니다.
- 완전히 삭제하는 방법은 3가지입니다.
    - 데이터 상세 화면에 있는 ［완전히 삭제］ 버튼을 씁니다.
    ![데이터 화면](../img/data/deleted_data8.png)  
    - 삭제된 데이터 목록 화면에서 작업 열에 있는 ［완전히 삭제］ 아이콘을 씁니다.
    ![데이터 화면](../img/data/deleted_data9.png)  
    - 삭제된 데이터 목록 화면에서 완전히 삭제하고 싶은 데이터에 체크하고, 삭제된 데이터 화면의 왼쪽 위에 있는 ▼ 표시에서 "완전히 삭제"를 고릅니다.
    ![데이터 화면](../img/data/deleted_data10.png)  

※ 데이터를 완전히 삭제할 수 있는 것은 그 데이터의 편집 권한이 있는 사용자뿐입니다.


## 데이터 목록 화면으로 이동

- 삭제된 데이터 목록 화면에서 ［삭제된 데이터▼］를 클릭하고 "취소"를 고르면 그 테이블의 데이터 목록 화면으로 이동합니다.

![데이터 화면](../img/data/deleted_data11.png)  


#### 권한 설정
- 삭제된 데이터를 표시하려면 그 데이터의 표시 권한이 사용자에게 필요합니다.
- 삭제된 데이터를 복원하거나 완전히 삭제하려면 그 데이터의 편집 권한이 사용자에게 필요합니다.

※ 권한 설정에 대해서는 [역할 그룹](/ko/role_group)을 참고하십시오.
