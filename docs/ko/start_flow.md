# Exment로 업무를 시작하기까지의 흐름
Exment를 설치한 뒤 업무에 쓰기 시작하기까지의 흐름입니다.  
누가 무엇을 하는지 역할별로 정리했습니다.

### 역할
Exment에 관계하는 사람의 역할은 다음 4가지입니다. 각 담당자가 Exment의 설정을 합니다.  
※ 회사에 따라서는 인프라 담당자가 관리자를 겸하는 등, 한 사람이 여러 역할을 맡기도 합니다.

- ##### 인프라 담당자  
→ Exment를 서버에 설치하고 업데이트하는 등, 서버 관련 작업을 하는 사람

- ##### 관리자  
→ 설치한 뒤의 초기 설정이나 테이블·열 추가 등, Exment를 쓰기 위한 설정을 하는 사람

- ##### 사용자(일반 사용자)  
→ 관리자가 준비한 테이블을 써서 데이터를 등록·편집·삭제하는 사람

- ##### 개발자  
→ 플러그인을 쓸 때 등 특별한 기능이 필요해졌을 때, Exment를 확장하는 개발을 하는 사람  

### 단계

#### 【인프라 담당자】
- [설치](/ko/quickstart)  
서버에 Exment를 설치합니다.  

- [업데이트](/ko/update)  
Exment의 새 버전이 나왔을 때, 서버에 로그인하여 업데이트합니다.  

#### 【관리자】
- [초기 설정](/ko/first_setting)  
설치한 바로 뒤에 사이트 이름, 첫 관리자의 로그인 ID 등 필요한 항목을 등록합니다.

- [사용자 정의 테이블 설정](/ko/table)  
"고객 관리", "작업 관리" 등 관리하고 싶은 것을 테이블로 등록합니다.  

- [사용자 정의 열 설정](/ko/column)  
"고객 관리" 테이블의 "고객 이름", "우편번호", "주소" 등 관리하고 싶은 항목을 열로 등록합니다.

- [템플릿](/ko/template)  
준비된 템플릿을 쓰면 사용자 정의 테이블·사용자 정의 열을 처음부터 만들지 않고 한꺼번에 추가할 수 있습니다.

##### ■ 그 밖에 필요한 설정

- [사용자·로그인 사용자](/ko/user)  
일반 사용자가 Exment에 로그인하기 위한 ID·비밀번호를 설정합니다.

- [역할·권한](/ko/permission)  
사용자별로 Exment에서 조작할 수 있는 범위를 정합니다.

- [메뉴](/ko/menu)  
화면 왼쪽에 항상 나와 있는 메뉴의 항목을 관리합니다.  

#### 【사용자(일반 사용자)】
- [데이터](/ko/data)  
관리자가 설정한 사용자 정의 테이블에 데이터를 추가·업데이트·열람·삭제합니다.  

- [검색](/ko/search)  
등록한 데이터를 쉽게 검색할 수 있습니다.  


#### 【개발자】
- [플러그인](/ko/plugin_quickstart)  
Exment의 기능을 확장해야 할 때, 플러그인을 업로드하여 기능을 더할 수 있습니다.
