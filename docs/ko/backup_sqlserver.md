# 백업·복원(SQL Server)
데이터베이스로 SQL Server를 쓰고 있을 때 Exment의 데이터를 수작업으로 백업/복원(원래대로 되돌리는 것)하는 절차입니다.  

## 개요
SQL Server를 쓰고 있을 때는 Exment의 화면에서 백업/복원을 할 수 없습니다. 다음 2가지를 수작업으로 하십시오.

| 대상 | 방법 |
| ---- | ---- |
| 데이터베이스 | Microsoft SQL Server Management Studio (SSMS)에서 백업과 복원을 합니다 |
| 파일(아래 4가지) | 탐색기 등으로 폴더째 다른 장소에 저장합니다. 필요할 때 원래대로 되돌립니다 |

- 플러그인 파일
- 첨부 파일
- 로그 파일
- 설정 파일

## 데이터베이스의 백업
SQL Server의 백업을 받는 절차입니다.  
원하는 때에 실행하십시오.  

- Microsoft SQL Server Management Studio (SSMS)를 시작합니다.  
**※반드시 sysadmin 서버 역할, db_owner 데이터베이스 역할, db_backupoperator 데이터베이스 역할 중 하나를 가진 멤버로 로그인하십시오.**
![백업 화면](../img/backup/sqlserver1.png)  

- 백업할 데이터베이스를 오른쪽 클릭하고 태스크→백업을 고릅니다.  
![백업 화면](../img/backup/sqlserver2.png)  

- 데이터베이스 백업 화면에서 "백업 유형: 전체"를 고르고, 백업 대상의 추가를 클릭합니다.  
![백업 화면](../img/backup/sqlserver3.png)  

- 백업 대상 선택 대화 상자가 나오므로 원하는 폴더와 파일 이름을 정하고 확인 버튼을 클릭합니다.  
![백업 화면](../img/backup/sqlserver4.png)  

- 데이터베이스 백업 화면으로 돌아가서 확인 버튼을 클릭하십시오. 백업이 시작됩니다. 끝나면 메시지가 나옵니다.   
![백업 화면](../img/backup/sqlserver5.png)  

- 정한 백업 대상에 백업 파일(.bak)이 만들어져 있는지 확인하십시오.

## 각종 파일의 백업
다음 파일은 서버의 정해진 폴더에 있습니다. 탐색기 등으로 다른 폴더나 외부 미디어에 폴더째 저장하십시오.
  
~~~
플러그인 파일: (프로젝트의 루트 디렉터리)/storage/app/plugins
첨부 파일    : (프로젝트의 루트 디렉터리)/storage/app/admin
로그 파일    : (프로젝트의 루트 디렉터리)/storage/logs
설정 파일    : (프로젝트의 루트 디렉터리)/config
.env 파일    : (프로젝트의 루트 디렉터리)/.env
~~~
    
**※.env 파일은 Laravel의 중요한 설정이 들어 있는 파일입니다. 백업해 두기를 권장합니다. 다만 복원할 때 그대로 바꿔 놓지 마십시오**.

## 데이터베이스의 복원
SQL Server의 백업을 원래대로 되돌리는 절차입니다.  
반드시 Exment를 쓰고 있는 사용자가 없는 것을 확인한 다음에 하십시오.  

- Microsoft SQL Server Management Studio (SSMS)를 시작합니다.  
**※반드시 sysadmin 또는 dbcreator 서버 역할을 가진 멤버, 또는 데이터베이스의 소유자 (dbo)로 로그인하십시오.**
![백업 화면](../img/backup/sqlserver1.png)  

- 복원할 데이터베이스를 오른쪽 클릭하고 태스크→복원→데이터베이스를 고릅니다.  
![백업 화면](../img/backup/sqlserver6.png)  

- 데이터베이스 복원 화면에서 "원본: 디바이스"를 고르고 "..."을 클릭해서 백업 디바이스 선택 대화 상자를 엽니다.  
![백업 화면](../img/backup/sqlserver7.png)  

- 추가 버튼을 클릭하면 백업 파일 찾기 대화 상자가 나옵니다. 되돌리고 싶은 백업 파일을 고르고 확인을 클릭합니다.  
![백업 화면](../img/backup/sqlserver8.png)  

- 백업 디바이스 선택 대화 상자에 고른 파일이 추가되어 있는지 확인하고, 다시 한 번 확인을 클릭합니다.  
![백업 화면](../img/backup/sqlserver9.png)  

- 데이터베이스 복원 화면으로 돌아갑니다. "페이지 선택: 옵션"을 골라 옵션 탭을 엽니다. "복원 옵션: 기존 데이터베이스 덮어쓰기"와 "서버 연결: 대상 데이터베이스에 대한 기존 연결 닫기"에 체크하고 확인을 클릭합니다.  
![백업 화면](../img/backup/sqlserver10.png)  

- 복원이 끝나면 메시지가 나옵니다.  
![백업 화면](../img/backup/sqlserver11.png)  


### 복원할 때의 주의
- 백업을 받았을 때의 Exment 버전과 지금 설치되어 있는 Exment 버전이 다를 때는, 복원한 다음에 데이터베이스를 최신 상태로 만들어야 합니다.  
예: 백업 시점의 버전: v1.1.6 현재 버전: v1.2.0  →데이터베이스의 최신화가 필요  
그때는 복원한 다음에 다음 명령을 실행하십시오.  

~~~
php artisan exment:update
~~~
    
**※새 버전의 Exment에서 백업한 데이터베이스를 옛 버전의 Exment에 복원할 수는 없습니다**.


## 각종 파일의 복원
저장해 둔 파일을 탐색기 등으로 폴더째 원래대로 되돌립니다.  

- 플러그인 파일과 첨부 파일은 데이터베이스의 데이터와 이어져 있습니다. 같은 때에 백업한 것을 데이터베이스와 함께 복원하십시오.
- 로그 파일은 그대로 덮어쓰지 말고, 다른 이름을 붙여 같은 폴더에 저장해 두기를 권장합니다.
  
~~~
플러그인 파일: (프로젝트의 루트 디렉터리)/storage/app/plugins
첨부 파일    : (프로젝트의 루트 디렉터리)/storage/app/admin
로그 파일    : (프로젝트의 루트 디렉터리)/storage/logs
설정 파일    : (프로젝트의 루트 디렉터리)/config
~~~
