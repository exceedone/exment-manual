# API 키
사용자가 직접 API 키를 만들어, 프로그램이나 AI에서 자신의 권한으로 Exment의 API를 호출할 수 있습니다. OAuth 액세스 토큰 대신 `Authorization: Bearer exk_...` 로 보냅니다.

※이 기능은 Exment v7.2.1 이상에서 사용할 수 있습니다.  
※처음에는 "사용 안 함"입니다. 시스템 관리자가 "설정: 시스템" → "[기능 관리](/ko/feature)"에서 "사용자의 API 키"를 사용하도록 설정하고, 사용할 수 있는 역할 그룹을 선택해 주십시오.  
※OAuth 액세스 토큰([API 설정](/ko/api))은 지금까지와 같이 사용할 수 있습니다.

## 자신의 키 만들기
오른쪽 위 사용자 메뉴의 "설정" 화면에 있는 "API 키"에서 엽니다(URL은 `/auth/api_keys`). 시스템 관리자는 "API 설정" 목록에서도 열 수 있습니다.

![API 키](../ja/img/api_key/api_key_mine.png)

| 항목 | 내용 |
|---|---|
| 이름 | 키의 용도를 알 수 있는 이름 |
| 할 수 있는 작업 | "읽기 전용"(me·table_read·view_read·value_read·workflow_read·notify_read)이거나, 범위를 선택 |
| 테이블 | 볼 수 있는 모든 테이블이거나, 선택한 테이블만. 선택하면 그 테이블의 API와 자신의 정보(me)만 호출할 수 있습니다 |
| 허용 IP 주소 | 한 줄에 하나씩(범위도 가능). IPv4와 IPv6(7.3.0부터: `2001:db8::/32`, `2001:db8:1:2::/64`). 비어 있으면 어디서나(사이트 전체의 API IP 제한은 그대로 적용됩니다) |
| 만료일 | 7·30·90(기본값)·180·365일 |
| 클라이언트 인증서 | 인증서의 SHA-256 지문을 넣으면, 그 인증서를 붙였을 때만 사용할 수 있습니다(인증서는 앞단의 웹 서버가 확인합니다) |
| 현재 비밀번호 | 만들 때 지금의 비밀번호를 넣습니다 |

- **키는 만들었을 때 한 번만 표시합니다**. 적어 두고, 다른 사람에게 넘기지 마십시오. 나중에 볼 수는 없습니다.
- 키로 할 수 있는 것은 **그 사용자가 화면에서 할 수 있는 것 중 키에 선택한 범위뿐**입니다.
- 사용할 수 있는 키는 1명당 10개까지입니다.
- 목록에 마지막으로 사용한 일시·IP·횟수가 나옵니다. 필요 없어진 키는 목록에서 중지해 주십시오.

## 키 사용하기
~~~
curl -H "Authorization: Bearer exk_xxxxxxxx" https://(Exment의 URL)/api/data/(테이블 이름)
~~~

※"/admin"이 붙어 있는 사이트에서는 `https://(Exment의 URL)/admin/api/...` 입니다([URL에 포함된 "admin"](/ko/additional_prefix)).

키는 만료일이 지났을 때, 중지했을 때, 사용자나 로그인을 삭제했을 때, 사용할 수 있는 역할 그룹에서 빠졌을 때, 허용 IP 주소나 인증서와 맞지 않을 때, 선택한 테이블 밖을 호출했을 때 사용할 수 없게 됩니다(이유는 돌려주지 않습니다).

## 시스템 관리자: 모든 키
"API 키" 관리 화면(URL은 `/api_keys`)에서 이 사이트의 사용자가 만든 API 키를 보고, 키 하나 또는 사용자의 모든 키를 바로 중지할 수 있습니다.

![API 키 관리](../ja/img/api_key/api_key_admin.png)

- SSO 사용자는 IdP에서 중지해도, 만료일이 되거나 여기에서 중지할 때까지 키를 사용할 수 있습니다. 사람이 그만두었을 때는 "이 사용자의 키를 모두 중지"를 사용해 주십시오.
- `.env` 의 `ADMIN_API_KEY_REQUIRE_CLIENT_CERT=true` 로 모든 키에 클라이언트 인증서를 요구할 수 있습니다. 로드 밸런서 등의 뒤에서는 `ADMIN_TRUST_PROXY_IPS` 를 설정하면 실제 IP로 비교합니다.
