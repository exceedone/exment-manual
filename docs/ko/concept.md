# Exment의 콘셉트

![Excel과 흩어진 파일에서 벗어납시다](../ja/img/concept/concept_hero.png)

## Exment란
Exment는 **프로그램을 쓰지 않고 우리 회사의 업무에 맞는 앱을 만들 수 있는 웹 데이터베이스**입니다.  
고객 목록·안건·신청·자산 대장 등, 지금 Excel이나 종이, 메일 첨부로 따로따로 관리하는 데이터를 한곳에 모읍니다. 누가 어디에서 열어도 같은 최신 데이터로 일할 수 있습니다.

> 처음에는 "빈 상자"입니다. 거기에 관리하고 싶은 것에 맞추어 테이블(표)을 더해 가면, 그 회사를 위한 업무 시스템이 됩니다. 고객을 더하면 고객 관리가 되고, 신청을 더하면 워크플로가 됩니다. **쓰는 방법은 회사의 수만큼 있습니다.**

## 3가지 특징
### 1. 만들 수 있다 —— 프로그램 없이
- 화면 조작만으로 테이블·항목·입력 폼·목록(뷰)을 만들 수 있습니다.
- 목록은 표·캘린더·칸반·간트 차트·그래프로 볼 수 있습니다.
- 템플릿(고객 관리·신청 팩 등)을 고르면 바로 쓰기 시작할 수 있습니다.

### 2. 돌릴 수 있다 —— 팀으로, 안전하게
- 신청 → 승인·반려의 **워크플로**, 기한이나 데이터 변경의 **알림**(메일·Slack·Microsoft Teams·LINE).
- 역할 그룹으로 누가 무엇을 볼 수 있고 고칠 수 있는지 정할 수 있습니다. 작업 로그도 남습니다.
- 대시보드로 지금의 숫자를 한눈에 봅니다. 스마트폰의 브라우저에서도 쓸 수 있습니다.

### 3. 이어진다 —— 다른 시스템이나 AI와
- API로 다른 시스템과 데이터를 주고받을 수 있습니다. 사용자별 API 키도 만들 수 있습니다.
- **AI(MCP)**: Claude 등의 AI에서 사용자의 권한 그대로 데이터를 읽을 수 있습니다.
- 공식 플러그인(프로젝트 관리·서포트 데스크·Groupware)이 무료로 함께 들어 있습니다. 플러그인으로 기능을 더할 수 있습니다.

## Excel과의 차이
| | Excel·파일 | Exment |
|---|---|---|
| 최신 데이터 | 파일이 복사되어 어느 것이 최신인지 알 수 없다 | 언제나 하나. 모두가 같은 데이터를 본다 |
| 동시에 쓰기 | 열고 있는 사람이 있으면 고칠 수 없다 | 몇 명이든 동시에 입력할 수 있다 |
| 권한 | 파일 단위. 행이나 열 단위는 어렵다 | 역할 그룹으로 테이블·데이터 단위로 |
| 이력 | 덮어쓰면 사라진다 | 변경 이력·작업 로그가 남는다 |
| 승인·알림 | 메일이나 종이로 돌린다 | 워크플로와 알림으로 자동으로 |
| 찾기 | 파일을 열어서 찾는다 | 키워드 검색·필터·정렬 |

## 예를 들면 이런 사용법
**고객 관리**: 거래처와 담당자를 모아서, 누구나 같은 정보를 볼 수 있게 합니다.

![고객 관리](../ja/img/concept/concept_customer.png)

**파일 공유**: 부서별 워크스페이스에 제안서·견적서·계약서를 둡니다. 버전 관리와 권한이 붙습니다.

![파일 공유](../ja/img/concept/concept_files.png)

그 밖에도 신청·승인(품의·경비 정산·휴가), 안건 관리, 자산·비품 관리, 문의 관리, 일일 보고 등이 있습니다. 어떤 업무든 테이블을 더하는 것에서 시작할 수 있습니다. 자세한 내용은 [기능 맵](https://exment.net/en/feature-map/)을 보십시오.

## 계속 쓸 수 있는 오픈 소스
- **무료 오픈 소스**(GPL-3.0). 자체 서버에 설치하면 **사용자가 늘어도 요금은 늘지 않습니다**.
- 데이터는 자체 서버에 둡니다. 서버를 준비하고 싶지 않을 때는 Exment SaaS도 고를 수 있습니다.
- 유상 지원으로 도입부터 운용까지 상담할 수 있습니다.
