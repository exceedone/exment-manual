# 스튜디오
스튜디오는 화면을 만들고·고치고·모아서 보기 위한 기능입니다. kintone의 앱처럼 부품을 늘어놓기만 하면 데이터를 담는 곳(테이블)과 입력 화면·목록을 만들 수 있습니다. 만든 화면은 스마트폰 앱(Exment 앱)에서도 쓸 수 있습니다.

※ 여기에 적은 기능은 Exment v7.2.1에서 갖추어집니다.

## 처음 쓸 때
- 스튜디오는 처음에는 "사용 안 함"입니다. 시스템 관리자가 "관리자 설정" → "[기능 관리](/ko/feature)"에서 "스튜디오"를 "사용"으로 하면 "관리자 설정" 아래에 "스튜디오" 메뉴가 나옵니다(URL은 `/studio`).
- 스튜디오를 열 수 있는 것은 기능 관리에서 고른 사람 중 어느 테이블에서든 테이블·폼·뷰의 설정 권한이 있는 사람과 시스템 관리자입니다.

| 할 수 있는 것 | 필요한 권한 |
| --- | --- |
| 새 앱(테이블)을 만든다 | 시스템의 "테이블" 권한 |
| 지금 있는 테이블에 화면을 더한다·스튜디오에서 고친다 | 그 테이블의 폼 설정 권한 |
| 버튼을 만든다·고치는 화면에서 새 항목(열)을 더한다 | 그 테이블의 설정 권한 |

## 화면 목록
스튜디오를 열면 사이트의 화면을 한 화면에서 모아 볼 수 있습니다.

| 칸 | 내용 |
| --- | --- |
| 테이블 화면 | 테이블마다 입력 화면(폼)과 목록(뷰)이 나란히 나옵니다. "열기", "편집", "복제"와 "열 설정", "테이블 설정"으로 가는 링크가 있습니다. 위의 칸에서 테이블 이름·화면 이름으로 필터할 수 있습니다. |
| 대시보드(모아 보는 화면) | 시스템의 대시보드와 사용자의 대시보드입니다. |
| 플러그인 페이지 | 페이지의 플러그인입니다. |
| 테이블 관계도 | 부모-자식(1대다)·다대다의 관계와 다른 테이블을 선택하는 열을 그림으로 볼 수 있습니다. |

- 입력 화면의 이름(과 연필 아이콘)을 누르면 [스튜디오에서 고치기](/ko/studio?id=스튜디오에서-고치기) 화면이 열립니다. 지금까지의 폼 설정 화면은 톱니바퀴 아이콘("폼 설정에서 열기")에서 열 수 있습니다.
- 목록에 나오는 것은 자신이 설정할 수 있는 테이블과 그 안의 설정할 수 있는 화면뿐입니다.

## 새 앱·화면 만들기
목록의 "새 앱 또는 화면"을 누릅니다. 만드는 방법은 3가지입니다.

| 만드는 방법 | 내용 |
| --- | --- |
| 새 앱 만들기 | 부품을 늘어놓으면 테이블과 열·입력 화면·목록이 만들어집니다. 고르면 칸반·캘린더·그래프·대시보드도 한꺼번에 만들어집니다([앱으로 한꺼번에 만들기](/ko/studio?id=앱으로-한꺼번에-만들기)). |
| 기존 테이블에 화면 추가 | 테이블은 만들지 않습니다. 지금 있는 열을 늘어놓아 입력 화면(폼)만 만듭니다. |
| Excel 또는 CSV에서 만들기 | Excel(.xlsx)이나 CSV를 읽어 들이면 1행째를 항목 이름, 2행째부터를 데이터로 하여 부품을 추측해서 늘어놓습니다. 다른 곳은 고친 뒤에 저장합니다. "데이터도 가져오기"로 하면 데이터도 함께 들어갑니다(1,000행까지, 파일은 10MB까지). |

저장하기 전에 무엇이 만들어지는지("저장하면 앱 "○○"(테이블, 입력 화면, 목록)이 만들어집니다." 등)가 나옵니다. 저장하면 만든 화면에서 데이터를 입력할 수 있습니다.

### 부품
| 부품 | 내용 |
| --- | --- |
| 한 줄 텍스트·여러 줄 텍스트·URL·이메일 | 문자를 넣습니다. |
| 정수·소수·통화 | 수를 넣습니다. |
| 계산 | 다른 수의 항목에서 계산합니다(아래의 "계산"). |
| 날짜·날짜 및 시각·시각 | 날짜나 시각을 넣습니다. |
| 선택지·YES/NO | 정해진 것 중에서 고릅니다. 선택지는 한 줄에 하나씩 씁니다. |
| 선택 (테이블에서) | 다른 테이블의 데이터를 고릅니다. "선택할 원본 테이블"을 정합니다. |
| 사용자·조직 | Exment의 사용자나 조직을 고릅니다. |
| 자동 번호 | 저장하면 날짜와 번호(예: 20261121-0001)가 자동으로 붙습니다. |
| 파일·이미지 | 파일이나 이미지를 첨부합니다. |

- 부품을 누르면 맨 끝에 더하고, 드래그하면 원하는 곳에 넣을 수 있습니다. 항목은 100개까지 둘 수 있습니다.
- 항목마다 항목 이름·열 이름(영문자와 숫자)·필수를 정합니다.

### 행과 열의 배치
행마다 "1열", "2열", "2열(왼쪽이 넓음)", "2열(오른쪽이 넓음)", "3열", "4열"을 고르면 항목을 가로로 늘어놓을 수 있습니다. 스마트폰에서는 세로로 늘어섭니다. 행은 50행까지 만들 수 있습니다.

### 표시 조건
항목마다 다른 항목의 값으로 표시를 전환할 수 있습니다("같음", "같지 않음", "비어 있음", "비어 있지 않음"). 예를 들면 상태가 "보류"일 때만 "이유"를 내보냅니다. 필수 항목에는 조건을 붙일 수 없습니다.

### 명세(자식 테이블)
주문 안의 상품처럼 데이터 1건에 여러 행을 입력하는 명세를 만들 수 있습니다. 명세마다 자식 테이블이 만들어지고, 입력 화면의 아래에 표의 형태로 나옵니다. 명세는 5개까지 만들 수 있습니다. 명세 안에서도 계산·다른 테이블에서 고르는 부품을 쓸 수 있습니다.

### 계산
계산 부품에서는 다른 수의 항목(정수·소수·통화·계산)을 `[ ]`로 둘러싸서 씁니다.

- 예: `[수량] * [단가]`
- 명세의 합계: `SUM[명세의 이름.항목]`(예: `SUM[주문 명세.금액]`)
- 쓸 수 있는 것은 항목·수·`+ - * / ( )`뿐입니다.

### 버튼
데이터 화면에 나오는 버튼을 만들 수 있습니다. 누르면 항목의 값을 바꿉니다(예: "완료로 하기"를 누르면 상태가 "완료"로).

- 한 화면에서 5개까지 만들 수 있습니다. 바꿀 수 있는 항목은 선택지·YES/NO·한 줄 텍스트·정수입니다.
- 이미 그 값이 되어 있는 데이터에는 버튼이 나오지 않습니다.
- 버튼은 테이블의 "[일괄 업데이트 설정](/ko/operation)"으로 만들어집니다. 나중에 거기에서 고치거나 지울 수 있습니다.
- 버튼을 만들 수 있는 것은 그 테이블의 설정 권한이 있는 사람뿐입니다.

### 상세 설정
- **테이블 이름(영문자와 숫자)**: 데이터의 URL 등에 쓰는 이름입니다. 비어 있을 때는 자동으로 붙입니다. 나중에 바꿀 수는 없습니다.
- **메뉴에 추가할 위치**: 왼쪽 메뉴의 어디에 더할지를 고릅니다("추가하지 않음"도 고를 수 있습니다).

## 앱으로 한꺼번에 만들기
"새 앱 만들기"에서는 "앱과 함께 만들 항목" 칸에서 데이터를 보는 화면도 함께 만들 수 있습니다.

| 만드는 것 | 쓰는 항목 |
| --- | --- |
| 칸반 | 레인으로 나눌 항목(선택지) |
| 캘린더 | 날짜 항목(캘린더에서 찾을 수 있도록 그 항목의 검색 인덱스를 켭니다) |
| 차트(건수) | 나누는 항목(선택지·YES/NO)별 건수 |
| 대시보드 | 목록·그래프·캘린더를 늘어놓습니다. 시스템 관리자가 만들면 모두에게, 다른 사람이 만들면 자신에게만 보입니다. |

- 쓸 수 있는 항목을 두면 자동으로 켜집니다. 끌 수도 있습니다.
- 모두 뷰·대시보드의 설정 화면에서 만드는 것과 같은 것입니다. 나중에 그 화면에서 고칠 수 있습니다.

## 스튜디오에서 고치기
스튜디오에서 만든 입력 화면(과 지금 있는 테이블의 폼)을 만들 때와 같은 화면에서 고칠 수 있습니다. 화면 목록에서 입력 화면의 이름을 누릅니다. 고칠 수 있는 것은 그 테이블의 폼 설정 권한이 있는 사람입니다.

- 항목을 옮기고·빼고, 표시 조건을 붙이고·빼고, 화면의 이름을 바꾸고, 버튼을 더할 수 있습니다.
- 화면에서 뺀 항목도 테이블의 열과 데이터는 그대로 남습니다.
- "새 항목(테이블에 열도 만들어집니다)"에서 부품을 더하면 저장했을 때 테이블에 열이 만들어지고 목록에도 나옵니다. 이것을 할 수 있는 것은 테이블의 설정 권한이 있는 사람뿐입니다. 계산 부품은 여기에서는 더할 수 없습니다(열 설정에서 더합니다).
- 제목·설명문·HTML·이미지·구분선·시스템의 항목 등 스튜디오에 아직 없는 항목은 지우지 않고 남깁니다. 옮기거나 뺄 수는 있고, 내용은 폼 설정에서 고칩니다.
- 명세(자식 테이블의 입력)는 그대로 남습니다. 명세를 고칠 때는 폼 설정에서 여십시오.
- 저장하기 전에 무엇이 바뀌는지("테이블 "○○"에 열 "○○"도 만들어집니다." 등)가 나옵니다.

## 스마트폰 앱(Exment 앱)
스마트폰의 브라우저에서 `/app`을 열면 스튜디오의 화면을 스마트폰 앱으로 쓸 수 있습니다. "홈 화면에 추가"하면 앱처럼 열 수 있습니다.

- **화면**: 쓸 수 있는 테이블의 입력 화면이 나란히 나옵니다. 열면 목록이 나오고, 오른쪽 아래의 "+"로 새로 등록할 수 있습니다.
- **사진·파일**: 파일·이미지 항목에서는 그 자리에서 사진을 찍어 붙일 수 있습니다. 사진은 스마트폰 안에서 작게 한 뒤에 보냅니다.
- **코드 스캔**: 위의 버튼에서 카메라로 QR 코드·바코드를 읽을 수 있습니다. Exment의 2차원 바코드([2차원 바코드 설정](/ko/2d_barcode))나 데이터 URL의 QR 코드라면 그 데이터가 열립니다. 목록 화면에서 읽으면 그 테이블의 문자·정수·자동 번호 열이 같은 데이터를 찾습니다. JAN 코드도 찾을 수 있습니다.
- **전파가 없을 때**: 저장할 때 전파가 없으면 입력(명세·사진도)을 스마트폰 안에 임시 저장으로 보관해 두고, 앱을 열었을 때나 전파가 돌아왔을 때 자동으로 보냅니다. 한 번 연 화면은 전파가 없어도 열 수 있으므로 새로 입력할 수도 있습니다. "전송하지 않은 임시 저장" 목록에서 열어서 고치기·지금 바로 보내기·지우기를 할 수 있습니다. 서버가 받아들이지 않은 임시 저장은 이유를 내보내고 남깁니다. 임시 저장은 사용자별입니다.
- "PC 버전"으로 평소의 화면으로 돌아갈 수 있습니다.
