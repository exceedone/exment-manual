# 사용자별 언어와 시간대
v7.2.4부터 사용자마다 화면의 언어와 시간대를 고를 수 있습니다. 메일과 알림도 받는 사람의 언어와 시간대로 도착합니다.

## 언어 고르기
언어는 다음 어디에서나 고를 수 있습니다.

- 오른쪽 위의 사용자 메뉴
- 로그인 사용자 설정(오른쪽 위의 사용자 메뉴 → "로그인 사용자 설정")의 "언어"
- 로그인 화면

고를 수 있는 언어는 日本語·English·Tiếng Việt·简体中文·한국어·Deutsch·Español입니다.  
※베트남어·중국어(간체)·한국어·독일어·스페인어 화면은 기계 번역입니다. 고치는 편이 좋은 곳은 [GitHub](https://github.com/exceedone/exment/issues)에서 알려 주십시오.  
※관리자는 사용자가 고를 수 있는 언어를 줄일 수 있습니다(아래의 "관리자의 설정").

### 사용할 언어의 순서
Exment는 다음 순서로 언어를 정합니다.

1. 사용자가 로그인 사용자 설정에서 고른 언어
1. 로그인 화면에서 고른 언어
1. 브라우저의 언어(시스템 설정의 "사용자가 언어를 선택하지 않았을 때 브라우저의 언어 사용"이 YES일 때. 사용자가 고를 수 있는 언어 중에서)
1. 사이트의 언어

로그인 사용자 설정의 "언어"에서 "자동(브라우저의 언어)"을 고르면, 언어를 고르지 않은 상태로 돌아갑니다.

> [!WARNING]
> v7.2.4로 업데이트하면, 언어를 고르지 않은 사용자 중 브라우저의 언어가 사이트의 언어와 다른 사람에게는 브라우저의 언어로 화면이 나옵니다.  
> 모든 사용자를 사이트의 언어 그대로 두려면, 시스템 설정 → [상세 설정]의 "사용자가 언어를 선택하지 않았을 때 브라우저의 언어 사용"을 NO로 하십시오.

## 시간대 고르기
시간대는 로그인 사용자 설정의 "시간대"에서 고릅니다. 초기값은 "사이트의 시간대"입니다.

고른 시간대로 날짜와 시간을 표시하고 입력합니다. 대상은 목록·상세·폼·"오늘" 등의 필터·캘린더·간트 차트·칸반·댓글·업데이트 이력·알림·작업 로그입니다.

### 사이트의 시간대 그대로인 것
- 데이터베이스에는 사이트의 시간대로 저장합니다.
- 날짜만 있는 열(시각이 없는 날짜)은 바꾸지 않습니다.
- API는 사이트의 시간대 그대로입니다.
- 날짜와 시간으로 묶은 그래프(집계 뷰나 대시보드)는 사이트의 시각으로 묶습니다. 그래프에는 "(사이트 시간: Asia/Tokyo)"처럼 나옵니다.
- 내보내기는 초기값에서는 사이트의 시간대입니다. "내 시간대의 날짜와 시간으로 내보내기(…)"를 고르면, 자신의 시간대로 내보낼 수 있습니다.
- 가져오기에서는 "파일의 날짜와 시간의 시간대"에서, 파일의 날짜와 시간이 사이트의 시간대인지 자신의 시간대인지를 고릅니다.

## 메일과 알림
메일과 알림은 받는 사람의 언어와 시간대로 보냅니다. 받는 사람이 언어를 고르지 않았을 때는 사이트의 언어입니다.

## 관리자의 설정
시스템 설정 → [상세 설정]에서 설정합니다([시스템 설정](/ko/system_setting)).

| 항목 | 내용 | 초기값 |
| --- | --- | --- |
| 사용자가 선택할 수 있는 언어 | 사용자가 오른쪽 위의 메뉴·로그인 화면·로그인 사용자 설정에서 고를 수 있는 언어입니다. 비어 있을 때는 들어 있는 모든 언어를 고를 수 있습니다. 사이트의 언어는 언제나 고를 수 있습니다. | 비어 있음(모두) |
| 사용자가 언어를 선택하지 않았을 때 브라우저의 언어 사용 | YES로 하면, 언어를 고르지 않은 사용자에게는 브라우저의 언어(사용자가 고를 수 있는 언어 중에서)로 화면을 표시합니다. NO로 하면 사이트의 언어로 표시합니다. | YES |

사이트의 언어와 시간대는 지금까지처럼 `.env`의 `APP_LOCALE`과 `APP_TIMEZONE`으로 정합니다.
