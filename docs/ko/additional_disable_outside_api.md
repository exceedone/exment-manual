# 서버 외부 통신 끄기
Exment 서버에서 다른 서버로 가는 통신을 멈추는 설정입니다.  
완전한 온프레미스 환경 등, 다른 서버와 통신하지 않는 환경에서 사용합니다.

Exment는 다음 용도로 다른 서버와 통신하는 경우가 있습니다.

- Exment에 최신 버전이 있는지 판단하기 위해, 패키지 시스템과 통신하여 최신 버전 정보를 가져온다
- 대시보드의 "Exment 새 소식 목록"에 표시하기 위해, Exment 공식 사이트(exment.net)와 통신하여 새 소식을 가져온다

### 설정 절차 
> 이 절차는 v1.3.0부터 바뀌었습니다.

1. 왼쪽 메뉴에서 "시스템 설정" 화면을 엽니다.
2. 목록 안의 "서버 외부 통신 수행" 항목을 NO로 합니다.  
![서버 외부 통신 끄기](../img/quickstart/outside_api.png)
3. 저장합니다. 이것으로 설정은 끝입니다.
