# 예약 작업
서버의 cron(`php artisan schedule:run`)이 정해진 시간에 실행하는 작업의 목록입니다. "설정: 시스템" → "예약 작업"(URL은 `/scheduled_jobs`)에서 엽니다.

※ 이 화면은 Exment v7.2.6 이후에서 쓸 수 있습니다.  
※ 이 화면을 볼 수 있는 것은 시스템 관리자뿐입니다.

## 쓰기 시작하기
[기능 관리](/ko/feature)에서 "예약 작업"을 "사용"으로 합니다. 처음에는 "사용 안 함"입니다. 쓰지 않을 때는 이 화면을 열 수 없습니다(404가 됩니다).

작업의 기록은 쓰고 있는 동안에만 남깁니다.

## cron 상태
마지막으로 `schedule:run`이 실행된 시각을 내보냅니다. 10분 이상 실행되지 않았을 때는 주의를 내보냅니다. 그때는 알림·자동 백업·플러그인의 배치 등이 멈춰 있습니다. 서버의 cron에 다음 한 줄을 넣으십시오([튜닝](/ko/tuning)에서도 확인할 수 있습니다).

~~~
* * * * * cd /var/www/exment && php artisan schedule:run >> /dev/null 2>&1
~~~

## 작업 목록
| 항목 | 내보내는 것 |
|---|---|
| 작업 | Exment의 작업 이름과 명령(플러그인의 배치는 "플러그인 배치: 이름") |
| 실행 시간 | "5분마다", "매시", "매일 3:30"처럼 말로 내보냅니다 |
| 다음 실행 | 귀하의 시간대로 내보냅니다 |
| 상태 | 실행하지 않는 작업은 이유도 내보냅니다(예: "안부 확인"을 쓰고 있지 않다) |
| 마지막 실행·최근 기록 | 시작·종료·소요 시간·결과·종료 코드·실행한 사람·출력의 마지막 4KB |

작업마다 최근 20회의 기록을 남깁니다. 횟수는 `.env`의 `EXMENT_SCHEDULED_JOBS_KEEP_RUNS`로 바꿀 수 있습니다.

## 연속으로 실패했을 때
3번 연속으로 실패한 작업은 빨간색으로 내보냅니다. 시스템 관리자에게는 화면 위쪽의 알림과 메일로 한 번만 알립니다. 성공하면 원래대로 돌아가고, 다시 연속으로 실패했을 때 알립니다. 횟수는 `.env`의 `EXMENT_SCHEDULED_JOBS_ALERT_FAILURES`로 바꿀 수 있습니다.

## 지금 실행
"지금 실행"을 누르면 그 작업을 바로 백그라운드에서 실행합니다. 실행 중인 작업은 겹쳐서 실행할 수 없습니다.

다만 겹침을 막는 설정이 없는 작업(매시의 `exment:schedule`이나 플러그인의 배치)은, 정해진 시간의 실행 쪽이 "지금 실행"을 기다리지 않습니다. 실행 시각(매시 정각 등)의 바로 앞에 누르면 두 개가 동시에 실행될 수 있습니다. 실행 시각 가까이에서는 누르지 마십시오.

다음 경우에는 버튼을 누를 수 없습니다(이유를 내보냅니다). 서버의 cron은 그때도 작업을 실행합니다.
- PHP에서 외부 명령을 실행할 수 없는 서버(`proc_open`을 쓸 수 없는 임대 서버 등)
- 데모 환경

## 명령
~~~
php artisan exment:schedule-status          # 목록을 표로 내보냅니다
php artisan exment:schedule-status --json   # 작업별 마지막 실행과 연속으로 실패한 횟수를 JSON으로 내보냅니다
~~~

SaaS에서는 테넌트마다 그 테넌트의 작업과 기록만 내보냅니다.
