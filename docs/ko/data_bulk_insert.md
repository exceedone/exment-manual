# 대량 데이터 일괄 투입
csv 파일로 준비한 대량의 데이터를 서버의 명령으로 사용자 정의 테이블에 한꺼번에 넣는 기능입니다(벌크 인서트. 1000건 이상도 가능).  
속도를 중시하므로 세세한 오류 검사는 하지 않습니다.

순서는 다음과 같습니다.

1. csv 파일을 만듭니다("데이터 준비").
2. 서버의 폴더에 두고 명령을 실행합니다("조작 방법").

## 주의할 점
벌크 인서트는 속도를 중시합니다. 그러므로 다음 점에 주의하십시오.

- **만든 csv나 데이터의 내용에 잘못된 곳이 있어도 세세한 오류 검사는 하지 않습니다.** 파일은 만들 때 잘 확인하십시오. 문제가 생겼을 때는 데이터의 일부를 화면에서 가져오기로 넣어 보는 등의 방법으로 확인하십시오.

- [일반 가져오기](/ko/data_import_export)에서 할 수 있는 "[다른 테이블 데이터의 지정 방법 변경](/ko/data_import_export)"은 이 기능에서는 할 수 없습니다. id를 열에 적어서 가져오십시오.


## 데이터 준비
먼저 가져오기용 csv 파일을 만듭니다.

| 규칙 | 내용 |
| ---- | ---- |
| 1행 | 사용자 정의 테이블의 열 이름 |
| 2행 이후 | 투입할 데이터 |
| 파일 이름 | **"(사용자 정의 테이블의 이름).csv"** (예: client.csv). 한 테이블에 넣을 데이터가 여러 파일로 나뉠 때는 **"(사용자 정의 테이블의 이름).일련번호.csv"** (예: client.01.csv)처럼 일련번호를 붙입니다 |
| 문자 코드 | <strong>UTF-8</strong>(BOM 없음) |

**EXCEL로 파일을 만들면 문자 코드는 처음에 Shift_JIS가 됩니다. 반드시 먼저 텍스트 편집기 등으로 문자 코드를 변환하십시오.**  

### 사용자 정의 테이블의 열 이름으로 쓸 수 있는 값
| 항목 | 설명 |
| ---- | ---- |
| id | 기본 키(숫자) ※ 지정하고 싶은 경우에만 입력 |
| parent_type | 부모 테이블의 이름 ※ 자식 테이블의 데이터인 경우에만 입력 |
| parent_id | 연결된 부모 데이터의 ID ※ 자식 테이블의 데이터인 경우에만 입력 |
| deleted_at | 데이터의 삭제 일시 ※ 지정하고 싶은 경우에만 입력 |
| deleted_user_id | 데이터를 삭제한 사용자 ID ※ 지정하고 싶은 경우에만 입력 |
| value.(사용자 정의 열의 열 이름) | 사용자 정의 열 설정에서 등록한 열 이름. 반드시 맨 앞에 value.를 붙이십시오 |

- 특별한 이유가 없으면 csv 파일에 적는 것은 사용자 정의 열만으로 하십시오(그 밖의 항목은 자동으로 들어갑니다).  
- **일반 가져오기와 달리, 기존 데이터와 같은 id를 지정해도 업데이트는 되지 않습니다.**  

#### 샘플 파일(client.csv)
- 고객 테이블(client)에 데이터를 넣는 샘플입니다. 고객 코드(client_code)와 고객 이름(client_name)을 넣고, 3번째 데이터에만 삭제 일시(deleted_at)와 삭제 사용자 ID(deleted_user_id)를 넣었습니다.  

~~~
value.client_code,value.client_name,deleted_at,deleted_user_id
CUST001,테스트 고객 이름 001,,
CUST002,테스트 고객 이름 002,,
CUST003,테스트 고객 이름 003,2019/3/20,2
CUST004,테스트 고객 이름 004,,
CUST005,테스트 고객 이름 005,,
CUST006,테스트 고객 이름 006,,
CUST007,테스트 고객 이름 007,,
CUST008,테스트 고객 이름 008,,
CUST009,테스트 고객 이름 009,,
~~~

## 조작 방법

1. 서버의 다음 위치에 작업용 폴더를 만듭니다. 폴더 이름은 이번 작업의 내용을 알 수 있는 것이나 날짜 등을 권장합니다.  

~~~
(프로젝트의 루트 디렉터리)/storage/app/bulkinsert/(폴더 이름)
~~~

2. 만든 csv 파일(여러 개 가능)을 그 폴더에 둡니다.

#### 폴더 배치 예
![일괄 투입용 작업 폴더](../img/bulkinsert/folder1.png)  

3. 명령줄에서 다음 명령을 실행합니다.
~~~
php artisan exment:bulkinsert {폴더 이름}
~~~

#### 명령 실행 예
