# 추가 설정
[설치 절차](/ko/quickstart)가 끝나면 Exment는 동작합니다.  
다만 일부 기능을 쓰려면 추가 설정이 필요합니다.  
아래 목록에서 쓰고 싶은 기능의 페이지를 열고 절차대로 설정하십시오.  

### 설정 내용 목록

- [URL에 포함되는 "admin"의 변경·삭제](/ko/additional_prefix)  
URL 앞에 붙는 "/admin" 등의 값을 바꾸거나 없앱니다(v7.2.1 이후의 새 설치에서는 표준으로 붙지 않습니다).

- [작업 스케줄](/ko/additional_task_schedule)  
백업의 자동 작성이나 기한 알림 등, 정해진 시각에 자동으로 처리를 실행하기 위한 설정입니다.

- [서버 외부 통신 끄기](/ko/additional_disable_outside_api)  
Exment의 업데이트 정보 가져오기 등, 서버에서 외부 서버로 가는 통신을 멈추기 위한 설정입니다.

- [캐시 활성화](/ko/additional_cache)  
사용자 정의 테이블·열·뷰·워크플로 등의 마스터 데이터를 캐시합니다. 환경에 따라서는 빨라질 수 있습니다.

- [파일 저장 위치 변경](/ko/additional_file_saveplace)  
파일의 저장 위치를 로컬 서버에서 FTP나 AWS S3 등으로 바꾸는 절차입니다.

- [PHP 설정값 변경](/ko/additional_php_ini)  
첨부 파일의 업로드 크기·PHP의 메모리 사용량·타임아웃 시간을 바꾸는 절차입니다.

- [IP 필터](/ko/additional_ip_filter)  
웹 페이지에 대한 요청과 API의 실행을 IP 주소로 제한할 수 있습니다.

- [API에서 429 오류가 발생할 때](/ko/additional_429_too_many)  
API를 실행했을 때 429 Too Many Requests가 나오는 경우의 대처법입니다.

- [데이터 가져오기 API에서 label 열을 추가하기](/ko/additional_api_label)  
데이터 목록을 가져올 때나 데이터를 새로 만들거나 업데이트할 때, 결과에 "label" 열을 더할 수 있습니다.

- [열 종류 "한 줄 텍스트"의 설정 "사용 가능 문자"에서 자체 옵션 추가](/ko/additional_available_characters)  
사용자 정의 열의 종류 "한 줄 텍스트"의 설정 "사용 가능 문자"에서 쓸 수 있는 옵션을 더할 수 있습니다.

- [알림 처리의 지연 실행](/ko/additional_queue)  
알림 등 일부 처리를 나중에 실행하도록(큐 실행) 할 수 있습니다.

- [리버스 프록시 설정](/ko/additional_reverse_proxy)  
리버스 프록시를 쓰는 환경에서 필요한 추가 설정입니다.

- [전문 검색 엔진(Meilisearch)의 이용](/ko/additional_meilisearch)  
데이터가 많은 환경에서 전문 검색 엔진 "Meilisearch"를 써서 빠르게 검색하기 위한 설정입니다.

- [전문가 모드](/ko/additional_expert)  
더 세세한 설정 항목을 화면에 내보내기 위한 절차입니다.
