# 유지보수 모드
데이터 이전이나 플러그인 도입을 하는 동안 시스템 관리자만 사이트에 들어올 수 있게 합니다. "설정: 시스템" → "유지보수 모드"(URL은 `/maintenance`)에서 전환합니다.

※ 이 화면은 Exment v7.2.1 이후에서 쓸 수 있습니다.  
※ 이 화면을 쓸 수 있는 것은 시스템 관리자뿐입니다. "기능 관리"에서 "유지보수 모드"를 쓰는 설정으로 하십시오.

![유지보수 모드(일본어 화면)](../ja/img/maintenance/maintenance1.png)

## 유지보수 중에 할 수 있는 것
- 들어올 수 있는 것은 **시스템 관리자·유지보수를 시작한 사람·"접속을 허용할 IP 주소"** 뿐입니다.
- 다른 사람에게는 "안내 메시지"와 종료 예정을 내보낸 유지보수 화면이 나옵니다(HTTP 503). 로그인 중인 사람은 로그아웃됩니다.
- 시작과 종료·바꾼 것은 작업 로그에 남습니다.

## 설정
| 항목 | 내용 |
|---|---|
| 시작 | 비워 두면 예정 없음(바로 시작할 때는 "지금 유지보수 시작"). 정하면 시작될 때까지 로그인 중인 사람에게 화면 위쪽에서 알립니다 |
| 종료 | 지나면 자동으로 끝납니다(끄는 것을 잊는 일을 막습니다). 비워 두면 끝내는 버튼을 누를 때까지 계속됩니다 |
| 안내 메시지(ja·en) | 유지보수 화면에 내보내는 글입니다 |
| 접속을 허용할 IP 주소 | 한 줄에 하나. 범위(`192.168.0.0/24` 등)도 쓸 수 있습니다. 화면에 서버에서 본 귀하의 IP 주소가 나옵니다 |
| API(OAuth, API 키) | "시스템 관리자만", "중지", "중지하지 않음"에서 고릅니다 |
| 외부에서 접근하는 화면 중지 | 공개 폼·공유 링크·안부 확인의 응답·LINE에서의 승인과 응답을 멈춥니다 |
| 예약 작업 중지 | 스케줄·플러그인의 배치를 멈춥니다. 끝난 뒤에 한 번만 실행됩니다(자동 백업처럼 시각을 정한 작업은 다음의 그 시각까지 기다립니다) |
| 큐 중지 | 메일 등의 백그라운드 처리를 멈춥니다. 끝나면 이어서 실행됩니다 |

## 명령
화면을 열 수 없을 때나 서버 작업에서 전환할 때는 명령도 쓸 수 있습니다.

~~~
php artisan exment:maintenance status
php artisan exment:maintenance on --until="2026-12-01 09:00" --message="유지보수 중입니다" --allow-ip=192.168.0.0/24
php artisan exment:maintenance off
~~~

`php artisan down`(화면에서의 업데이트나 복원에서 쓰는 것)은 이것과는 별개이며, 그대로 동작합니다.
