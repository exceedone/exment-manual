# 워크플로 설정 예
워크플로의 설정 예입니다. 만들고 싶은 흐름에 가까운 예를 골라, 그대로 입력하십시오.  
각 항목의 의미는 [워크플로 설정](/ko/workflow_setting)을 보십시오.

| 만들고 싶은 흐름 | 예 |
|---|---|
| 신청하고, 승인·반려하기만 하는 단순한 흐름 | [신청 → 승인·반려](/ko/workflow_example?id=example1) |
| 신청한 데이터의 금액에 따라 승인하는 사람(액션)을 나눈다 | [신청 → 부장 승인 or 과장 승인·반려](/ko/workflow_example?id=example2) |
| 2단계로 확인한다. 확인하는 사람은 둘 다 신청자의 상사 열에서 정한다 | [미신청 → 확인1 → 확인2 → 완료(최초 실행 사용자 정보에서 가져오기)](/ko/workflow_example?id=example4) |
| 2단계로 확인한다. 2번째 사람은 1번째로 확인한 사람의 상사로 한다 | [미신청 → 확인1 → 확인2 → 완료(실행 사용자 정보에서 가져오기)](/ko/workflow_example?id=example5) |
| 데이터를 잠금(편집·삭제 불가)한다 | [데이터 잠금](/ko/workflow_example?id=example3) |




<h2 id="example1"><a href="#/ko/workflow_example?id=example1" data-id="example1" class="anchor"><span>신청 → 승인·반려</span></a></h2>

데이터를 신청하고 승인·반려하는, 단순한 플로의 설정 방법입니다.  

![워크플로 화면](../img/workflow/workflow1.png)  
- 사용자는 관리부에 신청한다
- 관리부는 신청을 승인한다. 또는 반려한다
- 승인된 데이터는 그 뒤로 수정할 수 없다


### Step1.상태 설정

![워크플로 화면](../img/workflow/workflow_status1.png)  

- **워크플로 표시 이름** : 임의의 이름

- **워크플로 종류** : "범용"

- **시작 상태 이름** : "미실시"

- **상태 1번째 행**  
상태 이름: "신청 중"  
데이터 편집 불가: "YES"  

- **상태 2번째 행**  
상태 이름: "완료"  
데이터 편집 불가: "YES"  


### Step2.액션 설정

![워크플로 화면](../img/workflow/workflow_action0.png)  

- **액션 설정 1번째 행**  
액션 이름: "신청"  
실행 전 상태: "미실시"  
액션 설정 > 실행 후 상태: "신청 중"  
실행 가능 사용자 : "작성 사용자"  
옵션 설정 > 다음 상태로 진행하는 조건 : "1명 이상 실행"  
옵션 설정 > 코멘트 : "선택"  


- **액션 설정 2번째 행**  
액션 이름: "승인"  
실행 전 상태: "신청 중"  
액션 설정 > 실행 후 상태: "완료"  
실행 가능 사용자 : "관리 그룹"※미리 조직 "관리 그룹"을 만들어 두십시오  
옵션 설정 > 다음 상태로 진행하는 조건 : "2명 이상 실행"  
옵션 설정 > 코멘트 : "선택"  
옵션 설정 > 특수 액션 : 체크 없음  


- **액션 설정 3번째 행**  
액션 이름: "반려"  
실행 전 상태: "신청 중"  
액션 설정 > 실행 후 상태: "미실시"  
실행 가능 사용자 : "관리 그룹"※미리 조직 "관리 그룹"을 만들어 두십시오  
옵션 설정 > 다음 상태로 진행하는 조건 : "1명 이상 실행"  
옵션 설정 > 코멘트 : "필수"  
옵션 설정 > 특수 액션 : 체크 있음

- 승인된 데이터는 그 뒤로 수정할 수 없다
