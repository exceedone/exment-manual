# 알림 템플릿
Exment가 보내는 메일이나 알림의 제목·본문 등의 틀(알림 템플릿)을 설정하는 페이지입니다.  
만든 템플릿은 [알림 설정](/ko/notify) 등에서 골라서 씁니다.  

> v3.6.0부터 이름을 "메일 템플릿"에서 "알림 템플릿"으로 변경했습니다.  
v3.6.0 미만에서 설치한 버전에서는 일부 화면의 이름이 "메일 템플릿" 그대로입니다.

## 관리 방법
### 페이지 표시
- 왼쪽 메뉴에서 "알림 템플릿"을 선택합니다.  
또는 아래의 URL에 접속하십시오.  
http(s)://(Exment의 URL)/data/mail_template  
그러면 알림 템플릿 화면이 표시됩니다.  
![알림 템플릿 화면](../img/mail/mail_grid1.png)  

> ※URL은 "/admin"이 붙지 않는 표준 설정(v7.2.1 이후에 새로 설치한 사이트)의 경우입니다. `.env`의 `ADMIN_ROUTE_PREFIX`에 값이 있는 경우(이전 버전에서 설치한 사이트는 "admin")에는 사이트의 URL 뒤에 그 값을 붙이십시오(예: `http(s)://(Exment의 URL)/admin/data/mail_template`). 자세한 내용은 [URL에 포함된 "admin"의 변경·삭제](/ko/additional_prefix)를 보십시오.

### 템플릿 새로 추가
1. "알림 템플릿" 화면에서 페이지 오른쪽 위의 [만들기] 버튼을 클릭합니다.

2. 알림 템플릿을 새로 추가하는 화면이 표시됩니다.
![알림 템플릿 화면](../img/mail/mail_new1.png)

3. 필요한 사항을 입력합니다.  
![알림 템플릿 화면](../img/mail/mail_new2.png)

### 저장
설정을 적었으면 [저장]을 클릭하십시오.

### 편집
템플릿을 편집할 때는 그 행의 [편집] 링크를 클릭하십시오.  
![알림 템플릿 화면](../img/mail/mail_edit.png)

### 삭제
템플릿을 삭제하고 싶은 경우, 해당하는 행의 [삭제] 링크를 클릭하십시오.  
![알림 템플릿 화면](../img/mail/mail_delete.png)
**<span style="color: red; ">※다만, 알림 화면에서 설정해 둔 템플릿은 삭제할 수 없습니다.</span>**

## 첨부 파일·사용자 정의 첨부 파일
메일로 알릴 때, 알림 템플릿에 설정해 둔 파일을 첨부하여 전송할 수 있습니다.  
※현재 메일 알림의 경우에만 유효합니다.  
![알림 템플릿 화면](../ja/img/mail/mail_new3.png)  

#### 첨부 파일
여기에 등록한 파일을, 메일로 알릴 때마다 정해진 첨부 파일로 전송합니다.

#### 사용자 정의 첨부 파일
여기에 파라미터를 설정하면, 각 데이터에 등록되어 있는 다음 종류의 파일을 메일 알림으로 전송합니다.  

■사용자 정의 열의 종류: "파일" "이미지"  
파라미터 설정: ${file:사용자 정의 열 이름}  

■사용자 정의 열 "선택 (테이블에서)"에서 선택한 데이터의 "파일" "이미지" 열  
파라미터 설정: ${file:select_table:선택지의 사용자 정의 열 이름.참조 대상 테이블의 파일 열 이름}  
예: 열 "customer"(고객 테이블을 참조)에서 선택한 고객의, 열 "contract_file"의 파일을 첨부하는 경우  
${file:select_table:customer.contract_file}  
※데이터가 선택되어 있지 않은 경우나 열이 존재하지 않는 경우에는 아무것도 첨부되지 않습니다.
  
■데이터 상세 화면에 등록되어 있는(아래 이미지에 해당하는 곳) 첨부 파일  
파라미터 설정: ${documents}  
![알림 템플릿 화면](../ja/img/mail/mail_data_details.png)  



## 변수의 규칙
"메일 제목"과 "메일 본문" "메일 발신자-표시 이름"에서는 변수를 쓸 수 있습니다.  
변수를 쓰면, 등록한 데이터나 시스템 이름 등을 제목·본문에 넣을 수 있습니다.
