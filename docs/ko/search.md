# 검색
Exment의 데이터를 찾는 방법의 설명입니다. 찾는 방법은 크게 2가지입니다.

| 찾는 방법 | 찾는 범위 |
|---|---|
| 페이지 위의 검색 바 | 검색 대상으로 해 둔 모든 테이블 |
| 데이터 목록 화면의 검색(검색 바·필터) | 지금 열려 있는 테이블 |

- **검색은 처음에는 앞부분 일치입니다**(입력한 글자로 시작하는 데이터를 찾습니다). 부분 일치로 바꾸는 방법은 아래의 "데이터 검색을 부분 일치로 전환"을 참고하십시오.

## 검색 바로 검색(자유어 검색)
각 페이지의 위에는 검색 바가 있습니다.  
![검색 1](../img/search/search1.png)  
이 검색 바에 단어를 입력하면 Exment에 등록된 데이터를 검색할 수 있습니다.  
검색에는 "단어 검색"과 "관련 데이터 검색"의 2가지가 있습니다.  

### 단어 검색
보통의 검색입니다. 입력한 단어를 포함하는(앞부분이 일치하는) 데이터가 결과에 나옵니다.  
![검색 2](../img/search/search2.png)  

검색 바에 단어를 입력하고 그대로 검색 버튼을 클릭하면 검색합니다.  
먼저 검색 대상이 되는 테이블의 목록이 나오고, 그다음 해당하는 데이터를 찾습니다.

**검색 대상이 되는 것**

- 테이블: 사용자 정의 테이블 설정에서 "검색 가능"이 YES로 되어 있는 테이블입니다.  

- 사용자 정의 열: 사용자 정의 열 설정에서 "검색 인덱스"가 YES이고 "자유어 검색 대상"도 YES로 되어 있는 열입니다.  
※ "검색 인덱스"가 YES인 사용자 정의 열이 1건도 없는 테이블은 검색 결과에 나오지 않습니다.  

> v3.4.0부터 검색 대상이 되는 조건으로 "자유어 검색 대상"이 YES일 것이 필요해졌습니다.  
그 전에는 "검색 인덱스"가 YES인 모든 열에서 검색했습니다. 그러나 검색 인덱스가 10~20개 설정되어 있으면 성능이 떨어질 우려가 있어, 자유어 검색의 대상을 좁힐 수 있게 했습니다.


- 검색되는 것은 사용자가 열람할 권한을 가진 테이블뿐입니다.  

- **기본 검색 설정은 앞부분 일치입니다.** 이것은 검색 속도를 위해서입니다.  
부분 일치로 바꾸고 싶을 때는 아래의 "데이터 검색을 부분 일치로 전환"을 참고하십시오.

**검색 결과**

검색 결과의 데이터에는 ［보기］, ［편집］, ［관련 데이터 검색］ 아이콘이 나옵니다.  
![검색 3](../img/search/search3.png)    
［관련 데이터 검색］ 아이콘을 클릭하면 아래의 "관련 데이터 검색"을 합니다.  

### 관련 데이터 검색
관련 데이터 검색은 어떤 데이터에 연결된 데이터를 찾는 기능입니다.  
예를 들어 "고객" 테이블이 있을 때, 그 고객에 연결된 "계약"의 데이터 목록을 보고 싶을 수 있습니다.  
![검색 6](../img/search/search6.png)  
그때 이 "관련 데이터 검색"을 쓰면 고객에 연결된 계약 데이터를 목록으로 볼 수 있습니다.  

관련 데이터 검색이 실행되는 것은 다음 경우입니다.  
- 검색 바에 단어를 입력하고, 나온 후보를 골랐을 때  
![검색 4](../img/search/search4.png)  
>후보로 목록에 나오는 문구는 [제목 표시 열 설정](/ko/table)에서 바꿀 수 있습니다.

- 단어 검색을 하고, 그 결과에 나오는 ［관련 데이터 검색］ 아이콘을 골랐을 때  
![검색 3](../img/search/search3.png)  
  
관련 데이터 검색에서 목록에 나오는 것은 다음 조건으로 연결된 데이터입니다.  
- 사용자 정의 열의 "선택지"에서, 검색에서 고른 데이터를 선택한 데이터(다만 사용자 정의 열 설정에서 "검색 인덱스"가 YES로 되어 있어야 합니다)  
- 관계 설정에서 1:n 또는 n:n으로, 검색에서 고른 데이터를 부모로 등록한 데이터  
  
관련 데이터 검색에서는 고른 데이터 자체와, 위 조건의 관련 데이터가 목록으로 나옵니다.  
아래 예에서는 고른 고객 "주식회사 ABC"의 데이터와, 그 고객에 관련된 계약이 목록으로 나와 있습니다.  
![검색 5](../img/search/search5.png)  



## 데이터 목록 화면의 검색
데이터 목록 화면에서도 검색할 수 있습니다.
방법은 검색 바로 하는 검색과, 열을 지정하는 필터 검색의 2가지입니다.

![검색 1](../ja/img/search/search7.png)  

### 검색 바로 검색(자유어 검색)
이 검색 바에 단어를 입력하면 표시하고 있는 테이블 안의 데이터를 검색할 수 있습니다.  

![검색 1](../ja/img/search/search8.png)  

검색 바에 단어를 입력하고 그대로 검색 버튼을 클릭하면 검색합니다.  

![검색 1](../ja/img/search/search9.png)  

- 자유어 검색은 지금 고른 사용자 정의 뷰와는 별개의 기능입니다.  
찾는 범위는 그 테이블의 전체 데이터입니다. 모든 자유어 검색 열을 대상으로 검색합니다.  
그래서 결과는 지금 고른 사용자 정의 뷰가 아니라 전체 데이터 뷰의 형태로 나옵니다.

- 검색 대상이 되는 사용자 정의 열은 사용자 정의 열 설정에서 "검색 인덱스"가 YES이고 "자유어 검색 대상"도 YES로 되어 있는 열입니다.  

> v3.4.0부터 검색 대상이 되는 조건으로 "자유어 검색 대상"이 YES일 것이 필요해졌습니다.  
그 전에는 "검색 인덱스"가 YES인 모든 열에서 검색했습니다. 그러나 검색 인덱스가 10~20개 설정되어 있으면 성능이 떨어질 우려가 있어, 자유어 검색의 대상을 좁힐 수 있게 했습니다.

- **기본 검색 설정은 앞부분 일치입니다.** 이것은 검색 속도를 위해서입니다.  
부분 일치로 바꾸고 싶을 때는 아래의 "데이터 검색을 부분 일치로 전환"을 참고하십시오.


### 열을 지정하는 필터 검색
"필터" 버튼을 클릭하면 열을 지정하여 자세히 검색하기 위한 상자가 나옵니다.

![검색 1](../ja/img/search/search10.png)  

![검색 1](../ja/img/search/search11.png)  

- 검색 열의 항목으로 나오는 것은 다음과 같습니다.
    1. ID, 작성 일시, 업데이트 일시
    2. 워크플로 설정이 되어 있는 테이블의 경우, "워크플로 상태"와 "내가 담당자인 데이터"의 좁히기
    3. 그 테이블을 자식으로 하는 관계 설정이 되어 있는 경우, 부모 데이터를 좁히는 선택지를 표시
    4. 그 테이블의, 사용자 정의 열 설정 "검색 인덱스"가 YES로 되어 있는 사용자 정의 열

※ 이 중 1과 2는 시스템 설정의 상세 설정 화면에서 나오지 않게 할 수 있습니다.

![검색 1](../ja/img/search/search12.png)  


## 보충 사항


### 데이터 검색을 부분 일치로 전환
데이터의 단어 검색은 기본으로는 앞부분 일치입니다.  
이것은 검색을 빠르게 하기 위해서입니다. 부분 일치에서는 검색 속도가 충분히 나오지 않습니다.  
  
다만 부분 일치로 전환할 수는 있습니다.  
메뉴 "관리자 설정 > 시스템 설정(상세 설정)"에서 "데이터 검색 방법"을 부분 일치로 바꾸십시오.  
  
![검색 1](../ja/img/search/search13.png)  

이것으로 검색이 부분 일치가 됩니다.  
※ 이 설정으로 검색이 느려질 수 있습니다. 양해해 주십시오.



### 전문 검색 엔진(Meilisearch)의 이용
데이터의 건수가 많은 환경에서는 부분 일치로 검색하면 검색이 느려질 수 있습니다.  
그때는 전문 검색 엔진 "Meilisearch"를 쓰면 빠르게 검색할 수 있습니다.  
자세한 내용은 [전문 검색 엔진(Meilisearch)](/ko/additional_meilisearch)을 확인하십시오.


### 사용자 정의 열의 종류에 따른 자유어 검색의 사양에 대하여
자유어 검색으로 찾을 수 있는 것은 기본적으로 데이터베이스에 들어 있는 값뿐입니다.  
다만 일부 사용자 정의 열에서는 사용자가 입력한 검색 값을 시스템이 먼저 바꿔 쓴 다음 검색합니다.  
그 사양을 아래에 적습니다.

> 현재, Google 검색처럼 반각 공백을 입력하여 여러 열을 AND 검색하는 것은 지원하지 않습니다.


#### 선택 (값과 표시명 저장)
설정값 "값"에 설정한 값, 또는 설정값 "텍스트"에 설정한 값으로 검색할 수 있습니다.

![검색 1](../ja/img/search/search14.png)  

![검색 1](../ja/img/search/search15.png)  


#### 선택 (테이블에서)
"제목 열"로 설정된 문구로 검색할 수 있습니다.  

예:  
- "상품 마스터"가 있다.  

![검색 1](../ja/img/search/search16.png)  

- 그 "상품 마스터"에서는 "테이블 설정(확장 설정)"의 "제목 표시 열 설정"에 "상품 코드"가 설정되어 있다.  

![검색 1](../ja/img/search/search17.png)  

- 테이블 "상품 재고 정보"에, 그 "상품 마스터"를 참조 대상으로 하는 열 "상품 마스터"를 추가한다.  

![검색 1](../ja/img/search/search18.png)  

- 이런 설정일 때, 자유어 검색에서 상품 코드 "A001"을 입력하면 상품 마스터 "A001"을 참조 대상으로 하는 "상품 재고 정보"의 목록이 나옵니다.

![검색 1](../ja/img/search/search19.png)  


#### YES/NO
0/1, 또는 NO/YES 문자열로 검색할 수 있습니다.  
("0"이나 "1", "NO"나 "YES"라는 어디에나 있는 문자열로 검색하게 되므로, "자유어 검색"의 대상으로 하는 것은 그다지 권장하지 않습니다.)


#### 2개 값 선택
선택지의 값, 또는 표시명으로 검색할 수 있습니다.
