# 일시적으로 프로그램을 교체하는 경우
보통의 업데이트와는 별도로, Exment의 프로그램을 일시적으로 바꿔 넣기 위한 절차입니다.  
다음과 같은 때에 사용합니다.

| 하고 싶은 것 | 볼 곳 |
|---|---|
| 선행 개발 버전(개발 중인 버전)을 넣는다 | "개발 버전을 릴리스한다" |
| 과거 버전을 넣는다 | "개발 버전을 릴리스한다"(같은 절차로 과거 버전을 지정합니다) |
| 문제가 있는 소스의 일부를 정식 릴리스 전에 일시적으로 바꿔 넣는다 | "소스 코드를 교체한다" |

**먼저 읽어 주십시오**

- 개발 버전을 넣은 뒤에 소스가 갱신되는 경우가 있습니다. 그 뒤에 원래대로 되돌리면 정상적으로 동작하지 않게 되는 경우가 있습니다.  
특히 데이터베이스의 정의는 변경이 들어가면 불일치가 생기는 경우가 있습니다. 양해 바랍니다.
- 과거 버전을 넣으면 관련 라이브러리의 버전이 바뀌어 정상적으로 동작하지 않게 되는 경우가 있습니다.


### 개발 버전을 릴리스한다
개발 버전이나 과거 버전은 다음 절차로 넣습니다.

1. 폴더 "vendor/exceedone/exment" 안의 소스 코드 전체를 백업합니다.
2. 명령줄에서 다음 명령을 실행합니다. 먼저 백업을 하고, 그런 다음 넣으려는 버전에 맞는 쪽의 2줄(개발 버전인지 과거 버전인지)을 실행하십시오.

~~~
# 백업을 실시한다(범위는 주로 데이터베이스이며, 소스 코드는 백업되지 않습니다)
php artisan exment:backup

# Exment의 개발 버전을 지정한다. 예: 버전 "release_foobar"를 넣는 경우 아래 절차를 실시한다
composer require exceedone/exment=dev-release_foobar
php artisan exment:update

# Exment의 과거 버전을 지정한다. 예: 버전 "4.3.1"을 넣는 경우 아래 절차를 실시한다
composer require exceedone/exment=v4.3.1
php artisan exment:update
~~~

#### 개발 버전에서 최신 버전으로 되돌리는 경우
다음 중 하나를 하면 최신 버전으로 바뀝니다.

- [업데이트](/ko/update)를 한다.
- 다음 명령을 실행한다.

~~~
composer require exceedone/exment
php artisan exment:update
~~~



### 소스 코드를 교체한다
소스 코드의 일부를 바꿔 넣을 때는 다음 절차로 진행합니다.

1. 폴더 "vendor/exceedone/exment" 안의 소스 코드 전체를 백업합니다.  
또는 지금부터 바꿔 넣을 소스 코드만 복사하여 이름을 바꿔 둡니다.
2. "vendor/exceedone/exment"의 해당하는 곳에 바꿔 넣을 소스 코드를 둡니다.

#### 개발 버전에서 최신 버전으로 되돌리는 경우
다음 중 하나를 하면 최신 버전으로 바뀝니다.  
<span class="red">※ 실행 도중에 파일을 덮어쓸지 확인하는 메시지가 나오는 경우가 있습니다.</span> 그때는 동의하고 교체를 진행하십시오.

- [업데이트](/ko/update)를 한다.
- 다음 명령을 실행한다.

~~~
composer require exceedone/exment
php artisan exment:update
~~~
