# 로그인 설정
Exment에 로그인할 때의 규칙을 정하는 페이지입니다. 비밀번호의 규칙(비밀번호 정책)과 2단계 인증을 설정할 수 있습니다.  
명령으로 비밀번호를 재설정하는 방법도 이 페이지에 있습니다.

> SSO에 관한 설정·설명은 [여기](/ko/login_sso)를 확인하십시오.


## 2단계 인증
Exment는 2단계 인증에 대응합니다.  
사용자 정보를 입력하고 로그인한 뒤, 이메일로 온 코드나 Google 인증 시스템에 나오는 코드를 입력하면 Exment를 쓸 수 있게 됩니다.  
※ 2단계 인증은 로그인 방식이 "표준", "LDAP"인 경우에 이용할 수 있습니다.

- [2단계 인증 시스템 설정](/ko/login_2factor_setting)
- [로그인(2단계 인증)](/ko/login_2factor)


## 로그인 설정 관리 방법

- 시스템 관리자가 다음 URL을 엽니다.  
http(s)://(Exment의 URL)/login_setting  
※ 위에 적은 "시스템 설정 변경"을 하면 접속할 수 있게 됩니다.

> ※ URL은 "/admin"이 붙지 않는 표준 설정(v7.2.1 이후에 새로 설치한 사이트)의 경우입니다. `.env`의 `ADMIN_ROUTE_PREFIX`에 값이 있는 경우(이전 버전에서 설치한 사이트는 "admin")는 사이트의 URL 뒤에 그 값을 더하십시오(예: `http(s)://(Exment의 URL)/admin/oauth/token`). 자세한 내용은 [URL에 포함되는 "admin"의 변경·삭제](/ko/additional_prefix)를 보십시오.

- v7.1.0 이후는 왼쪽 메뉴의 "관리자 설정" → "로그인 설정"에서도 열 수 있습니다.
- v7.0 이전은 "로그인 설정"이 처음에는 메뉴에 나오지 않습니다. 메뉴에 더하려면 "관리자 설정" > "메뉴" 페이지를 열고 메뉴 종류 "시스템 메뉴"를 고릅니다. 대상에 "로그인 설정"이 나오니, 고르고 저장하십시오.

![로그인 설정 목록](../img/login/login_setting4.png)  

- 2단계 인증의 설정은 다음 페이지의 절차로 합니다.

    - [2단계 인증 시스템 설정](/ko/login_2factor_setting)


### 비밀번호 정책 설정
로그인 비밀번호에 관한 규칙을 정합니다.   

![비밀번호 정책 설정 화면](../img/system_setting/system_setting_password.png)  

#### 복잡한 비밀번호
- YES로 하면 비밀번호는 3종류 이상의 문자 종류(반각 영문 대문자, 반각 영문 소문자, 반각 숫자, 반각 기호)를 포함한 12자 이상으로 해야 합니다.
- 초기값은 "NO"입니다.

#### 비밀번호 유효 기간(일)
- 정한 일수가 지난 뒤 처음 로그인했을 때 비밀번호 변경 화면이 나옵니다. 비밀번호를 바꾼 뒤에 다시 로그인하십시오.
- 유효 기간(일)을 "0"으로 하면 비밀번호는 무기한이 됩니다.
- 초기값은 "0"입니다.

#### 첫 로그인 시 비밀번호 변경
- YES로 하면 사용자가 처음 로그인했을 때 비밀번호를 바꾸는 화면을 내보냅니다.
- 이 설정을 YES로 한 뒤에 새로 등록한 사용자와 비밀번호를 재설정한 사용자가 대상입니다.
- YES로 하기 전에 새로 등록 등을 한 사용자는 대상이 되지 않습니다.
- 초기값은 "NO"입니다.

#### 비밀번호 이력 수
- 최근에 쓴 비밀번호를 다시 쓸 수 없게 합니다. 새 비밀번호가 최근 이력 수만큼의 비밀번호 중 어느 것과 같을 때는 오류로 합니다.
- 이력 수를 "0"으로 하면 비교하지 않습니다.
- 초기값은 "0"입니다.

#### 주의

- <span class="small">"복잡한 비밀번호"와 "비밀번호 이력 수"는 사용자 설정 화면이나 비밀번호 재설정 화면 등에서 사용자 자신이 비밀번호를 정할 때 쓰입니다. 시스템 관리자가 정할 때는 대상이 아닙니다.</span>


### 기타
- v3.3.0 미만에서 v3.3.0 이상으로 업데이트한 경우에, 사용자 코드에 "점(.)"을 포함한 프로바이더로 로그인하면 오류가 날 수 있습니다.  
그때는 다음과 같이 고치십시오.
    - "사용자" 테이블의 "사용자 정의 열 설정"에서 "사용자 코드" 열의 편집 화면을 연다.
    - "사용 가능 문자" 옵션에서 "점"에 체크를 넣고 저장한다.


- 처음의 설정에서는 로그인한 채로 브라우저를 닫아도 일정 시간(120분)이 지날 때까지는 로그인 상태가 계속됩니다.  
v3.6.0 이후에서는 브라우저를 닫았을 때 자동으로 로그아웃하게 할 수 있습니다. ".env" 파일을 열고 다음과 같이 추가하십시오.  
※ 설정 파일을 고치는 방법은 [설정값 목록](/ko/config)을 보십시오.

~~~
EXMENT_SESSION_EXPIRE_ON_CLOSE=true
~~~




## 비밀번호 재설정 명령
명령으로 사용자의 비밀번호를 재설정할 수 있습니다.

- 시스템 관리자가 콘솔에서 다음 명령을 실행합니다.

~~~
php artisan exment:resetpassword --email=foobar@test.com --password=P@ssw0rd!
~~~

- 이 명령은 이메일 주소가 "foobar@test.com"인 사용자에게 비밀번호 "P@ssw0rd!"를 설정합니다.


### 명령의 인수

```
exment:resetpassword {--id=} {--email=} {--user_code=} {--password=} {--random=0} {--send=0} {--reset_first_login=0}
```

#### 인수: 사용자 지정
※ 다음 인수 중 하나가 필수입니다. 여러 개를 지정했을 때는 id > email > user_code의 순서로 우선하여 찾습니다.

- ##### id
대상 사용자의 로그인 ID입니다.

- ##### email
대상 사용자의 이메일 주소입니다.

- ##### user_code
대상 사용자의 사용자 코드입니다.


#### 인수: 비밀번호
※ "password"나 "random=1" 중 하나를 지정하십시오. 둘 다 지정했을 때는 "password"를 우선합니다.

- ##### password  
새 비밀번호의 문자열을 지정하십시오.

- ##### random  
비밀번호를 무작위로 만들 때는 1을 지정하십시오. 지정하지 않으면 0.

#### 인수: 옵션

- ##### send  
새 비밀번호를 대상 사용자에게 메일로 보낼 때는 1을 지정하십시오. 지정하지 않으면 0.

- ##### reset_first_login  
비밀번호를 바꾼 뒤 사용자가 처음 로그인했을 때 비밀번호를 바꾸는 화면을 내보냅니다. 지정하지 않으면 0.  
※ 이 옵션을 지정하지 않아도, 로그인 설정에서 "첫 로그인 시 비밀번호 변경"을 YES로 해 두면 사용자가 처음 로그인했을 때 비밀번호를 바꾸는 화면을 내보냅니다.

### 특기 사항
- "random=1"을 지정하고 "send=1"을 지정하지 않았을 때는 재설정한 뒤 새 비밀번호를 콘솔에 내보냅니다.


### 명령 실행 예

~~~
# 예: id1의 사용자에게 비밀번호를 지정하여 재설정
php artisan exment:resetpassword --id=1 --password=P@ssw0rd!

# 예: 사용자 코드 "user1"의 사용자에게 무작위 비밀번호를 설정하고 메일을 보낸다
php artisan exment:resetpassword --user_code=user1 --random=1 --send=1

# 예: 이메일 주소 "foobar@test.com"의 사용자에게 무작위 비밀번호를 설정한다
php artisan exment:resetpassword --email=foobar@test.com --random=1
비밀번호를 재설정했습니다. 새 비밀번호: XXXXXXXXXX #변경 후의 비밀번호가 콘솔에 출력된다
~~~
