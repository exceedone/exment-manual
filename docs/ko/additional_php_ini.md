# PHP 설정값 변경

PHP의 설정값을 바꾸는 절차입니다. 다음 4가지를 바꿀 수 있습니다.

| 설정 | 바꾸면 어떻게 되는가 |
| ---- | ---- |
| 파일 업로드 상한 크기 변경 | 화면에서 업로드할 수 있는 파일의 크기가 바뀝니다 |
| 메모리 양 변경 | Exment(PHP)가 쓰는 메모리의 양이 바뀝니다 |
| 타임아웃 시간 변경 | 시간이 걸리는 처리가 도중에 잘 멈추지 않게 됩니다 |
| 한 번에 POST할 수 있는 상한 수 | 항목이 많은 화면에서도 저장할 수 있게 됩니다 |

바꾸는 방법은 아래의 "[설정 방법](/ko/additional_php_ini?id=설정-방법)"을 보십시오.


#### 파일 업로드 상한 크기 변경
Exment에는 화면에서 파일을 업로드하는 기능이 있습니다.  
업로드할 수 있는 파일의 크기에는 서버마다 상한이 있습니다.  
(처음의 상한은 설치한 서버에 따라 다릅니다)  

#### 메모리 양 변경
Exment(PHP)가 쓰는 메모리의 양을 바꿉니다.  
메모리의 양이 클수록 처리가 빨라지거나 한 번에 실행할 수 있는 내용이 달라집니다. 다만 너무 크면 서버의 동작에 영향을 줄 수 있습니다.

#### 타임아웃 시간 변경
PHP의 타임아웃 시간(처리를 중단하기까지의 시간)을 바꿉니다.  
시간을 길게 하면 가져오기·내보내기·백업 등 시간이 걸리는 기능을 더 확실하게 실행할 수 있습니다.  
※시간이 걸리는 기능에는 타임아웃 시간을 늘리는 처리를 처음부터 Exment의 코드에도 넣어 두었습니다. 다만 환경에 따라서는 이 처리가 듣지 않을 수 있습니다. 타임아웃이 자주 일어날 때 이 설정을 하십시오.

#### 한 번에 POST할 수 있는 상한 수
한 번에 POST할 수 있는(화면에서 보낼 수 있는) 항목 수의 상한을 정합니다.  
데이터를 입력하는 화면에서 항목 수가 상한을 넘으면 올바르게 동작하지 않을 수 있습니다.  
※주로 다음 화면에서 상한이 모자라 오류가 날 수 있습니다.  

- 워크플로 이용 설정에서 테이블 수·워크플로 수가 많을 때
- 사용자 정의 폼 설정 화면에서 등록하는 열의 항목이 아주 많을 때
- 사용자 정의 데이터 입력 화면에서 항목이 아주 많을 때




## 설정 방법
설정 방법 1·2 중 하나로 설정하십시오.


### 설정 방법1 php.ini 수정

1. PHP를 설치한 폴더에 있는 "php.ini" 파일을 엽니다. ※php.ini 파일의 위치는 환경에 따라 다릅니다.

2. php.ini 파일의 다음 값을 고칩니다. ※이미 숫자가 들어 있는 경우가 많으므로 숫자를 바꿔 쓰십시오.

~~~
### 파일 업로드 상한 크기 변경
#POST 데이터에 허용되는 최대 크기
post_max_size=20M
#파일 하나의 업로드에 허용되는 최대 크기
upload_max_filesize=20M


### 메모리 양 변경
# 512M으로 변경하는 경우
memory_limit=512M
# 무제한으로 변경하는 경우
memory_limit=-1


### 타임아웃 시간 변경
#240초로 변경하는 경우
max_execution_time=240
#무제한으로 변경하는 경우
max_execution_time=0


### 한 번에 POST할 수 있는 상한 수 변경
#3000건으로 변경하는 경우
max_input_vars=3000
~~~

3. 서버를 다시 시작합니다.


### 설정 방법2 .htaccess 파일 수정
1. Exment를 설치한 폴더의 "public/.htaccess" 파일을 엽니다.

2. 다음 값을 추가합니다.

~~~
### 파일 업로드 상한 크기 변경
#POST 데이터에 허용되는 최대 크기
php_value post_max_size 20M
#파일 하나의 업로드에 허용되는 최대 크기
php_value upload_max_filesize 20M


### 메모리 양 변경
# 512M으로 변경하는 경우
php_value memory_limit 512M
# 무제한으로 변경하는 경우
php_value memory_limit -1


### 타임아웃 시간 변경
#240초로 변경하는 경우
php_value max_execution_time 240
#무제한으로 변경하는 경우
php_value max_execution_time 0


### 한 번에 POST할 수 있는 상한 수 변경
#3000건으로 변경하는 경우
php_value max_input_vars 3000
~~~

3. 서버를 다시 시작합니다.
