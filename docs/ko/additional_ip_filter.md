# IP 필터
Exment의 Web 페이지와 API에 접속할 수 있는 IP 주소를 정하는 설정입니다.

- 허용할 IP 주소만 등록합니다(화이트리스트 방식).
- Web 페이지용과 API용을 따로 등록합니다. 예를 들어 "API만 실행할 수 있는 IP 주소를 제한"할 수도 있습니다.


### 설정 절차
1. Exment를 전문가 모드로 바꿉니다. 아직 전문가 모드가 아니면 ".env" 파일을 열고 다음 값을 추가합니다.

~~~
EXMENT_EXPART_MODE=true
~~~

2. 시스템 설정 화면을 엽니다. IP 필터 설정 항목이 추가되어 있습니다.

![IP 필터 설정](../img/quickstart/ip_filter.png)

#### 설정 내용 상세

| 하고 싶은 일 | 입력 방법 | 예 |
| ---- | ---- | ---- |
| IP 주소를 1개 정해서 허용한다 | IP 주소를 그대로 입력합니다 | 123.4.5.6 |
| IP 주소를 범위로 허용한다 | 서브넷 마스크 형식으로 입력합니다 | 예1: 123.4.0.0/16 → 123.4.0.0부터 123.4.255.255까지 접속 허용<br>예2: 123.4.10.0/24 → 123.4.10.0부터 123.4.10.255까지 접속 허용 |
| localhost에 만든 서버에서 localhost로부터의 접속을 허용한다 | "::1"이라고 입력합니다 | ::1 |
| 여러 IP 주소를 허용한다 | 줄바꿈으로 구분해서 입력합니다. 어느 하나에 맞으면 접속할 수 있습니다 | |


#### IPv6 (7.3.0)
Exment 7.3.0부터 IPv6 주소와 범위도 입력할 수 있습니다. IPv4와 함께 입력해도 됩니다.

| 하고 싶은 것 | 입력 방법 | 예 |
| ---- | ---- | ---- |
| IPv6 주소 하나를 허용 | 주소를 그대로 입력합니다(대문자·소문자, 짧은 형식·긴 형식 모두 가능) | 2001:db8::10 |
| 집이나 회사의 네트워크를 허용 | 프로바이더에게서 받은 /64를 입력합니다 | 2001:db8:1:2::/64 |
| 더 넓은 IPv6 범위를 허용 | 프리픽스 길이를 붙여 입력합니다 | 2001:db8::/32 |

- 듀얼 스택 서버에서 `::ffff:192.0.2.7`처럼 보이는 IPv4 클라이언트는 `192.0.2.7`로 비교합니다. `192.0.2.0/24` 같은 IPv4 줄에 맞습니다.
- 줄은 줄바꿈이나 쉼표로 구분합니다. 주소나 범위 형식이 아닌 줄은 저장할 수 없습니다.
- 시도 횟수 제한(로그인 잠금, API 횟수 제한)은 IPv6 주소를 /64 단위로 셉니다. 같은 /64 안에서 주소를 바꿔도 횟수가 늘지 않습니다.
- 로그 관리의 IP 설정에서 「줄이기」를 선택하면 IPv6 주소는 /64까지 남깁니다(`2001:db8:1:2::/64`).

#### IP 제한을 강제로 끄기
Web 페이지의 IP 주소 설정을 잘못해서 접속할 수 없게 되었을 때 등에 IP 제한을 멈추는 절차입니다.

- ".env" 파일을 열고 다음 값을 추가합니다.

~~~
EXMENT_DISABLE_IP_FILTER=true
~~~
