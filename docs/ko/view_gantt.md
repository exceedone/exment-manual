# 간트 차트 뷰

데이터를 시작일부터 기한일(종료일)까지의 가로 막대(바)로 만들어, 시간 순서대로 표시하는 뷰입니다.

## 간트 차트 뷰란

간트 차트란 작업별 기간을 가로 막대로 나타내고, 날짜 눈금 위에 늘어놓아 표시하는 그림입니다.  
어느 작업이 언제부터 언제까지 예정되어 있는지, 오늘 시점에 어느 작업이 기한을 넘겼는지 한눈에 알 수 있습니다.

Exment의 간트 차트 뷰에서는 다음을 할 수 있습니다.

- 데이터 1건을 시작일 열부터 기한일(종료일) 열까지의 막대 하나로 표시하기
- 선택지 열의 값별로 막대의 색을 구분하기
- 진행률을 막대 안에 겹쳐서 표시하고, 기한을 넘겼는데 완료되지 않은 데이터를 빨간 테두리로 강조하기
- 선택지나 마일스톤(테이블에서 선택)별로 행을 그룹화하고, 마일스톤의 기한을 ◆ 표시로 나타내기
- 부모·자식 관계가 있는 데이터를 부모 아래에 들여쓰기하여 표시하기
- 담당자를 아이콘으로 표시하기

※ 간트 차트는 표시 전용입니다. 차트 위에서 막대를 끌어서 날짜를 바꿀 수는 없습니다. 날짜 등을 바꾸려면 데이터의 편집 화면에서 바꾸십시오.

## 뷰 새로 추가

1. 사용자 정의 뷰 설정 화면을 엽니다([사용자 정의 뷰](/ko/view) 참고).
2. 오른쪽 위의 ［새로 만들기］ 버튼을 클릭합니다.
3. 표시된 대화 상자에서 "간트 차트 뷰 새로 만들기"를 선택합니다.

데이터 목록 화면의 ［뷰］ 버튼 메뉴에서도 "간트 차트 뷰 새로 만들기"를 선택할 수 있습니다. 이 경우 저장한 다음 그 뷰로 데이터 목록이 표시됩니다.

※ 테이블에 "날짜" 또는 "날짜 및 시각" 열이 하나도 없으면 "간트 차트 뷰 새로 만들기"는 표시되지 않습니다.

#### 뷰 표시 이름·뷰 권한·기본값·뷰 정보 상자 사용

## 기본 설정

#### 시작일 열
막대의 시작 위치가 되는 날짜 열입니다. (필수)  
※ "날짜", "날짜 및 시각" 열만 지정할 수 있습니다. "날짜 및 시각" 열은 날짜 부분만 사용합니다.

#### 기한일(종료일) 열
막대의 끝 위치가 되는 날짜 열입니다. (필수)  
막대는 시작일부터 기한일까지(두 날짜 모두 포함) 표시됩니다.  
※ "날짜", "날짜 및 시각" 열만 지정할 수 있습니다.  
※ 기한일이 오늘보다 앞이고 진행률이 100 미만인 데이터는 "기한 초과"로서, 막대가 빨간 테두리로, 행 왼쪽의 기한일이 빨간 글씨로 표시됩니다. "진행률 열"을 설정하지 않은 경우나 진행률을 입력하지 않은 경우에도 기한 초과로 다룹니다.

#### 막대 색 구분(선택지 열)
이 열의 값별로 막대의 색을 구분합니다. 차트 위쪽에 값과 색의 범례가 표시됩니다.  
※ "선택 (고정 값)", "선택 (값과 표시명 저장)" 열만 지정할 수 있습니다. 다중 선택 열인 경우에는 첫 번째 값으로 색을 구분합니다.  
※ 색은 그 열의 "값별 색상"(열에 설정한 [표시 프리셋](/ko/cell_style_preset) 포함)을 그대로 사용합니다. 색을 지정하지 않은 값에는 선택지의 순서에 따른 색이 자동으로 할당됩니다.  
※ 설정하지 않으면 모든 막대가 파란색으로 표시됩니다.

#### 진행률 열(0~100)
막대 안에 진행률(%)만큼 짙은 색을 겹쳐서 표시합니다.  
※ "정수", "소수", "통화" 열만 지정할 수 있습니다.  
※ 값은 0~100으로 다룹니다. 0 미만은 0, 100을 넘는 값은 100으로 표시합니다.

## 고급 설정

#### 행 그룹화 기준 열
이 열의 값별로 행을 그룹화하여 표시합니다. 지정하지 않으면 그룹화하지 않고 표시합니다.  
※ "선택 (고정 값)", "선택 (값과 표시명 저장)", "선택 (테이블에서)" 열(다중 선택이 아닌 것)만 지정할 수 있습니다.

그룹의 순서는 다음과 같습니다.

| 열의 종류 | 순서 |
| --- | --- |
| 선택 (고정 값), 선택 (값과 표시명 저장) | 선택지의 순서 |
| 선택 (테이블에서) | 참조 대상 데이터의 기한이 가까운 순. 기한이 없는 것은 마지막 |

- "선택 (테이블에서)" 열(마일스톤 테이블을 참조하는 열 등)을 지정한 경우, 참조 대상 데이터의 기한을 그룹의 제목 행과 차트 위의 ◆ 표시로 나타냅니다.
- 값을 입력하지 않은 데이터는 마지막에 "미분류" 그룹으로 표시됩니다.
- 데이터가 1건도 없는 값의 그룹은 표시되지 않습니다.

※ 참조 대상 데이터의 기한에는, 참조 대상 테이블의 날짜 열("날짜", "날짜 및 시각") 중 열 이름에 "due", "end", "limit", "deadline", "期限" 중 하나가 들어 있는 첫 번째 열을 사용합니다. 해당하는 열이 없으면 마지막 날짜 열을 사용합니다. 날짜 열이 없으면 ◆ 표시는 나타나지 않습니다.

#### 상위 열(자기 테이블 참조)
자기 테이블을 참조하는 열을 고르면, 자식 데이터를 부모 데이터 바로 아래에 "└"를 붙여 들여쓰기하여 표시합니다.  
※ "선택 (테이블에서)" 열 중 참조 대상이 이 테이블 자신인 열만 지정할 수 있습니다.  
※ 들여쓰기되는 것은 1계층뿐입니다. 손자 이후의 데이터는 그룹의 마지막에 들여쓰기 없이 표시됩니다.  
※ 부모 데이터가 같은 그룹에 표시되어 있지 않으면, 자식 데이터는 보통의 행으로 표시됩니다.

#### 담당자 열
사용자 열을 고르면 각 행에 담당자의 아이콘(사용자 이름의 첫 글자)을 표시합니다. 아이콘에 마우스를 올리면 사용자 이름이 표시됩니다.  
※ "사용자" 열, 또는 참조 대상이 사용자 테이블인 "선택 (테이블에서)" 열만 지정할 수 있습니다. 다중 선택 열인 경우에는 첫 번째 사람을 표시합니다.

#### 최대 표시 건수
차트에 표시할 데이터의 최대 건수입니다(10~2000, 초기값 500).  
※ 입력하지 않은 경우나 범위 밖의 값인 경우에는 500건으로 다룹니다.  
※ 표시 조건에 일치하는 데이터가 이 건수를 넘으면 "데이터 건수가 상한(○건)을 초과했습니다. 표시 조건으로 범위를 좁히십시오."라고 표시되고, 넘은 만큼의 데이터는 표시되지 않습니다.

## 데이터 정렬·데이터 표시 조건

[뷰의 설정 항목](/ko/view)의 "데이터 정렬", "데이터 표시 조건"과 같은 설정 항목입니다.  
"데이터 표시 조건"으로 차트에 표시할 데이터를 좁힙니다.

※ 차트 위의 행은 "데이터 정렬" 설정과 관계없이, 각 그룹 안에서 시작일이 이른 순으로 표시됩니다(시작일을 입력하지 않은 데이터는 마지막). "데이터 정렬"은 데이터가 "최대 표시 건수"를 넘었을 때 어느 데이터를 표시할지의 순서에 사용됩니다.

## 차트 사용법

### 화면 보는 법

#### 도구 모음

| 장소 | 내용 |
| --- | --- |
| 왼쪽 | 범례입니다. "막대 색 구분"의 값과 색, 오늘을 나타내는 "│ 오늘", 마일스톤의 기한이 있는 경우에는 "◆ 기한"이 표시됩니다. |
| 오른쪽 | 데이터 목록 화면과 같은 ［뷰］ 버튼, 테이블의 메뉴, ［새로 만들기］ 버튼이 표시됩니다(권한에 따라 표시됩니다). |

#### 행의 왼쪽

각 행의 왼쪽에 막대의 색·데이터의 제목·담당자의 아이콘·기한일(월/일)이 표시됩니다.

- 데이터의 제목은 데이터의 상세 화면으로 가는 링크입니다.
- 담당자의 아이콘은 "담당자 열"을 설정한 경우에만 표시됩니다.
- 기한일을 입력하지 않은 데이터는 "—"로 표시됩니다. 기한 초과 데이터는 빨간 글씨로 표시됩니다.
- 왼쪽 위의 제목에는 "행 그룹화 기준 열"의 이름이 표시됩니다.

#### 날짜 눈금

- 윗단에 연월(예: 2026/10), 아랫단에 각 주의 월요일 날짜(예: 10/19)가 표시됩니다. 폭이 좁으면 주의 날짜는 한 주 걸러 표시됩니다.
- 토요일·일요일은 배경이 옅은 회색으로 표시됩니다.
- 오늘의 위치에 빨간 세로선과 "오늘"이 표시됩니다.
- 표시하는 기간은 표시할 데이터의 시작일·기한일, 마일스톤의 기한, 오늘을 포함하도록 자동으로 정해집니다. 앞뒤에 며칠의 여백을 두고, 월요일부터 일요일 단위로 맞춥니다.
- 하루당 폭은 화면의 폭에 맞추어 자동으로 조정됩니다(확대·축소 전환은 없습니다). 기간이 길면 가로로 스크롤하여 표시합니다.
- 화면을 열었을 때는 오늘 날짜가 보이는 위치까지 자동으로 스크롤합니다.

※ 오늘부터 약 3년 이상 떨어진 날짜는 표시 기간을 넓히는 대상이 되지 않습니다. 그 경우 막대는 표시 기간의 끝에서 잘려 표시됩니다.

#### 막대

- 시작일부터 기한일까지의 막대가 표시됩니다.
- "진행률 열"을 설정한 경우, 진행률만큼 막대 안에 짙은 색이 겹쳐서 표시됩니다.
- 기한 초과 데이터는 막대의 둘레가 빨간 테두리가 됩니다.
- 막대에 마우스를 올리면 데이터의 제목·기간(시작일 ~ 기한일)·진행률·담당자 이름이 표시됩니다.

※ 시작일 또는 기한일을 입력하지 않은 데이터는 막대가 표시되지 않고, 행의 왼쪽만 표시됩니다.

#### 그룹의 제목 행

"행 그룹화 기준 열"을 설정한 경우, 그룹마다 제목 행이 표시됩니다.

- 제목 행에는 그룹 이름·건수, (마일스톤인 경우에는) 기한일이 표시됩니다.
- 제목 행을 클릭하면 그 그룹의 행을 접거나 펼칠 수 있습니다.

### 데이터 열기

막대, 또는 행 왼쪽의 데이터 제목을 클릭하면 그 데이터의 상세 화면으로 이동합니다.

### 표시되는 메시지

| 메시지 | 내용 |
| --- | --- |
| 간트 차트를 표시하려면 시작일 열과 종료일 열이 모두 필요합니다. 뷰 설정 화면에서 날짜 열을 선택하십시오. | "시작일 열", "기한일(종료일) 열"이 설정되지 않았거나, 지정한 열이 날짜 열이 아니게 된(삭제된) 경우에 표시됩니다. |
| 데이터 건수가 상한(○건)을 초과했습니다. 표시 조건으로 범위를 좁히십시오. | 표시 조건에 일치하는 데이터가 "최대 표시 건수"를 넘은 경우에 표시됩니다. |
| 표시할 데이터가 없습니다. | 표시할 데이터가 1건도 없는 경우에 표시됩니다. |

## 주의 사항

- 간트 차트는 표시 전용입니다. 막대를 끌거나 차트 위에서 편집할 수는 없습니다.
- 표시되는 것은 로그인 사용자가 볼 수 있는 데이터뿐입니다.
- 뷰 설정 화면의 ［미리 보기］ 버튼으로 저장하기 전에 표시 내용을 확인할 수 있습니다([사용자 정의 뷰](/ko/view) 참고).
- 대시보드의 "데이터 목록", "차트"에서는 간트 차트 뷰를 선택할 수 없습니다([대시보드](/ko/dashboard) 참고).
