# 매개변수 변수 목록
실행할 때 실제 값으로 바뀌는 "매개변수 변수"의 목록입니다. "${변수 이름}"의 형태로 적습니다([예](/ko/params?id=예)).
아래의 항목에서 사용할 수 있습니다.

- 알림 템플릿
    - 데이터 새로 만들기·업데이트 등
    - 시간 경과
    - 버튼
    - 워크플로
    - 사용자의 새로 만들기
    - 사용자의 비밀번호 재설정
    - 공개 폼의 등록 완료(사용자·관리자) 알림, 오류 알림
- 문서 출력
- 사용자 정의 열의 자동 채번
- 메일 전송의 보낸 사람 표시 이름

## 변수 목록
### 날짜
아래의 예는 실행 일시가 "2018/02/17 11:20:32"인 경우입니다.

| 항목 | 설명 |
| ---- | ---- |
| ${y} or ${year} | 실행할 때의 연도가 4자리로 설정됩니다. (예: 2018) |
| ${m} or ${month} | 실행할 때의 월이 설정됩니다. (예: 2) |
| ${m:(정수)} or ${month:(정수)} | 실행할 때의 월이 지정한 정수의 자릿수로 설정됩니다. (예: ${m:2}라고 적은 경우, 02) |
| ${d} or ${day} | 실행할 때의 일이 설정됩니다. (예: 17) |
| ${d:(정수)} or ${day:(정수)} | 실행할 때의 일이 지정한 정수의 자릿수로 설정됩니다. (예: ${d:2}라고 적은 경우, 17) |
| ${h} or ${hour} | 실행할 때의 시가 설정됩니다. (예: 11) |
| ${h:(정수)} or ${hour:(정수)} | 실행할 때의 시가 지정한 정수의 자릿수로 설정됩니다. (예: ${hour:2}라고 적은 경우, 11) |
| ${i} or ${minute} | 실행할 때의 분이 설정됩니다. (예: 20) |
| ${i:(정수)} or ${minute:(정수)} | 실행할 때의 분이 지정한 정수의 자릿수로 설정됩니다. (예: ${minute:2}라고 적은 경우, 20) |
| ${s} or ${second} | 실행할 때의 초가 설정됩니다. (예: 32) |
| ${s:(정수)} or ${second:(정수)} | 실행할 때의 초가 지정한 정수의 자릿수로 설정됩니다. (예: ${second:2}라고 적은 경우, 32) |
| ${ymdhms} or ${ymdhis} | yyyymmddhhiiss 문자열(예: 20180217112032) |
| ${ymdhm} or ${ymdhi} | yyyymmddhhii 문자열(예: 201802171120) |
| ${ymdh} | yyyymmddHH 문자열(예: 2018021711) |
| ${ymd} | yyyymmdd 문자열(예: 20180217) |
| ${ym} | yyyyMM 문자열(예: 201802) |
| ${hms} or ${his} | hhiiss 문자열(예: 112032) |
| ${hm} or ${hi} | hhii 문자열(예: 1120) |
| ${now} | 실행 일시가 yyyymmddhhiiss 형식으로 출력됩니다. (예: 20180217112032) |
| ${now:(format)} | 실행 일시가 지정한 포맷의 형식으로 출력됩니다. 포맷은 <a href="https://www.php.net/manual/function.date.php" target="_blank">여기</a>를 참조해 주십시오.<br />(예: ${now:y}라고 적은 경우, 18) |

### 데이터
| 항목 | 설명 |
| ---- | ---- |
| ${id} | 등록되어 있는 데이터의 ID가 설정됩니다. (예: 123) |
| ${id:(정수)} | 등록되어 있는 데이터의 ID가 지정한 정수의 자릿수로 설정됩니다. (예: ${id:5}라고 적은 경우, 00123) |
| ${suuid} | 등록되어 있는 데이터의 suuid(Short UUID. 20자리의 무작위 문자열)가 설정됩니다. |
| ${created_user} | 데이터를 등록한 사용자 이름이 설정됩니다. (예: 관리자) |
| ${updated_user} | 데이터를 업데이트한 사용자 이름이 설정됩니다. (예: 사용자 A) |
| ${created_at} | 데이터를 등록한 일시가 설정됩니다. (예: 2020/08/06 10:00:00) |
| ${updated_at} | 데이터를 업데이트한 일시가 설정됩니다. (예: 2020/08/06 14:00:00) |
| ${value_url} | 등록되어 있는 데이터를 표시하는 링크가 설정됩니다. |
| ${value:(열 이름)} | 등록되어 있는 데이터의 열의 값이 설정됩니다.<br />(예: 사용자 데이터에 대해 ${value:user_code}라고 적은 경우, 사용자 코드가 설정된다) |

#### 데이터(옵션)
"${value:(열 이름)/(옵션 키 1)=(옵션 값 1)}"처럼 적으면, 매개변수에 옵션을 추가할 수 있습니다. 옵션이 여러 개 있는 경우에는 쉼표로 구분해 주십시오.
예:
- ${value:mitsumori_date/format="Y"}
- ${value:mitsumori_price/disable_number_format=1,disable_currency_symbol=1}

| 옵션 키 | 설명 |
| ---- | ---- |
| ${value:(열 이름)/format="(날짜 포맷)"} | 열 종류가 "날짜", "날짜 및 시각"일 때, 등록되어 있는 데이터의 열의 값을 포맷 변환하여 표시합니다.<br />(예 1: "계약 정보(contract)" 테이블에 "계약일(contract_date)" 열이 있고, 계약 연도를 표시하고 싶은 경우, ${value:contract_date/format="Y"})<br />(예 2: "계약 정보(contract)" 테이블에 "계약일(contract_date)" 열이 있고, "yyyy/mm/dd" 형식으로 표시하고 싶은 경우, ${value:contract_date/format="Y/m/d"})|
| ${value:(열 이름)/disable_number_format=1} | 열 종류가 "정수", "소수", "통화"일 때, "숫자 쉼표 구분" 설정을 무효로 합니다.|
| ${value:(열 이름)/disable_currency_symbol=1} | 열 종류가 "통화"일 때, "통화 표시 형식" 설정(엔 기호, $ 등)을 무효로 합니다.|


### 관계, 관련 데이터
| 항목 | 설명 |
| ---- | ---- |
| ${select_table:(열 이름).(참조하는 테이블의 열 이름)} | "열 이름"에 해당하는 열이 "선택 (테이블에서)", "사용자", "조직"인 경우, 참조하는 열의 값이 설정됩니다.<br />   (예: "계약 정보(contract)" 테이블에 "고객(client)" 열이 있고 "고객 정보(client)" 테이블을 참조하는 경우, ${select_table:client.client_code}라고 설정하면 "고객 정보(client)" 테이블의 고객 코드(client_code)를 표시할 수 있다) |
| ${parent:(참조하는 테이블의 열 이름)} | 상위 테이블의 열의 값이 설정됩니다.<br />(예: "계약 명세 정보(contract_detail)" 테이블에서 상위인 "계약 정보(contract)" 테이블의 계약 코드(contract_code)를 참조하는 경우, ${parent:contract_code}라고 적으면 계약 코드가 설정된다) |


### 개별
기능에 따라서는 그 기능에서만 쓸 수 있는 변수 매개변수가 있습니다.
아래는 각 기능·화면과, 그 기능에서 사용할 수 있는 매개변수의 목록입니다.

#### 알림
메일이나 시스템 내 알림으로 사용자에게 알림을 보내는 경우에 사용할 수 있습니다.

| 항목 | 설명 |
| ---- | ---- |
| ${user:user_name} | 메일을 받는 사용자의 사용자 이름 |
| ${user:user_code} | 메일을 받는 사용자의 사용자 코드 |
| ${user:email} | 메일을 받는 사용자의 이메일 주소 |

#### 알림(첨부 파일)
알림 템플릿의 열 "사용자 정의 첨부 파일"에 아래의 규칙으로 매개변수를 설정하면, 메일 알림 때 그 사용자 정의 열에 등록되어 있는 첨부 파일을 사용자에게 보냅니다.
자세한 내용은 [첨부 파일·사용자 정의 첨부 파일](/ko/mail)을 확인해 주십시오.
※현재, 메일 알림의 경우에만 유효합니다.

| 항목 | 설명 |
| ---- | ---- |
| ${file:(사용자 정의 열 이름)} | 사용자 정의 열의 종류 "파일", "이미지"에 등록되어 있는 첨부 파일 |
| ${file:select_table:(선택 항목의 사용자 정의 열 이름).(참조하는 테이블의 파일 열 이름)} | 사용자 정의 열 "선택 (테이블에서)"에서 선택한 데이터의 "파일", "이미지" 열에 등록되어 있는 첨부 파일.<br/>예: ${file:select_table:customer.contract_file} |
| ${documents} | 데이터 상세 화면에 대해 등록되어 있는(위 링크 페이지의 이미지에 해당하는 곳) 첨부 파일 |

#### 로그인 사용자
로그인했을 때만 사용할 수 있습니다. 배치 등으로 알림을 보내는 경우에는 사용할 수 없습니다.

| 항목 | 설명 |
| ---- | ---- |
| ${login_user:user_name} | 로그인 사용자의 사용자 이름 |
| ${login_user:user_code} | 로그인 사용자의 사용자 코드 |
| ${login_user:email} | 로그인 사용자의 이메일 주소 |
| ${login_user:(열 이름)} | 로그인 사용자의, 지정한 열의 값이 설정됩니다 |

#### 비밀번호 재설정
비밀번호 재설정 메일을 보낼 때만 사용할 수 있습니다.

| 항목 | 설명 |
| ---- | ---- |
| ${system:password_reset_url} | 시스템의 비밀번호 재설정 URL |
| ${user:password} | 메일을 받는 사용자의 로그인 비밀번호 |

#### 공개 폼
공개 폼의 알림에서만 사용할 수 있습니다.

| 항목 | 설명 |
| ---- | ---- |
| ${publicform:public_form_view_name} | 공개 폼 표시명 |
| ${publicform:inputs} | 공개 폼 사용자 입력값 |

#### 공개 폼(오류 발생 시)
공개 폼의 오류 발생 시의 알림에서만 사용할 수 있습니다.

| 항목 | 설명 |
| ---- | ---- |
| ${error:message} | 공개 폼 오류 개요 |
| ${error:stacktrace} | 공개 폼 오류 상세 |


#### 플러그인(문서 출력)

| 항목 | 설명 |
| ---- | ---- |
| ${value_image:(열 이름)} | "열 이름"에 해당하는 열의 종류가 "이미지"인 경우, Excel에 이미지를 출력합니다. |
| ${value_image:(열 이름)/width=(크기 정수),height=(크기 정수)} | 출력할 이미지의 너비(width)나 높이(height)를 지정하는 경우, 옵션을 입력해 주십시오. width 또는 height 어느 한쪽만 지정할 수도 있습니다. |


## 예
※실행일이 2018/8/9, 대상 데이터의 ID가 100, 대상 데이터의 user_code(사용자 코드)가 "U12345"인 경우
- U-${id:4} → U-0100
- ${y}-${m:2}-${d:2}-${id} → 2018-08-09-100
- ${y}${m:2}${d:2}-${id:5} → 20180809-00100
- ${now:y}${m:2}${d:2}-${id:4} → 180809-0100
- ${y}${m:2}${d:2}-${value:user_code} → 20180809-U12345
