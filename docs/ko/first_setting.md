# 초기 설정
설치한 뒤 처음에 하는 설정의 절차입니다. 사이트의 정보와 첫 관리자의 로그인 ID 등을 정합니다.

절차는 다음 4가지입니다.

1. Exment의 페이지에 접속한다
2. 초기 설정 화면에서 필요한 정보를 입력한다
3. 쓰고 싶은 템플릿을 고른다
4. "제출" 버튼을 누른다

## URL 접속
Exment의 페이지에 접속합니다.  
http(s)://(귀하의 사이트 URL)  

> ※ URL은 "/admin"이 붙지 않는 표준 설정(v7.2.1 이후에 새로 설치한 사이트)의 경우입니다. `.env`의 `ADMIN_ROUTE_PREFIX`에 값이 있는 경우(이전 버전에서 설치한 사이트는 "admin")는 사이트의 URL 뒤에 그 값을 더하십시오(예: `http(s)://(Exment의 URL)/admin/oauth/token`). 자세한 내용은 [URL에 포함되는 "admin"의 변경·삭제](/ko/additional_prefix)를 보십시오.

## 초기 설정 화면
설치가 올바르게 끝났으면 Exment의 초기 설정 화면이 나옵니다.

![초기 설정 화면](../img/install/install1.png)
시스템 설정에 필요한 정보를 입력하십시오.  
※ 항목의 자세한 설명은 [시스템 설정](/ko/system_setting)을 보십시오.

## 템플릿 설정
Exment에는 미리 템플릿이 준비되어 있습니다.  
템플릿을 고르면 그 템플릿에 들어 있는 테이블·열·폼·메뉴·권한이 한꺼번에 설치됩니다.  
다른 Exment에서 내보낸 템플릿을 이 화면에서 업로드할 수도 있습니다.  
자세한 내용은 [템플릿](/ko/template)을 보십시오.

![설치 화면_템플릿](../img/install/install_template.png)

목록에는 처음부터 시스템에 들어 있는 템플릿과 지금까지 가져온 템플릿이 나옵니다.  
설치하고 싶은 템플릿을 고르십시오.  

## 초기 설정 완료
필요한 항목을 입력하고 "제출" 버튼을 누르면 설정이 저장되고 Exment를 쓸 수 있게 됩니다.
